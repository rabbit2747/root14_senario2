# 프로젝트 계획서: APT 시나리오 기반 인프라 학습 플랫폼

## 1. 프로젝트 개요

본 프로젝트는 사이버보안 교육을 기존의 텍스트·슬라이드 중심 방식에서 벗어나, **시나리오 기반 인프라 맵**으로 학습하게 하는 웹 교육 플랫폼이다.

수강생은 먼저 전체 인프라 구조를 시각적으로 확인하고, 이후 공격 시나리오의 각 단계마다 어떤 인프라가 사용되는지 애니메이션과 활성화 효과를 통해 직관적으로 학습한다.

## 2. 핵심 아이디어

```text
시나리오 입력
→ LLM이 인프라 구조, 경계, 통신 흐름, 단계별 활성화 정보를 생성
→ Layout Engine이 기업망 구조에 맞게 자동 배치
→ React Flow Renderer가 인프라 맵 표시
→ 수강생은 단계별로 활성화되는 인프라와 통신 흐름을 학습
```

## 4. 핵심 가치

| 기존 방식 | 본 플랫폼 방식 |
|---|---|
| 공격 단계를 텍스트로 설명 | 공격 단계별 인프라 활성화로 설명 |
| 수강생이 망 구조를 상상해야 함 | 전체 인프라 맵을 먼저 제공 |
| 시나리오와 인프라가 분리됨 | 시나리오, 인프라, 통신 흐름이 연결됨 |
| 콘텐츠 제작에 시간이 많이 듦 | LLM이 템플릿 기반 시나리오 구조 생성 |
| 슬라이드 중심의 정적 교육 | 단계별 애니메이션 중심의 인터랙티브 교육 |

## 6. MVP 범위

MVP라 하더라도 사용자가 보는 품질은 낮추지 않는다. 다만 구현 범위를 명확히 제한한다.

### 포함 범위

- 웹 기반 수강생 플레이어
- React Flow 기반 인프라 맵
- 기업망/외부망/DMZ/내부망/클라우드 그룹 경계 표현
- 커스텀 인프라 노드
- 커스텀 애니메이션 엣지
- 단계별 활성화
- JSON 기반 시나리오 로딩
- LLM 프롬프트 템플릿
- 관리자 미리보기 화면

### 제외 범위

- 실제 공격 실습 환경 제공
- 실제 취약점 공격 코드 제공
- 실시간 패킷 캡처 연동
- 복잡한 3D WebGL 렌더링
- 수천 개 규모의 노드 렌더링

### Phase 1. 기반 구축

- Next.js 프로젝트 생성

- 기본 InfraNode 컴포넌트 구현

### Phase 3. LLM 생성 파이프라인

### Phase 5. 학습 기능

## 11. 주요 리스크와 대응

| 리스크 | 설명 | 대응 |
|---|---|---|
| LLM 출력 불안정 | JSON 누락, 잘못된 참조 발생 | Zod 검증, 자동 보정, 재생성 프롬프트 |
| 레이아웃 품질 저하 | 노드 겹침, 경계 밖 배치 | 규칙 기반 Layout Engine, 후처리 충돌 검사 |
| 애니메이션 과부하 | 많은 엣지가 동시에 animated 상태 | 현재 단계 활성 엣지만 애니메이션 적용 |
| 콘텐츠 안전성 | 공격 절차가 너무 구체화될 위험 | 방어 교육 중심, 공격 코드/명령어 금지 |
| 제작자 검수 누락 | LLM 생성 결과가 부정확할 수 있음 | 관리자 검수 단계 필수화 |

## 12. 성공 기준

- 시나리오 입력 후 1분 이내에 시각화 초안 생성
- 콘텐츠 제작자가 30분 이내에 하나의 시나리오 검수·수정 가능
- 수강생이 각 단계에서 어떤 인프라가 사용되는지 즉시 이해 가능
- 최소 10개 이상의 시나리오를 동일 구조로 생성 가능
- 시나리오별 노드 20~80개 규모에서 부드러운 조작 가능
