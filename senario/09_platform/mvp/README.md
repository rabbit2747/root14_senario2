# APT Scenario Platform MVP

이 폴더는 Orion Echo V2 Practical 3D MVP 기준 작업 공간이다.

현재 기준 화면:

```text
http://localhost:3100/three/orion_2
```

실행:

```bash
npm run dev
```

빌드 검증:

```bash
npm run build
```
