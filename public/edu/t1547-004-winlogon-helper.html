T1547.004: Winlogon Helper DLL

Persistence

Winlogon Helper DLL

로그인 프로세스에 악성 DLL 주입 — SYSTEM 권한 자동 실행

#1. Winlogon Helper란?

🔐 ➜ 📦 ➜ 🔄 ➜ 💀

"로그인 문지기를 매수하기"

Winlogon은 Windows 로그인/로그아웃을 담당하는 핵심 시스템 프로세스입니다. Winlogon은 로그인 시 특정 DLL(Helper DLL)을 로드하는데, 공격자는 이 레지스트리 값을 수정하여 악성 DLL이 SYSTEM 권한으로 자동 로드되게 합니다.

주요 레지스트리 값

# Shell - 로그인 후 실행할 프로그램 (기본값: explorer.exe)
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Shell
# Userinit - 로그인 초기화 프로그램 (기본값: userinit.exe)
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Userinit
# Notify - 로그인 이벤트 알림 DLL (레거시, 여전히 악용 가능)
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon\Notify

왜 특히 위험한가?

SYSTEM 권한 실행

Winlogon은 SYSTEM 권한으로 실행되므로 로드되는 DLL도 최고 권한을 가집니다.

탐지 어려움

정상적인 시스템 프로세스 내에서 실행되어 프로세스 기반 탐지가 어렵습니다.

#2. 공격 기법 분석

Shell 값 변조

Shell 값에 악성 프로그램을 추가하여 explorer.exe와 함께 실행시킵니다.

# Shell 값에 악성 바이너리 추가
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
  /v Shell /t REG_SZ
  /d "explorer.exe, C:\Windows\Temp\svchost.exe" /f

Userinit 값 변조

Userinit 체인에 악성 프로그램을 끼워넣어 로그인 초기화 시 실행합니다.

# Userinit 체인에 악성 바이너리 삽입
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon"
  /v Userinit /t REG_SZ
  /d "C:\Windows\system32\userinit.exe,C:\Windows\Temp\updater.exe," /f

탐지 및 방어 전략

🛡️

Winlogon 레지스트리 모니터링: Shell, Userinit 값의 변경을 Sysmon Event ID 13으로 실시간 감지

🛡️

기본값 무결성 검증: Shell은 "explorer.exe", Userinit은 "userinit.exe,"만 포함해야 합니다

🛡️

DLL 서명 검증: Winlogon이 로드하는 DLL의 디지털 서명을 확인하여 비정상 모듈 탐지
