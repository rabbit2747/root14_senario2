Spearphishing Link

표적 맞춤형 이메일에 악성 URL을 삽입하여 초기 침투

#1. 스피어피싱 링크란?

"맞춤형 미끼" 비유

특정 물고기(표적)가 좋아하는 미끼(링크)를 만들어 낚시하는 것입니다. 일반 스팸(대량 피싱)과 달리, 피해자의 이름, 직위, 업무 내용을 조사하여 신뢰할 수 있는 이메일을 작성합니다. 링크는 자격증명 탈취 페이지, 악성코드 다운로드, OAuth 토큰 탈취 등으로 연결됩니다.

자격증명 탈취

가짜 로그인 페이지로 유도하여 ID/PW 수집

악성코드 전달

드라이브바이 다운로드 또는 HTML Smuggling

OAuth 토큰 탈취

악성 앱 권한 동의로 이메일/파일 접근

#2. 공격 기법

# GoPhish를 사용한 스피어피싱 캠페인 설정
From: it-support@c0rp-security.com
To: jsmith@corp.local
Subject: [긴급] 비밀번호 만료 안내 - 24시간 내 변경 필요
Body: 안녕하세요 김과장님, 보안 정책에 따라...
Link: https://corp-security-update.evil.com/reset
# corp → c0rp (숫자 0), 유사 도메인

방어 방법

  • DMARC/SPF/DKIM: 이메일 출처 인증으로 스푸핑 차단
  • URL 필터링: 새로 생성된 도메인 차단
  • MFA: 자격증명 탈취 후에도 접근 차단
  • 피싱 시뮬레이션: 정기적인 직원 교육
  • Safe Links: 클릭 시 URL 실시간 검사
