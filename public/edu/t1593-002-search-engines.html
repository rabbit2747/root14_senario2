T1593.002: 검색 엔진 정찰

Reconnaissance

검색 엔진 정찰

구글에 올바른 질문을 하면 비밀번호도 나온다 — 구글 도킹의 세계

#1. 구글 도킹이란?

🔍 ➜ 🎯 ➜ 📄 ➜ 🔓

"site:company.com filetype:pdf confidential"

구글 도킹(Google Dorking)은 검색 엔진의 고급 검색 연산자를 활용하여 의도치 않게 공개된 민감한 정보를 찾는 기법입니다. 관리자 로그인 페이지, 설정 파일, 비밀번호가 포함된 문서, 데이터베이스 백업 등을 검색할 수 있습니다.

주요 검색 연산자

site:company.com → 특정 도메인 내 검색
filetype:pdf → 특정 파일 형식 검색
intitle:"index of" → 디렉토리 리스팅 검색
inurl:admin → URL에 admin 포함 페이지
intext:"password" → 본문에 password 포함

#2. 실전 도킹 쿼리 예시

위험한 도킹 쿼리들

# 노출된 관리자 페이지 검색
site:company.com inurl:admin OR inurl:login
# 설정 파일 노출 검색
site:company.com filetype:env OR filetype:ini OR filetype:conf
# 백업 파일 검색
site:company.com filetype:sql OR filetype:bak
# 디렉토리 리스팅 검색
site:company.com intitle:"index of" "parent directory"

방어 전략

  • ● robots.txt로 민감한 경로 크롤링 차단
  • ● 정기적으로 자사 도메인에 대한 도킹 검사 수행
  • ● 민감한 파일을 웹 접근 가능 경로에 두지 않기
  • ● 관리자 페이지에 IP 화이트리스트 적용
