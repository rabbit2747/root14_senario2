Scanning IP Blocks

아파트 단지 전체의 초인종을 하나씩 눌러보는 방문판매원 — IP 블록 스캐닝의 세계

#1. IP 블록 스캐닝이란?

🏘️ ➜ 🚪 ➜ 🔔 ➜ 📋

"아파트 단지 전체를 돌아다니는 방문판매원"

방문판매원이 아파트 단지의 모든 호수를 돌며 초인종을 누르듯, 공격자는 특정 IP 대역(예: 192.168.1.0/24)의 모든 주소를 하나씩 확인합니다. 누가 사는지(어떤 서버가 있는지), 집에 있는지(온라인 상태인지), 문이 열려 있는지(포트가 열려 있는지)를 파악합니다.

🌐 ➜ 📊 ➜ 🎯 ➜ 💻

"IP 주소 체계 이해하기"

IP 주소는 인터넷의 '주소'입니다. CIDR 표기법(예: 10.0.0.0/8)을 사용하면 수백만 개의 IP를 한 번에 지정할 수 있습니다. /24는 256개, /16은 65,536개, /8은 약 1,677만 개의 IP를 포함합니다. 공격자는 목표 조직이 소유한 IP 블록 전체를 스캔합니다.

#2. 스캐닝 기법 심층 분석

IP 블록 스캐닝에는 다양한 기법이 사용됩니다. 각 기법의 원리와 탐지 방법을 살펴봅니다.

ICMP Ping Sweep

가장 기본적인 방법으로, ICMP Echo Request를 보내 응답이 오는 호스트를 식별합니다.

$ nmap -sn 192.168.1.0/24
Nmap scan report for 192.168.1.1
Host is up (0.0015s latency).
Nmap scan report for 192.168.1.10
Host is up (0.0023s latency).
Nmap done: 256 IP addresses (12 hosts up) scanned in 2.84 seconds

TCP SYN Sweep

ICMP가 차단된 환경에서 TCP SYN 패킷으로 호스트 존재를 확인합니다.

$ masscan 10.0.0.0/8 -p80,443 --rate=100000
Discovered open port 80/tcp on 10.0.1.15
Discovered open port 443/tcp on 10.0.2.30
Discovered open port 80/tcp on 10.0.5.100
rate: 100000.00-kpps, 98.12% done, 0:00:45 remaining

탐지 시그니처

  • ● 네트워크 플로우: 단일 소스에서 순차적 IP로 향하는 대량 트래픽
  • ● 방화벽 로그: 짧은 시간 내 수백~수천 개의 연결 시도
  • ● IDS 규칙: Snort/Suricata의 포트 스캔 탐지 시그니처 매칭
