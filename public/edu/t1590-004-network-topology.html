#1. 네트워크 토폴로지란?

🗺️ ➜ 🔀 ➜ 🏢 ➜ 📡

"네트워크의 지하철 노선도"

네트워크 토폴로지는 장치들이 어떻게 연결되어 있는지를 나타내는 '네트워크 지도'입니다. 라우터, 스위치, 방화벽, 서버가 어떻게 연결되고, 데이터가 어떤 경로로 흐르는지 보여줍니다. 공격자는 이 지도를 확보하여 방화벽을 우회하고 내부 네트워크로 이동하는 최적 경로를 찾습니다.

🌐 ➜ 🔀 ➜ 🛡️ ➜ 💻

"토폴로지로 알 수 있는 것들"

네트워크 세그먼트(DMZ, 내부망, 관리망 분리), 라우팅 경로(데이터 흐름), 방화벽 위치(보안 경계), 단일 장애점(SPOF), 병목 구간을 파악할 수 있습니다. 이 정보는 공격 경로 계획에 핵심적입니다.

토폴로지 정찰 도구

#2. Traceroute와 네트워크 매핑

Traceroute는 패킷이 목적지까지 거치는 모든 '중간 정류장'(라우터)을 보여줍니다. 이를 통해 네트워크의 계층 구조와 방화벽 위치를 파악할 수 있습니다.

Traceroute 결과 분석

$ traceroute target.example-corp.com
 1  gateway (192.168.1.1)      1.234 ms
 2  isp-router (10.0.0.1)      5.678 ms
 3  core-sw1 (172.16.0.1)      8.901 ms
 4  fw-external (172.16.1.1)  12.345 ms  ← 외부 방화벽
 5  dmz-router (172.16.2.1)   15.678 ms  ← DMZ 영역
 6  fw-internal (172.16.3.1)  18.901 ms  ← 내부 방화벽
 7  target (10.0.1.50)        22.345 ms  ← 타겟 서버

Traceroute에서 읽는 보안 구조

  • Hop 4 (fw-external): 외부 방화벽 위치 파악 → 방화벽 규칙 우회 시도의 시작점
  • Hop 5 (dmz-router): DMZ 존재 확인 → 웹서버/메일서버 위치
  • Hop 6 (fw-internal): 내부 방화벽 → DMZ와 내부망 사이의 보안 경계
  • RTT 증가 패턴: 방화벽에서 지연이 크면 패킷 검사(DPI)를 수행 중

방어: ICMP 필터링과 토폴로지 은닉

방화벽에서 ICMP TTL Exceeded 메시지를 차단하면 traceroute로 내부 구조를 파악하기 어렵습니다. 또한 네트워크 장비의 호스트명에서 역할 정보(fw-, dmz-, db- 등)를 제거하여 정보 노출을 줄여야 합니다.
