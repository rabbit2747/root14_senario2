Initial Access

Cloud Accounts

클라우드 IAM 계정 탈취, STS 토큰 남용, 서비스 계정 키 악용

#1. 개념과 원리

클라우드 계정 악용이란?

AWS, Azure, GCP 등 클라우드 플랫폼의 IAM 계정을 탈취하여 클라우드 인프라에 접근합니다. 유출된 Access Key, 서비스 계정 JSON 키, STS 임시 토큰 등을 악용합니다. MFA 미설정 계정이 주요 타겟이며, GitHub 등에서 실수로 커밋된 키를 수집합니다.

Access Key 유출

GitHub, .env, 설정 파일에서 키 수집

STS 토큰 남용

임시 자격증명으로 권한 상승

서비스 계정 키

GCP SA 키, Azure SP로 자동화 접근

#2. 공격 기법 분석

# GitHub에서 유출된 AWS 키 활용
export AWS_ACCESS_KEY_ID=AKIAIOSFODNN7EXAMPLE
export AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
aws sts get-caller-identity
# 클라우드 자원 열거
aws s3 ls
aws ec2 describe-instances --region us-east-1

공격 분석

  • 키 유출: GitHub 커밋, .env, Docker 이미지 내 하드코딩
  • STS AssumeRole: 임시 토큰으로 권한 상승 (Cross-Account)
  • 메타데이터 서비스: EC2 169.254.169.254에서 IAM 역할 토큰 탈취
  • 서비스 계정: GCP SA JSON 키로 영구 접근

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • MFA 필수: 모든 IAM 사용자에 MFA 적용
  • 키 순환: Access Key 90일 이내 자동 순환
  • IMDSv2: EC2 메타데이터 서비스 v2 강제 (토큰 기반)
  • CloudTrail: 모든 API 호출 감사 로깅
  • SCPs: Service Control Policies로 권한 경계 설정
