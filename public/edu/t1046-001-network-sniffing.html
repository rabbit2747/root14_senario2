Network Sniffing

네트워크 트래픽 캡처를 통한 자격 증명 및 정보 수집

#1. Network Sniffing이란?

🌐 ➜ 📡 ➜ 📋 ➜ 🔓

"네트워크 트래픽에서 민감 정보를 가로채기"

공격자는 tcpdump, Wireshark, pktmon 등의 도구로 네트워크 인터페이스를 모니터링하여 평문 자격 증명, 세션 토큰, 내부 통신 패턴을 수집합니다.

주요 스니핑 도구

# Linux
tcpdump -i eth0 -w capture.pcap
tshark -i eth0 -f "port 80 or port 21"
# Windows
pktmon start --capture --comp nics
netsh trace start capture=yes

왜 위험한가?

평문 자격 증명 수집

FTP, Telnet, HTTP 등 암호화되지 않은 프로토콜의 비밀번호를 캡처합니다.

내부 통신 패턴 분석

네트워크 구조, 서버 위치, 통신 패턴을 분석하여 추가 공격에 활용합니다.

#2. 공격 기법 분석

평문 프로토콜 자격 증명 수집

FTP, HTTP, Telnet 등 평문 프로토콜의 자격 증명을 캡처합니다.

# FTP 자격 증명 필터
tcpdump -i eth0 port 21 -A | grep -i "USER\|PASS"

# HTTP 폼 데이터 캡처
tcpdump -i eth0 port 80 -A | grep -i "password\|login"

탐지 및 방어 전략

🛡️

암호화 강제: 모든 통신에 TLS/SSL 적용, 평문 프로토콜(FTP, Telnet) 비활성화

🛡️

프로미스큐어스 모드 탐지: 네트워크 인터페이스의 프로미스큐어스 모드 활성화 감시

🛡️

네트워크 세그멘테이션: 민감한 트래픽을 별도 VLAN으로 격리
