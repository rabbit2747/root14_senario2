사장님 이름으로 온 가짜 청구서 — 위장 이메일 첨부파일 공격

#1. 스피어피싱이란?

📧 ➜ 🎯 ➜ 📎 ➜ 💥

"사장님 이름으로 온 가짜 청구서"

일반 피싱(Phishing)은 수천 명에게 같은 이메일을 뿌리는 "그물 던지기"입니다. 반면 스피어피싱(Spearphishing)은 특정 인물을 겨냥한 "작살 던지기"입니다. 공격자는 타깃의 이름, 직책, 거래처 정보를 사전에 조사한 뒤, 실제 업무 이메일처럼 위장한 메일에 악성 첨부파일을 넣어 보냅니다.

일반 피싱 vs 스피어피싱 비교

구분 일반 피싱 스피어피싱
대상 불특정 다수 (수천~수만 명) 특정 개인 또는 조직
내용 "계정 정지됨" 등 일반적 문구 실제 거래처/동료 이름 포함
성공률 매우 낮음 (~3%) 매우 높음 (~30%+)
준비시간 수 분 수 일~수 주 (OSINT)

실제 사례: 2020년 국내 방산업체 공격

공격자는 방산업체 직원에게 "연봉 협상 안내문.docx"라는 제목의 이메일을 발송했습니다. Word 문서를 열면 매크로가 실행되어 원격 접속 도구(RAT)가 설치되었고, 수 개월간 기밀 문서가 유출되었습니다.

#2. 첨부파일 공격 기법

공격자가 이메일에 첨부하는 악성 파일은 다양한 형태로 위장됩니다. 대표적인 3가지 기법을 알아봅니다.

📄

매크로 문서 (.docm)

Word/Excel 파일에 VBA 매크로를 삽입합니다. 문서를 열면 "콘텐츠 사용" 버튼 클릭을 유도하고, 클릭 시 악성 코드가 자동 실행됩니다.

Sub AutoOpen()
  Shell "powershell -enc JABj..."
End Sub
🌐

HTA 파일 (.hta)

HTML Application 파일은 브라우저가 아닌 mshta.exe로 실행되어 로컬 시스템 권한으로 코드를 실행할 수 있습니다. HTML로 위장하지만 실제로는 시스템 명령을 실행합니다.

<script language="VBScript">
  Set s = CreateObject("WScript.Shell")
  s.Run "cmd /c ..."
</script>
💿

ISO/IMG 파일

디스크 이미지 파일(.iso)은 Windows에서 더블클릭하면 가상 드라이브로 마운트됩니다. MOTW(Mark of the Web)를 우회할 수 있어 최근 공격에 많이 활용됩니다.

invoice.iso 내부:
├── invoice.lnk (바로가기)
└── payload.dll (숨김파일)

공격 흐름도 (Kill Chain)

OSINT 수집 → 이메일 위장 → 첨부파일 발송 → 사용자 실행 → 시스템 침투
