#1. 위협 인텔리전스(TI)란?

"사이버 보안의 정보국"

위협 인텔리전스(Threat Intelligence)는 사이버 위협에 대한 정보를 수집, 분석, 공유하는 활동입니다. Recorded Future, Mandiant, CrowdStrike, VirusTotal 같은 벤더들이 대표적입니다. 이들은 악성코드 샘플, IoC(침해 지표), 공격 그룹 프로파일, 취약점 분석 보고서를 제공합니다.

TI 벤더가 제공하는 정보

IoC (침해 지표)
악성 IP, 도메인, 해시값 등 침해의 흔적
TTP (전술/기법/절차)
공격 그룹의 행동 패턴과 사용 도구
취약점 보고서
CVE 분석, 익스플로잇 코드, 패치 정보
산업별 위협 동향
특정 산업을 겨냥한 공격 캠페인 정보

#2. 공격자의 TI 활용법

공격자도 방어자와 동일한 TI 벤더 서비스를 구독하거나, 공개 보고서를 분석하여 방어 체계의 빈틈을 찾습니다.

탐지 규칙 우회

TI 보고서에 공개된 YARA 규칙, Sigma 규칙을 분석하여 탐지를 우회하도록 악성코드를 수정합니다.

$ cat yara_rule.yar
rule APT_Backdoor { ... }
→ 시그니처 변경으로 우회

방어 솔루션 파악

대상 조직이 사용하는 보안 솔루션(EDR, SIEM, WAF)을 TI 보고서나 채용 공고에서 파악합니다.

# 채용 공고 분석
"CrowdStrike Falcon 운영 경험"
→ EDR: CrowdStrike 확인

패치 갭 공략

취약점 보고서 공개와 실제 패치 적용 사이의 시간차를 노려 익스플로잇을 실행합니다.

# CVE 공개 후 72시간
CVE-2025-XXXX → PoC 공개
→ 미패치 서버 스캔 시작

실제 사례: APT 그룹의 TI 역이용

  • ● APT29: 보안 벤더 보고서 발행 후 48시간 내에 C2 인프라를 교체
  • ● Lazarus: VirusTotal에 새 샘플이 업로드되면 자동으로 변종 생성
  • ● FIN7: 보안 컨퍼런스 발표 자료에서 방어 전략을 역분석

#3. 방어 전략

TI 정보 공개 범위 제한

자사가 사용하는 보안 솔루션, 탐지 규칙, 네트워크 아키텍처 정보를 외부에 불필요하게 노출하지 않아야 합니다. 채용 공고에 구체적인 제품명 대신 "EDR 운영 경험" 같은 일반적 표현을 사용합니다.

다층 방어(Defense in Depth)

하나의 탐지 규칙이 우회되더라도 행위 기반 탐지, 이상 행위 분석, 네트워크 세그멘테이션 등 다중 방어 계층으로 대응합니다. TI에 의존하지 않는 행위 기반 탐지(UEBA)가 핵심입니다.
