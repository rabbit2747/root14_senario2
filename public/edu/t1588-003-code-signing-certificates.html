T1588.003
코드서명 인증서 획득

공격자가 코드서명 인증서를 탈취하거나 구매하여 악성코드에 신뢰성을 부여하는 기법을 학습합니다.

🔏 Chapter 1 — 코드서명 개요

코드서명이란?

코드서명은 소프트웨어 개발자가 자신의 신원을 인증하고, 코드가 변조되지 않았음을 보증하는 디지털 서명 기술입니다. Windows SmartScreen, macOS Gatekeeper 등 운영체제 보안 기능은 서명된 소프트웨어를 더 신뢰합니다.

정상 코드서명 프로세스
  • 1. CA(인증기관)에 사업자 등록증 제출
  • 2. 신원 확인 후 코드서명 인증서 발급
  • 3. 개인키로 실행 파일에 서명
  • 4. OS가 서명을 검증하여 신뢰 표시
공격자의 악용 방법
  • • 합법 기업의 인증서를 해킹으로 탈취
  • • 다크웹에서 도난된 인증서 구매
  • • 위장 회사 설립 후 직접 인증서 신청
  • • 만료/폐기된 인증서로 타임스탬프 악용

# 서명된 악성코드의 인증서 정보 확인

$ sigcheck -a malware_signed.exe

Company: GlobalTech Solutions Ltd.

🔓 Chapter 2 — 인증서 탈취 기법

실제 공격 사례

1. 소프트웨어 회사 해킹

빌드 서버나 CI/CD 파이프라인을 침해하여 코드서명용 개인키(.pfx, .p12)를 탈취합니다. SolarWinds 공급망 공격에서 이 방법이 사용되었습니다.

2. 다크웹 인증서 거래

EV(Extended Validation) 코드서명 인증서가 $1,000~$5,000에 거래됩니다. SmartScreen 우회가 가능한 EV 인증서가 더 높은 가격에 판매됩니다.

3. 위장 회사 설립

명목상의 법인을 설립하고 CA에 코드서명 인증서를 합법적으로 신청합니다. Lazarus 그룹이 이 방법을 사용한 것으로 알려져 있습니다.

# 탈취된 PFX 인증서로 악성코드 서명

$ signtool sign /f stolen_cert.pfx /p "P@ssw0rd" /t http://timestamp.digicert.com /fd sha256 payload.exe

Done Adding Additional Store

Successfully signed: payload.exe

$ sigcheck payload.exe

Verified: Signed

Publisher: "Legit Software Corp."

탐지 방법

  • • CI/CD 파이프라인에서 서명 프로세스 분리
