T1498.001: Direct Network Flood

Impact

DDoS

가게 앞에 수천 명이 줄 서서 진짜 손님 못 들어오게 하기 — DDoS

#1. DDoS란?

🏪 ➜ 👥👥👥 ➜ 🚫 ➜ 😱

"가게 앞에 수천 명이 줄 서서 진짜 손님 못 들어오게 하기"

작은 빵집에 갑자기 수천 명의 가짜 손님이 몰려와 줄을 섭니다. 진짜 손님은 가게에 들어갈 수 없고, 결국 영업을 못 합니다. DDoS(Distributed Denial of Service)는 수많은 감염 PC(봇넷)에서 동시에 대량의 트래픽을 보내 서버를 마비시키는 공격입니다.

DDoS의 목적

서비스를 마비시키는 것 자체가 목적입니다. 경쟁사 방해, 정치적 보복, 협박(DDoS 중단 대가 요구), 다른 공격의 연막 등 다양한 동기가 있습니다.

🤖
봇넷 (Botnet)
수만~수십만 대의 감염 PC/IoT 기기 동원
📈
Tbps 규모
최대 수 Tbps의 공격 트래픽 가능
💰
피해 규모
서비스 중단 시 시간당 수천만원 손실

#2. SYN Flood, UDP Flood, Amplification

SYN Flood

TCP 3-Way Handshake의 SYN만 보내고 ACK를 보내지 않음. 서버의 연결 대기 테이블을 가득 채움

UDP Flood

랜덤 포트로 대량의 UDP 패킷 전송. 서버가 각 패킷에 ICMP Unreachable 응답 시 과부하

Amplification

DNS/NTP 서버에 위조된 IP(피해자)로 요청. 작은 요청이 수십 배 큰 응답으로 증폭되어 피해자에게 전달

# SYN Flood 시 서버 상태 (개념)
netstat -an | grep SYN_RECV
tcp 0 0 192.168.1.1:80 10.0.0.1:12345 SYN_RECV
tcp 0 0 192.168.1.1:80 10.0.0.2:23456 SYN_RECV
tcp 0 0 192.168.1.1:80 10.0.0.3:34567 SYN_RECV
... 수만 개의 SYN_RECV 연결 → 서버 연결 테이블 포화
