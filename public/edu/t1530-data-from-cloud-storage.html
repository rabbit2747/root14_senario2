탈취한 자격증명으로 S3, Azure Blob, GCS에서 기밀 데이터를 수집

#1. 클라우드 스토리지 데이터 수집이란?

☁️ ➜ 🔑 ➜ 📥 ➜ 💀

"클라우드 금고의 열쇠를 훔치다"

기업들이 AWS S3, Azure Blob Storage, Google Cloud Storage에 중요 데이터를 저장합니다. 공격자는 탈취한 API 키, IAM 자격증명, 또는 잘못 설정된 접근 권한을 이용해 이 데이터를 대량으로 다운로드합니다.

왜 클라우드 스토리지가 표적인가?

클라우드에는 백업, 데이터베이스 덤프, 로그, 고객 데이터가 집중됩니다. 공개 버킷 설정 오류나 과도한 IAM 권한이 있으면, 공격자는 네트워크 침투 없이도 직접 클라우드에서 데이터를 가져올 수 있습니다.

#2. 공격 기법 분석

공개 버킷 스캐닝

공격자는 자동화 도구로 공개 접근이 허용된 S3 버킷을 스캔합니다. 기업명, 프로젝트명으로 버킷 이름을 추측하여 접근 가능한 버킷을 찾아냅니다.

탈취 키로 API 호출

GitHub 커밋, 환경변수, 설정 파일에서 AWS Access Key/Secret Key를 발견하면 AWS CLI로 직접 S3 버킷의 파일을 나열하고 다운로드합니다.

실전 시나리오: AWS S3 대량 다운로드

공격자가 GitHub에서 발견한 AWS 키로 S3 버킷에 접근하여 고객 데이터를 대량으로 다운로드하는 시나리오입니다.

# 탈취된 AWS 키로 S3 버킷 조회
aws s3 ls s3://company-backup-prod/ --profile stolen
2026-02-28 03:00:00 2.1GB db-backup-20260228.sql.gz
2026-02-27 03:00:00 1.8GB customer-data-export.csv
2026-02-25 12:00:00 450MB internal-docs.tar.gz
