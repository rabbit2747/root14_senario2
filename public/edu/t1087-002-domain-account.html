#1. AD 계정 열거란?

"회사 전화번호부에서 VIP 뽑기"

회사에 입사하면 직원 전화번호부를 받습니다. 여기엔 모든 직원의 이름, 부서, 직급이 적혀 있죠. 공격자는 이 전화번호부(Active Directory)에서 '관리자', '서버담당', 'DBA' 같은 높은 권한을 가진 VIP 계정만 골라냅니다.

기본 명령어: net user /domain

AD에 가입된 아무 PC에서 관리자 권한 없이도 실행할 수 있는 기본 Windows 명령어입니다.

C:\> net user /domain
사용자 계정
------------------------------------------
Administrator alice.kim bob.park
svc_backup svc_sql domain.admin
# svc_ 접두사 = 서비스 계정 → 공격자의 주요 타겟!

왜 위험한가?

계정 목록만 확보하면 Password Spraying(흔한 비밀번호로 모든 계정에 시도), Kerberoasting(서비스 계정 해시 탈취) 등 후속 공격이 가능해집니다.

#2. LDAP 쿼리 & PowerView

LDAP 쿼리

LDAP(Lightweight Directory Access Protocol)은 AD의 데이터를 검색하는 표준 프로토콜입니다.

(&(objectCategory=person)
 (objectClass=user)
 (adminCount=1))

adminCount=1 → 관리자 권한을 가진 계정만 필터링

PowerView

PowerShell 기반의 AD 정보 수집 도구로, 한 줄의 명령어로 강력한 열거가 가능합니다.

PS> Get-DomainUser -AdminCount
PS> Get-DomainUser -SPN
# SPN 설정된 계정 = Kerberoasting 대상
