T1562.004: Disable System Firewall

Defense Evasion

Disable System Firewall

시스템 방화벽을 비활성화하거나 규칙을 수정하여 C2 통신을 허용

#1. 방화벽 비활성화란?

"성문 열기" 비유

성벽(방화벽)의 문을 열어놓거나, 새로운 비밀 통로(규칙)를 만드는 것입니다. 공격자는 C2 통신, 횡적 이동, 데이터 유출을 위해 방화벽을 비활성화하거나, 특정 포트/프로그램을 허용하는 규칙을 추가합니다.

Windows

  • netsh advfirewall set allprofiles state off
  • New-NetFirewallRule -Action Allow
  • iptables -F (Linux)

Linux

  • iptables -F (모든 규칙 삭제)
  • ufw disable
  • systemctl stop firewalld

#2. 공격 기법

# 은밀한 방화벽 규칙 추가
netsh advfirewall firewall add rule name="Windows Update"
dir=in action=allow protocol=TCP localport=4444
# "Windows Update"로 위장한 C2 포트 허용 규칙

방어 방법

  • GPO: 방화벽 비활성화 차단 정책
  • Event ID 2003: 방화벽 설정 변경 이벤트
  • 규칙 감사: 정기적으로 방화벽 규칙 검토
  • Network Segmentation: 방화벽 우회해도 세그먼트 제한
