T1546.010: AppInit DLLs

Persistence

AppInit DLLs

레지스트리 AppInit_DLLs 값을 이용한 DLL 인젝션 지속성

#1. AppInit DLLs란?

🪟 ➜ 📝 ➜ 📦 ➜ 💉

"모든 GUI 프로세스에 DLL을 강제 로드"

Windows는 AppInit_DLLs 레지스트리 값에 지정된 DLL을 User32.dll을 로드하는 모든 프로세스에 자동 주입합니다. 공격자는 이 메커니즘을 악용하여 악성 DLL을 모든 GUI 애플리케이션에 로드시킬 수 있습니다.

관련 레지스트리 경로

# 32비트 프로세스
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows\AppInit_DLLs
# 64비트 시스템의 32비트 프로세스 (WoW64)
HKLM\SOFTWARE\Wow6432Node\Microsoft\Windows NT\CurrentVersion\Windows\AppInit_DLLs
# 활성화 플래그
LoadAppInit_DLLs = 1 (DWORD)

왜 위험한가?

광범위한 영향

User32.dll을 로드하는 모든 프로세스에 DLL이 주입되어 매우 넓은 공격 범위를 가집니다.

부팅 시 자동 활성화

시스템 재시작 후에도 모든 GUI 프로세스에 자동으로 DLL이 로드됩니다.

#2. 공격 기법 분석

AppInit DLLs 레지스트리 설정

악성 DLL 경로를 AppInit_DLLs에 등록하고 LoadAppInit_DLLs를 활성화합니다.

# 악성 DLL 등록 및 활성화
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows" /v AppInit_DLLs /t REG_SZ /d "C:\Windows\System32\evil.dll" /f
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Windows" /v LoadAppInit_DLLs /t REG_DWORD /d 1 /f

공격 흐름

1.

DLL 배치: 악성 DLL을 System32 등 신뢰 경로에 복사

2.

레지스트리 수정: AppInit_DLLs에 경로 등록, LoadAppInit_DLLs 활성화

3.

자동 주입: 이후 실행되는 모든 GUI 프로세스에 DLL 로드

탐지 및 방어 전략

🛡️

Secure Boot 활성화: Windows 10+에서 Secure Boot 시 AppInit DLLs가 비활성화됩니다.

🛡️

레지스트리 모니터링: AppInit_DLLs 및 LoadAppInit_DLLs 값 변경을 실시간 감시합니다.

🛡️

코드 서명 요구: RequireSignedAppInit_DLLs=1로 서명된 DLL만 허용합니다.
