#1. 소프트웨어 정보 수집이란?

💻 ➜ 📋 ➜ 🔓 ➜ 🎯

"어떤 자물쇠가 달려 있는지 파악하기"

공격자는 대상의 운영체제, 웹 서버, 데이터베이스, CMS 등 소프트웨어 스택을 파악합니다. 각 소프트웨어의 정확한 버전을 알면 알려진 취약점(CVE)을 매칭하여 맞춤형 공격을 준비할 수 있습니다.

"수집 방법"

HTTP 응답 헤더(Server, X-Powered-By), HTML 메타 태그(generator), JavaScript 라이브러리 버전, 에러 페이지의 스택 트레이스 등에서 소프트웨어 정보가 유출됩니다.

수집 대상 소프트웨어 정보

🖥️
OS & Kernel
Windows/Linux 버전
🌐
Web Stack
Apache, PHP, WordPress
🛡️
Security SW
AV, EDR, WAF 제품

#2. 기술 심층 분석

HTTP 헤더에서 소프트웨어 식별

$ curl -sI https://target.com | grep -iE "server|x-powered|x-aspnet"
Server: Apache/2.4.41 (Ubuntu)
X-Powered-By: PHP/8.1.2
X-Generator: WordPress 6.4.2

Wappalyzer 기반 기술 스택 분석

$ whatweb -a 3 https://target.com
https://target.com [200 OK]
Apache[2.4.41], Bootstrap[5.3], jQuery[3.7.1],
PHP[8.1.2], WordPress[6.4.2], MySQL
Yoast SEO[21.6], WooCommerce[8.4.0]

위험 포인트

  • ●버전 정보 노출: 정확한 소프트웨어 버전은 CVE 매칭의 핵심 정보
  • ●에러 페이지: 디버그 모드 활성화 시 스택 트레이스에서 프레임워크/라이브러리 버전 노출
  • ●JavaScript 라이브러리: 프론트엔드 라이브러리 버전에서 XSS 등 취약점 식별

#Q. 종합 퀴즈

Q. 웹 서버의 소프트웨어 정보 노출을 줄이기 위한 가장 효과적인 방법은?
