T1056.002: GUI Input Capture

Credential Access

GUI Input Capture

가짜 로그인 대화상자로 자격 증명을 가로채는 공격

#1. GUI Input Capture란?

"가짜 은행 창구" 비유

진짜 은행 창구 앞에 완벽히 똑같은 가짜 창구를 세워놓고, 고객이 계좌번호와 비밀번호를 적도록 유도하는 것입니다. GUI Input Capture는 운영체제의 정상적인 로그인 대화상자를 모방하여 사용자가 의심 없이 자격 증명을 입력하게 만드는 공격입니다.

Fake UAC Prompt

관리자 권한 요청 대화상자 위조

Fake Login Dialog

Windows/macOS 로그인 화면 모방

Fake Browser Popup

브라우저 인증 팝업 위조

#2. 공격 기법

# PowerShell - Fake Credential Prompt (교육용)
$cred = $host.ui.PromptForCredential(
"Windows Security",
"Your session has expired. Please re-enter credentials.",
"$env:USERDOMAIN\$env:USERNAME",
""
)
# 사용자가 비밀번호를 입력하면 평문으로 획득
$plainPass = $cred.GetNetworkCredential().Password

AppleScript 변형 (macOS)

macOS에서는 osascript를 사용하여 시스템 환경설정과 동일한 인증 대화상자를 표시합니다. 사용자는 실제 시스템 요청과 구분할 수 없습니다.

방어 방법

  • UAC Secure Desktop: 진짜 UAC는 보안 데스크톱에서 실행 (Ctrl+Alt+Del 필요)
  • 프로세스 모니터링: PromptForCredential 호출 감시
  • 사용자 교육: 예상치 못한 인증 요청 의심하기
  • Application Whitelisting: 허가된 프로그램만 실행 가능
