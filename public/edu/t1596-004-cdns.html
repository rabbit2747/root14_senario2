#1. CDN이란 무엇인가?

🌐 ➜ 🛡️ ➜ 🖥️ ➜ 📦

"인터넷의 택배 물류 센터"

CDN(Content Delivery Network)은 전 세계에 분산된 서버 네트워크로, 사용자와 가까운 위치에서 웹 콘텐츠를 전달합니다. 마치 전국에 물류센터를 두고 가장 가까운 곳에서 택배를 보내는 것과 같습니다. Cloudflare, Akamai, AWS CloudFront 등이 대표적입니다.

🛡️ ➜ 🕵️ ➜ ❓ ➜ 🎯

"CDN이 숨기는 것 — Origin IP"

CDN은 실제 서버(Origin Server)의 IP를 숨기는 역할도 합니다. 공격자는 CDN을 식별한 후 Origin IP를 찾아야 실제 서버를 공격할 수 있습니다. 이를 위해 DNS 히스토리, 이메일 헤더, SSL 인증서 등 다양한 우회 기법을 사용합니다.

#2. CDN 정찰 기법

공격자는 CDN 뒤에 숨겨진 Origin IP를 찾기 위해 다양한 우회 기법을 사용합니다. CDN은 보안 방패 역할을 하지만, 설정 실수나 정보 유출을 통해 원본 서버가 노출될 수 있습니다.

DNS 히스토리

CDN 적용 이전의 DNS 기록에서 Origin IP를 찾습니다. SecurityTrails, ViewDNS 등을 활용합니다.

$ curl securitytrails.com/history
2023: 203.0.113.50 (Origin!)

이메일 헤더 분석

대상 도메인에서 발송된 이메일의 헤더에서 Origin IP가 노출될 수 있습니다.

Received: from mail.target.com
(203.0.113.50) ← Origin IP

Censys / Shodan

SSL 인증서 해시를 기반으로 같은 인증서를 사용하는 IP를 역추적합니다.

Certificate match: 2 IPs
203.0.113.50 (non-CDN)

Origin IP 노출이 위험한 이유

  • ● CDN의 WAF(웹 방화벽) 보호를 완전히 우회할 수 있음
  • ● DDoS 방어가 무력화되어 직접 공격 가능
  • ● Rate Limiting, Bot Protection 등 CDN 보안 기능 전부 무시
  • ● 서버 직접 접근으로 취약점 스캔 및 익스플로잇 가능
