DNS / Passive DNS

전화번호부를 뒤지면 모든 주소가 나온다 — DNS는 인터넷의 전화번호부

#1. DNS란 무엇인가?

📞 ➜ 📖 ➜ 🏠 ➜ 📍

"인터넷의 전화번호부"

전화번호부에서 이름을 찾으면 전화번호가 나오듯이, DNS(Domain Name System)는 도메인 이름(예: root14.co.kr)을 입력하면 실제 서버의 IP 주소(예: 123.45.67.89)를 알려주는 시스템입니다. 우리가 매일 웹사이트에 접속할 때 자동으로 DNS 조회가 일어납니다.

🕵️ ➜ 📖 ➜ 🗂️ ➜ 🗺️

"Passive DNS — 과거의 전화번호부까지 열람"

Passive DNS는 과거에 어떤 도메인이 어떤 IP를 사용했는지의 기록을 저장한 데이터베이스입니다. 마치 10년 전 전화번호부까지 보관하고 있는 도서관 같은 것이죠. 공격자는 이를 통해 숨겨진 서브도메인, 이전 서버 IP, 인프라 변경 이력을 파악합니다.

#2. 정찰 도구와 기법

공격자는 다양한 도구를 사용하여 대상 조직의 DNS 정보를 수집합니다. 이 정보는 서버 위치, 사용 중인 서비스, 보안 설정까지 드러낼 수 있습니다.

whois

도메인 소유자, 등록일, 네임서버 등의 등록 정보를 조회합니다.

$ whois root14.co.kr
Registrant: ROOT14 Inc.

dig / nslookup

특정 DNS 레코드를 직접 조회하여 IP, 메일서버, 네임서버를 확인합니다.

$ dig root14.co.kr A
ANSWER: 123.45.67.89

SecurityTrails

Passive DNS 이력, 서브도메인, IP 변경 기록을 제공하는 온라인 플랫폼입니다.

Subdomains found: 23
Historical IPs: 7

Passive DNS가 공격자에게 유용한 이유

  • ● 숨겨진 서브도메인(dev.company.com, staging.company.com) 발견
  • ● 이전 IP 주소로 패치되지 않은 구 서버 접근 가능
  • ● 호스팅 공급자, CDN, 보안 솔루션 파악 → 우회 전략 수립
  • ● 조직의 인프라 확장/축소 패턴 분석
