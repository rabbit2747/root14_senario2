기업 메일함에서 기밀 정보를 대량 수집하는 공격 기법

#1. 이메일 수집이란?

📧 ➜ 🔍 ➜ 📥 ➜ 💀

"메일함은 기업의 비밀 일기장"

이메일에는 계약서, 비밀번호, 내부 전략, 인사 정보 등 기업의 핵심 정보가 담겨 있습니다. 공격자는 Exchange Server, Outlook, Gmail 등에서 특정 키워드로 이메일을 검색하고 대량으로 수집합니다.

공격 방식의 다양성

로컬 Outlook PST 파일을 직접 복사하거나, Exchange Web Services(EWS) API로 원격 접근하거나, 메일 전달 규칙을 설정하여 지속적으로 이메일을 탈취할 수 있습니다.

📂
로컬 PST 파일
Outlook 데이터 파일 직접 복사
🌐
EWS/Graph API
API로 원격 메일 검색/다운로드
📨
메일 전달 규칙
자동 전달로 지속적 탈취

#2. 공격 기법 분석

PST/OST 파일 탈취

Outlook은 메일을 PST(개인 저장소) 또는 OST(오프라인 캐시) 파일에 저장합니다. 공격자는 이 파일을 통째로 복사하면 수년간의 이메일을 한 번에 획득합니다.

Exchange EWS 검색

Exchange Web Services API를 이용하면 "비밀번호", "계약", "VPN" 같은 키워드로 이메일을 검색하고, 첨부파일까지 한 번에 다운로드할 수 있습니다.

실전 예시: PowerShell EWS 접근

탈취한 자격증명으로 Exchange Web Services에 접근하여 특정 키워드가 포함된 이메일을 검색합니다.

# EWS를 이용한 이메일 검색
$ews = New-Object Microsoft.Exchange.WebServices.Data.ExchangeService
$search = "subject:비밀번호 OR subject:VPN OR subject:계약서"
$results = $ews.FindItems("Inbox", $search, $view)
# 검색 결과: 47건의 이메일 발견
