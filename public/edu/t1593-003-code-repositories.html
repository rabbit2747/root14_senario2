코드 저장소 검색

GitHub 커밋에 남긴 API 키가 해킹의 시작이 된다

#1. 코드 저장소 정찰이란?

💻 ➜ 🔍 ➜ 🔑 ➜ 💥

"git commit -m 'added AWS keys temporarily'"

공격자는 GitHub, GitLab, Bitbucket 등의 코드 저장소에서 대상 조직의 코드를 검색합니다. 개발자가 실수로 커밋한 API 키, 비밀번호, 인증 토큰, 내부 URL 등을 찾아 직접 시스템에 접근합니다. 커밋 히스토리에는 삭제된 시크릿도 남아 있습니다.

자주 유출되는 시크릿 유형

AWS_SECRET_ACCESS_KEY=wJalrXUtnFEMI/K7MDENG/...
GITHUB_TOKEN=ghp_xxxxxxxxxxxx
DATABASE_URL=postgres://admin:P@ssw0rd@db.company.com
SLACK_WEBHOOK=https://hooks.slack.com/services/T.../B.../...

#2. 시크릿 탐지 도구

TruffleHog

Git 히스토리에서 고엔트로피 문자열과 시크릿 패턴을 검색합니다.

GitLeaks

정규식 기반으로 API 키, 비밀번호 등 시크릿을 탐지합니다.

GitHub Secret Scanning

GitHub 내장 기능으로 알려진 시크릿 패턴을 자동 탐지합니다.

방어 전략

  • ● pre-commit hook으로 시크릿 커밋 방지
  • ● 환경 변수나 Vault를 사용하여 시크릿 관리
  • ● .gitignore에 .env, credentials 파일 추가
  • ● 시크릿 유출 시 즉시 키 로테이션
