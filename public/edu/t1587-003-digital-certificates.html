T1587.003
디지털 인증서 개발

공격자가 자체 SSL/TLS 인증서를 생성하거나 무료 CA를 활용하여 C2 통신 암호화 및 피싱 인프라를 구축하는 기법을 학습합니다.

🔒 Chapter 1 — 디지털 인증서 개요

디지털 인증서(SSL/TLS)는 웹 통신의 암호화와 서버 인증을 제공합니다. 공격자는 자체 인증서를 개발하여 C2 통신을 암호화하고, 피싱 사이트를 합법적으로 보이게 만듭니다. T1588.004(인증서 탈취)와 달리 직접 생성합니다.

인증서 생성 방법
  • - 자체 서명 (Self-signed) — OpenSSL
  • - 무료 CA — Let's Encrypt (자동 발급)
  • - 저가 DV 인증서 — 리셀러 구매
  • - 내부 CA 악용 — AD CS 공격
인증서 악용 목적
  • - C2 통신 HTTPS 암호화
  • - 피싱 사이트 자물쇠 아이콘 표시
  • - MitM 프록시 인증서
  • - Domain Fronting 인프라

⚡ Chapter 2 — 인증서 생성 및 활용

Let's Encrypt 자동 발급

Let's Encrypt는 도메인 소유권만 확인하면 무료로 SSL 인증서를 발급합니다. ACME 프로토콜로 완전히 자동화되어, 스크립트 하나로 수백 개의 C2 도메인에 인증서를 배포할 수 있습니다. 90일 자동 갱신으로 장기 운영도 가능합니다.

# 자체 서명 인증서 생성 — C2 내부 통신용

$ openssl req -x509 -newkey rsa:4096 -sha256 -days 365 \

-nodes -keyout c2_key.pem -out c2_cert.pem \

-subj "/CN=microsoft-update-service.com" \

-addext "subjectAltName=DNS:microsoft-update-service.com,DNS:*.microsoft-update-service.com"

Generating a RSA private key

writing new private key to 'c2_key.pem'

[+] Self-signed certificate created

[+] Valid for 365 days

[+] CN mimics Microsoft update service

피싱 사이트 인증서

사용자의 83%가 자물쇠 아이콘을 "안전한 사이트"로 인식합니다. 공격자는 Let's Encrypt로 피싱 사이트에 합법 인증서를 설치하여, 브라우저에 자물쇠 아이콘을 표시합니다. "https://microsofit-login[.]com"은 자물쇠가 있어도 피싱입니다.

자체 CA 구축 (Advanced)

고급 공격자는 자체 Root CA를 생성하여 다수의 C2 서버에 인증서를 발급합니다. 이 인증서는 공개 CA 인프라에 등록되지 않아 CT(Certificate Transparency) 로그에 남지 않습니다. 자체 임플란트가 이 CA를 신뢰하도록 하드코딩합니다.

🛡️ Chapter 3 — 탐지와 방어

인증서 모니터링
  • - CT 로그 모니터링 (crt.sh, Censys)
  • - 브랜드 유사 도메인 인증서 알림
  • - JA3/JA3S TLS 핑거프린트 분석
  • - 인증서 발급자/유효기간 이상 탐지
네트워크 방어
  • - SSL/TLS 검사 (복호화 + 재암호화)
  • - 자체 서명 인증서 차단 정책
  • - HSTS Preload List 활용
  • - Certificate Pinning (모바일 앱)
사용자 교육

자물쇠 아이콘은 "통신이 암호화되었다"는 의미이지, "사이트가 안전하다"는 의미가 아닙니다. 사용자에게 URL을 직접 확인하도록 교육하고, 의심스러운 사이트에서는 인증서 세부 정보(발급자, 유효기간, 도메인)를 확인하는 습관을 기르도록 합니다.
