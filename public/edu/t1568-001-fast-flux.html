Fast Flux DNS

IP 주소를 빠르게 순환하여 C2 서버 추적을 방해하는 기술

#1. Fast Flux DNS란?

🌐 ➜ 🔄 ➜ 🔄 ➜ 💀

"같은 도메인, 매번 다른 IP"

Fast Flux는 하나의 도메인에 대해 DNS A 레코드를 수초~수분 간격으로 변경하는 기법입니다. C2 도메인을 조회할 때마다 다른 IP가 반환되므로, 특정 IP를 차단해도 C2 통신이 유지됩니다. 주로 봇넷에 감염된 수백 대의 PC가 프록시 역할을 합니다.

왜 Fast Flux인가?

일반 C2 도메인은 IP 차단으로 무력화됩니다. Fast Flux는 수백 개 IP를 순환하므로 모든 IP를 차단하기 불가능합니다. 또한 매우 짧은 TTL(Time-To-Live, 60초 이하)을 설정하여 DNS 캐시를 무력화합니다.

⏱️

🤖

#2. Single Flux vs Double Flux

Single Flux

DNS A 레코드만 빠르게 변경합니다. 하나의 도메인이 여러 IP를 순환하며, 각 IP는 봇넷 노드입니다. 네임서버(NS)는 고정이므로 NS를 차단하면 무력화할 수 있습니다.

Double Flux

DNS A 레코드와 NS 레코드 모두 변경합니다. 네임서버 자체도 봇넷 노드에서 운영되므로, NS 차단으로도 무력화 불가합니다.

Fast Flux 네트워크 구조

3계층 구조: Mothership(실제 C2) → Tier-2 프록시 → Flux Agent(봇넷 노드)

# Fast Flux DNS 조회 (30초 간격)
dig c2.evil.com (T+0s) → 192.168.1.10 (TTL=60)
dig c2.evil.com (T+30s) → 10.20.30.40 (TTL=60)
dig c2.evil.com (T+60s) → 172.16.0.55 (TTL=60)
# 같은 도메인, 매번 다른 IP — 모두 봇넷 노드
