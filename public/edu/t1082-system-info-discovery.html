시스템 하드웨어, OS, 패치 수준 정보 수집

#1. System Info Discovery란?

💻 ➜ 📋 ➜ 🔍 ➜ 🎯

"시스템의 상세 정보를 수집"

공격자는 systeminfo, hostname, uname 등으로 OS 버전, 패치 수준, 하드웨어 정보, 도메인 멤버십을 수집합니다. 이를 통해 해당 환경에 맞는 익스플로잇과 공격 도구를 선택합니다.

주요 정보 수집 명령어

systeminfo
hostname
Get-ComputerInfo
wmic os get caption,version,buildnumber
uname -a # Linux

#2. 공격 기법 분석

패치 수준 확인

# 설치된 핫픽스 확인
wmic qfe list brief /format:table

# 시스템 상세 정보
systeminfo | findstr /B /C:"OS Name" /C:"OS Version" /C:"Hotfix(s)"

🛡️

명령 감사: systeminfo, wmic 등의 정보 수집 명령 실행을 Sysmon으로 모니터링

🛡️

패치 관리: 정기적인 보안 패치 적용으로 알려진 취약점 제거
