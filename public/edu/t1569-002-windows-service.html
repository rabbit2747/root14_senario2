T1569.002: Service Execution

Execution

Service Execution

Windows 서비스를 생성/수정하여 SYSTEM 권한으로 악성 코드 실행

#1. 개념과 원리

서비스를 통한 실행이란?

Windows 서비스(sc.exe/services.msc)를 생성하거나 기존 서비스를 수정하여 악성 코드를 SYSTEM 권한으로 실행합니다. 서비스는 시스템 부팅 시 자동 시작되므로 지속성도 확보됩니다. PsExec도 내부적으로 서비스를 생성하여 원격 명령을 실행합니다.

서비스 생성

sc create로 새 악성 서비스 등록

서비스 수정

기존 서비스의 바이너리 경로 수정

PsExec

원격 서비스 생성을 통한 명령 실행

#2. 공격 기법 분석

# 악성 서비스 생성
sc create UpdateSvc binPath= "C:\temp\beacon.exe" start= auto
sc start UpdateSvc
# PsExec 원격 실행 (내부적으로 서비스 생성)
psexec \\target -s -d C:\temp\beacon.exe
# 서비스 바이너리 교체
sc config LegitService binPath= "C:\temp\beacon.exe"
// 서비스 = SYSTEM 권한 실행

공격 분석

  • 신규 서비스: 정상 서비스명으로 위장하여 등록
  • 바이너리 교체: 기존 서비스의 실행 파일 교체
  • DLL 사이드로딩: 서비스가 로드하는 DLL 교체
  • PsExec/RemCom: 원격 서비스 생성으로 원격 실행

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • 서비스 생성 감시: Event 7045(새 서비스 설치) 모니터링
  • 서비스 무결성: 서비스 바이너리 해시 정기 검증
  • 최소 권한: 서비스 생성 권한 제한
  • AppLocker: 서비스 바이너리 화이트리스트
  • Sysmon: 서비스 프로세스의 비정상 자식 프로세스 탐지
