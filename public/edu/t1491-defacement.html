기업 웹사이트를 해커의 낙서판으로 만드는 공격

#1. 웹사이트 변조란?

🌐 ➜ 🎨 ➜ 💀 ➜ 📢

"회사 간판을 해커의 낙서로 바꿔치기"

웹사이트 변조(Defacement)는 공격자가 웹 서버에 침투하여 홈페이지 내용을 임의로 변경하는 공격입니다. 정치적 메시지를 표시하거나, 해킹 사실을 과시하거나, 기업 신뢰도를 훼손하는 것이 목적입니다. 외부 공개 사이트(External)와 내부 인트라넷(Internal) 변조로 구분됩니다.

외부 변조 (External)

  • - 공개 웹사이트의 메인 페이지 변경
  • - 고객이 즉시 인지하여 브랜드 이미지 타격
  • - 핵티비즘(Hacktivism) 동기가 많음

내부 변조 (Internal)

  • - 사내 인트라넷/대시보드 페이지 변경
  • - 직원들에게 심리적 압박 (랜섬웨어 연계)
  • - 내부 침투 성공의 과시 목적

#2. 공격 기법 분석

주요 침투 경로

💉
SQL Injection— DB 쿼리를 조작하여 관리자 권한 획득
📤
파일 업로드 취약점— 웹셸을 업로드하여 서버 제어
🔑
CMS 관리자 계정 탈취— 약한 비밀번호나 크리덴셜 스터핑
# 웹셸을 통한 index.html 변조 의사코드
curl -X POST "https://target.com/upload.php"
-F "file=@webshell.php;type=image/jpeg"
# 웹셸 업로드 후 index.html 덮어쓰기
curl "https://target.com/uploads/webshell.php
?cmd=echo 'HACKED BY...' > /var/www/html/index.html"

  • - CMS 관리자 계정에 MFA 적용
