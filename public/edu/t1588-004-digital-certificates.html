T1588.004
디지털 인증서 획득

공격자가 SSL/TLS 인증서를 탈취하여 C2 통신 암호화, 피싱 사이트 신뢰성 확보에 활용하는 기법을 학습합니다.

🔐 Chapter 1 — SSL/TLS 인증서 개요

SSL/TLS 인증서는 웹사이트의 신원을 증명하고 통신을 암호화합니다. 브라우저는 유효한 인증서가 있는 사이트에 자물쇠 아이콘을 표시하여 사용자에게 안전함을 알립니다.

공격자의 인증서 획득 방법
  • • 웹서버 해킹으로 개인키(.key) 탈취
  • • 도메인 하이재킹 후 DV 인증서 재발급
  • • Let's Encrypt로 유사 도메인 인증서 발급
  • • 와일드카드 인증서 탈취로 모든 서브도메인 사칭
악용 목적
  • • C2 통신 HTTPS 암호화 (트래픽 검사 우회)
  • • 피싱 사이트 자물쇠 아이콘 표시
  • • MitM 공격용 가짜 인증서
  • • 합법 서비스 사칭 (banking, cloud)

# 피싱 도메인의 인증서 정보 확인

$ echo | openssl s_client -connect login-microsoft365[.]com:443 2>/dev/null | openssl x509 -noout -subject -issuer -dates

subject=CN = login-microsoft365[.]com

issuer=CN = R3, O = Let's Encrypt, C = US

notBefore=Feb 28 00:00:00 2026 GMT

notAfter=May 29 23:59:59 2026 GMT

[!] Let's Encrypt DV 인증서 — Microsoft 사칭 피싱 도메인

🔓 Chapter 2 — 인증서 악용 기법

C2 통신 암호화

탈취한 인증서로 HTTPS C2 서버를 구축하면, 네트워크 보안 장비가 암호화된 트래픽 내용을 검사할 수 없습니다. 합법 도메인의 인증서를 사용하면 도메인 평판까지 활용합니다.

SSL Stripping / MitM

탈취한 인증서로 중간자(MitM) 공격을 수행합니다. 피해자와 서버 사이에 위치하여 암호화된 통신을 복호화하고 중계합니다.

피싱 신뢰도 강화

HTTPS + 자물쇠 아이콘이 있는 피싱 사이트는 사용자의 신뢰를 크게 높입니다. EV 인증서를 탈취하면 조직명까지 표시됩니다.

# 탈취한 인증서로 HTTPS C2 리스너 구성

$ cat nginx-c2.conf

server {

listen 443 ssl;

server_name cdn-update.azureedge[.]net;

ssl_certificate /opt/certs/stolen_fullchain.pem;

ssl_certificate_key /opt/certs/stolen_privkey.pem;

location / { proxy_pass http://127.0.0.1:8080; }

}

🛡️ Chapter 3 — 탐지 및 방어

탐지 전략
  • • Certificate Transparency 로그 실시간 모니터링
  • • 조직 도메인 유사 인증서 발급 알림 설정
  • • TLS 인터셉션으로 암호화 트래픽 검사
  • • JA3/JA3S 핑거프린트로 비정상 TLS 클라이언트 식별
방어 대책
  • • CAA DNS 레코드로 인증서 발급 CA 제한
  • • HSTS Preload로 SSL Stripping 방지
  • • Certificate Pinning으로 인증서 고정
  • • DANE/TLSA 레코드로 인증서 바인딩
