T1055.012: Process Hollowing

Privilege Escalation / Defense Evasion

Process Hollowing

정상 프로세스의 몸통을 비우고 악성 코드를 집어넣는 은밀한 공격 기법

#1. Process Hollowing이란?

"가짜 유니폼" 비유

경비원(보안 도구)이 건물에 들어오는 사람의 유니폼(프로세스 이름)을 확인합니다. 공격자는 정상 직원(svchost.exe)의 유니폼을 빌려 입고, 겉모습은 정상이지만 내부(메모리)에는 악성 코드가 실행됩니다. 이것이 Process Hollowing입니다.

공격 흐름 4단계

1CreateProcess(SUSPENDED): 정상 프로세스를 일시 정지 상태로 생성
2NtUnmapViewOfSection: 원본 코드 섹션을 메모리에서 제거 (Hollowing)
3WriteProcessMemory: 빈 공간에 악성 코드를 주입
4ResumeThread: 프로세스를 재개하여 악성 코드 실행

#2. 공격 단계 분석

탐지가 어려운 이유

작업 관리자에서 보면 정상적인 svchost.exe로 표시됩니다. 파일 시스템에 악성 파일을 생성하지 않으므로 백신의 파일 스캔을 우회합니다. 프로세스 이름, 경로, 부모 프로세스 관계가 모두 정상처럼 보입니다.

// Process Hollowing 의사 코드 (C/C++)
STARTUPINFO si; PROCESS_INFORMATION pi;
CreateProcess("svchost.exe", ..., CREATE_SUSPENDED, &pi);
NtUnmapViewOfSection(pi.hProcess, imageBase);
VirtualAllocEx(pi.hProcess, imageBase, size, ...);
WriteProcessMemory(pi.hProcess, imageBase, malware, ...);
ResumeThread(pi.hThread);

방어 방법

  • EDR 메모리 스캔: 프로세스 메모리의 실제 코드와 디스크 이미지 비교
  • API 후킹 모니터링: NtUnmapViewOfSection, WriteProcessMemory 호출 감시
  • Sysmon Event ID 8: CreateRemoteThread 이벤트 탐지
  • AMSI (Antimalware Scan Interface): 메모리 내 스크립트 검사
