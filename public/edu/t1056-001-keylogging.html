Keylogging

키보드 입력을 몰래 기록하여 자격 증명을 탈취하는 공격

#1. Keylogging이란?

"투명 키보드 위의 감시자" 비유

키로거는 키보드와 운영체제 사이에 투명한 감시자를 심는 것입니다. 사용자가 입력하는 모든 글자 - 비밀번호, 이메일, 채팅, 신용카드 번호 - 가 기록되어 공격자에게 전송됩니다. 소프트웨어 키로거와 하드웨어 키로거 두 종류가 있습니다.

소프트웨어 키로거

  • Windows API Hooking (SetWindowsHookEx)
  • 커널 드라이버 기반 필터
  • Browser Extension 기반

하드웨어 키로거

  • USB 인라인 디바이스
  • 키보드 내장형
  • 무선 신호 도청(Van Eck Phreaking)

#2. 공격 기법

Windows API Hooking 키로거

SetWindowsHookEx WH_KEYBOARD_LL 후킹을 사용하여 모든 키 입력을 가로챕니다.

# PowerShell 키로거 감지 (방어 관점)
Get-WinEvent -FilterHashtable @{
LogName='Microsoft-Windows-Sysmon/Operational'
Id=13 # Registry value set
} | Where-Object {
$_.Message -match 'SetWindowsHookEx'
}

방어 방법

  • EDR 솔루션: SetWindowsHookEx 호출 모니터링
  • Sysmon: 이벤트 ID 13으로 레지스트리 후킹 탐지
  • 가상 키보드: 금융 사이트에서 가상 키보드 사용
  • 비밀번호 관리자: 자동 입력으로 키 입력 최소화
  • USB 포트 감사: 하드웨어 키로거 물리적 점검
