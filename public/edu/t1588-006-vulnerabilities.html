T1588.006
취약점 정보 획득

공격자가 NVD, CVE 데이터베이스 등에서 취약점 정보를 수집하여 공격 계획을 수립하는 기법을 학습합니다.

📊 Chapter 1 — 취약점 정보 소스

공격자는 공개된 취약점 데이터베이스에서 대상 시스템의 알려진 취약점을 수집합니다. 이 정보는 익스플로잇 개발이나 구매의 기초가 됩니다.

공개 데이터베이스
  • • NVD — NIST 국가취약점 데이터베이스
  • • MITRE CVE — CVE 식별자 시스템
  • • CISA KEV — 실제 악용 취약점 카탈로그
  • • Vendor Advisory — Microsoft, Apache 등 보안 공지
비공개 소스
  • • 다크웹 취약점 거래 포럼
  • • 보안 연구자 비공개 보고서
  • • 버그 바운티 미공개 제출물
  • • 국가 후원 취약점 연구 프로그램

# NVD API로 최신 Critical 취약점 검색

$ curl -s 'https://services.nvd.nist.gov/rest/json/cves/2.0?cvssV3Severity=CRITICAL&resultsPerPage=3' | jq '.vulnerabilities[].cve | {id, description: .descriptions[0].value[0:80]}'

{"id":"CVE-2026-XXXX","description":"Microsoft Exchange Server Remote Code Execution..."}

{"id":"CVE-2026-YYYY","description":"Apache Log4j3 JNDI Injection Vulnerability..."}

{"id":"CVE-2026-ZZZZ","description":"Fortinet FortiOS SSL-VPN Pre-Auth Buffer Overflow..."}

🎯 Chapter 2 — CVSS와 공격 우선순위

공격자는 CVSS 점수와 공격 가능성을 기준으로 취약점의 우선순위를 결정합니다.

9.0-10.0

Critical

7.0-8.9

High

4.0-6.9

Medium

0.1-3.9

Low

공격자의 우선순위 기준
  • 1. 원격 실행 가능 (RCE) — 인증 없이 원격에서 코드 실행
  • 2. 인터넷 노출 — 인터넷에서 접근 가능한 서비스
  • 3. 인증 불필요 — 사전인증 공격 가능
  • 4. PoC 가용성 — 공개 익스플로잇 코드 존재
  • 5. 패치 미적용률 — 많은 조직이 미패치 상태

🛡️ Chapter 3 — 방어 전략

취약점 관리
  • • 정기 취약점 스캔 (Nessus, Qualys 등)
  • • SBOM(소프트웨어 구성 목록) 관리
  • • CISA KEV 기반 우선순위 패칭
  • • 가상 패칭으로 임시 보호
공격 표면 축소
  • • 불필요한 서비스 인터넷 노출 제거
  • • WAF/IPS로 알려진 공격 패턴 차단
  • • 제로 트러스트 네트워크 아키텍처
  • • 정기 레드팀/침투테스트 수행
