T1574.001: DLL Search Order Hijacking

Privilege Escalation / Persistence

DLL Search Order Hijacking

도서관에서 가짜 책을 진짜 자리에 끼워넣는 기법

#1. DLL이란? Windows DLL 로딩 순서

"도서관 비유"

프로그램이 도서관에서 책(DLL)을 찾을 때, 정해진 순서대로 서가를 둘러봅니다. 첫 번째 서가에 같은 제목의 가짜 책을 놓으면, 프로그램은 진짜 책 대신 가짜 책을 읽게 됩니다. 이것이 DLL 탐색 순서 하이재킹입니다.

Windows DLL 탐색 순서

1애플리케이션 폴더 (실행 파일과 같은 디렉토리)
2C:\Windows\System32
3C:\Windows\System
4C:\Windows
5현재 작업 디렉토리
6PATH 환경변수 디렉토리들

#2. PATH 하이재킹 & 사이드 로딩

DLL Search Order Hijacking

프로그램이 찾는 DLL보다 먼저 탐색되는 경로에 악성 DLL을 배치. 예: 앱 폴더에 version.dll 배치.

DLL Side-Loading

합법적인 프로그램이 서명 검증 없이 로드하는 DLL을 악성 버전으로 교체. 안티바이러스 우회에 효과적.

# Process Monitor로 DLL 로딩 실패(NAME NOT FOUND) 확인
Filter: Process Name = target.exe, Result = NAME NOT FOUND
target.exe CreateFile C:\App\helper.dll NAME NOT FOUND
target.exe CreateFile C:\Windows\System32\helper.dll SUCCESS
# → C:\App\ 에 악성 helper.dll을 넣으면 먼저 로드됨!
