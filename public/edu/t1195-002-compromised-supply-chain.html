Supply Chain Compromise

택배 기사가 배달 중간에 소포를 바꿔치기 — 공급망 공격

#1. 공급망 공격이란?

📦 ➜ 🔄 ➜ 🏭 ➜ 💥

"택배 기사가 배달 중간에 소포를 바꿔치기"

여러분이 인터넷에서 주문한 택배가 배달되는 중간에, 누군가 포장을 뜯고 안에 도청기를 넣은 뒤 다시 포장한다면? 받는 사람은 정상 택배라고 믿고 집에 들여놓습니다. 공급망 공격(Supply Chain Attack)은 정상적인 소프트웨어 배포 과정에 악성 코드를 끼워 넣어, 수만~수십만 사용자에게 동시에 감염시키는 기법입니다.

실제 사례로 이해하기

SolarWinds

IT 관리 소프트웨어 Orion의 업데이트 서버가 해킹되어, 18,000개 이상의 조직(미국 정부기관 포함)에 악성 업데이트가 배포되었습니다.

Codecov

코드 커버리지 도구의 CI/CD 스크립트가 변조되어, 사용자의 환경변수(API 키, 토큰)가 공격자 서버로 유출되었습니다.

NPM 패키지

인기 패키지와 유사한 이름(typosquatting)으로 악성 패키지를 업로드하여 개발자가 실수로 설치하도록 유도합니다.

#2. 소프트웨어 서명 & 패키지 매니저 침해

코드 서명(Code Signing) 공격

공격자가 소프트웨어 빌드 서버에 침투하여, 정상적인 코드 서명 인증서로 악성 코드를 서명합니다. OS는 서명이 유효하므로 경고 없이 실행합니다.

# 정상 업데이트 해시
SHA256: a1b2c3d4e5f6...

# 변조된 업데이트 해시
SHA256: 9x8y7z6w5v4... ← 다름!

패키지 매니저 침해

npm, pip, Maven 등 패키지 저장소에 악성 패키지를 올리거나, 기존 패키지 관리자의 계정을 탈취하여 악성 버전을 배포합니다.

# Typosquatting 예시
npm install lodash # 정상
npm install l0dash # 악성!
npm install lodash-utils # 악성!
