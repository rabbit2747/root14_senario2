T1548.002: Bypass UAC

Privilege Escalation

Bypass UAC

보안 경비원을 속여 VIP 출입증 없이 통과하는 기법

#1. UAC(사용자 계정 컨트롤)란?

"보안 경비원" 비유

건물 입구에 경비원이 서 있습니다. 일반 직원이 기밀 구역에 들어가려면 경비원에게 "관리자 허가증을 보여주세요"라고 물어봅니다. 이것이 바로 UAC(User Account Control)입니다. Windows Vista부터 도입된 보안 기능으로, 관리자 권한이 필요한 작업 시 사용자에게 "예/아니오" 확인 창을 띄웁니다.

UAC 동작 원리

1관리자 그룹 사용자도 제한된 토큰(Medium IL)으로 실행
2관리자 작업 요청 시 동의 프롬프트(어두운 화면 + 예/아니오) 표시
3"예" 클릭 시 상승된 토큰(High IL)으로 프로세스 실행

#2. UAC 우회 기법

Auto-Elevate: 경비원이 자동 통과시키는 VIP

일부 Microsoft 서명 프로그램은 UAC 프롬프트 없이 자동으로 관리자 권한을 얻습니다(Auto-Elevate). 공격자는 이런 프로그램을 중간 다리(Proxy)로 악용합니다.

fodhelper.exe 우회

Windows 기능 관리자. 레지스트리 키를 조작해 원하는 명령을 관리자 권한으로 실행.

REG ADD HKCU\Software\Classes\
 ms-settings\Shell\Open\command
 /d "cmd.exe" /f

eventvwr.exe 우회

이벤트 뷰어. mmc.exe를 호출할 때 레지스트리에서 경로를 읽는 점을 악용.

REG ADD HKCU\Software\Classes\
 mscfile\Shell\Open\command
 /d "powershell.exe" /f
