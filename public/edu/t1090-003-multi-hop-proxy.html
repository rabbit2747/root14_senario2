#1. 다중 프록시(Multi-hop Proxy)란?

🖥️ ➜ 🔀 ➜ 🔀 ➜ 🔀 ➜ 💀

"여러 중계 서버를 거쳐 출발지를 숨기는 기술"

Multi-hop Proxy는 트래픽을 여러 프록시 서버를 경유시켜 원래 출발지(C2 서버)를 추적할 수 없게 만드는 기술입니다. 각 프록시는 바로 앞 노드의 IP만 알기 때문에, 전체 경로를 파악하려면 모든 프록시의 로그가 필요합니다. 마치 여러 나라를 거쳐가는 택배처럼, 최종 목적지를 숨깁니다.

왜 다중 프록시인가?

단일 프록시는 해당 서버가 압수되면 C2가 노출됩니다. 3개 이상의 프록시 체인을 구성하면, 한 노드가 노출되어도 전체 경로 추적이 극도로 어렵습니다. 특히 프록시가 여러 국가에 분산되어 있으면 법적 관할권 문제로 수사가 더욱 복잡해집니다.

#2. Tor 네트워크와 프록시 체인

Tor 기반 C2

Tor(The Onion Router)는 3개의 릴레이(Entry → Middle → Exit)를 경유하며, 각 릴레이마다 별도의 암호화 레이어를 적용합니다. C2 서버를 .onion 히든 서비스로 운영하면 Exit 노드 없이 완전한 익명성을 확보할 수 있습니다.

커스텀 프록시 체인

APT 그룹은 자체 프록시 체인을 구축합니다. 침해된 서버, VPS, IoT 장비를 중계 노드로 사용하며, 각 노드는 다음 노드의 주소만 알고 있습니다. SOCKS5 프록시나 SSH 터널을 체인으로 연결하는 방식이 일반적입니다.

실전 도구: Proxychains

Proxychains는 임의의 애플리케이션 트래픽을 SOCKS/HTTP 프록시 체인으로 강제 라우팅합니다. 공격자는 이를 통해 일반 도구도 다중 프록시를 경유하게 만듭니다.

# Proxychains 설정 및 실행
proxychains4 -q nmap -sT 10.10.15.0/24
Chain: SOCKS5→VPS(RU)→VPS(NL)→VPS(SG)→Target
