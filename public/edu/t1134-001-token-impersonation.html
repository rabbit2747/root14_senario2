ATT&CK Matrix

T1134.001: Token Impersonation

Privilege Escalation

Token Impersonation

다른 사람의 사원증을 빌려 기밀구역에 출입하는 기법

#1. 액세스 토큰이란?

"사원증(ID 배지) 비유"

회사에 출근하면 사원증을 받습니다. 이 사원증에는 이름, 부서, 출입 가능 구역이 적혀 있죠. Windows에서 프로그램이 실행되면 OS가 액세스 토큰(Access Token)이라는 '디지털 사원증'을 발급합니다. 이 토큰에는 사용자 ID(SID), 소속 그룹, 권한 목록이 들어있습니다.

토큰의 두 가지 종류

🔑

Primary Token (주 토큰)

프로세스가 생성될 때 할당. 해당 프로세스의 '신분증' 역할.

🎭

Impersonation Token (가장 토큰)

다른 사용자 행세를 위한 임시 토큰. 서비스가 클라이언트 권한으로 작업할 때 사용.

# 현재 프로세스의 토큰 권한 확인
C:\> whoami /priv
SeImpersonatePrivilege   Impersonate a client after authentication   Enabled
SeAssignPrimaryTokenPrivilege   Replace a process level token   Disabled

#2. SeImpersonatePrivilege & Potato 공격

핵심 권한: SeImpersonatePrivilege

IIS 웹 서버, SQL Server, MSSQL 같은 서비스 계정에는 기본적으로 SeImpersonatePrivilege가 부여됩니다. 이 권한이 있으면 다른 사용자의 토큰을 '빌려' 그 사람인 척 행동할 수 있습니다. 공격자가 이런 서비스 계정을 장악하면, SYSTEM 권한 토큰을 훔쳐 최고 관리자가 됩니다.

🥔

JuicyPotato

COM 서버를 악용해 SYSTEM 토큰 획득. Windows 10 1809 이전 동작.

🍠

SweetPotato

여러 Potato 기법을 통합. 최신 Windows에도 일부 동작.

🖨️

PrintSpoofer

Print Spooler 서비스 악용. Named Pipe로 SYSTEM 토큰 가로채기.

# PrintSpoofer를 이용한 권한 상승 예시
C:\> PrintSpoofer.exe -i -c cmd
[+] Found privilege: SeImpersonatePrivilege
[+] Named Pipe listening...
[+] Got SYSTEM token! Launching cmd as NT AUTHORITY\SYSTEM
