Cloud Account Discovery

클라우드 환경의 IAM 사용자 및 역할 열거

#1. Cloud Account Discovery란?

☁️ ➜ 👤 ➜ 📋 ➜ 🎯

"클라우드 IAM 사용자와 역할을 열거"

공격자는 AWS, Azure, GCP의 IAM API를 사용하여 클라우드 환경의 사용자, 역할, 그룹, 정책을 열거합니다. 이를 통해 고권한 계정과 과도한 권한을 가진 역할을 식별합니다.

주요 열거 명령어

# AWS IAM
aws iam list-users
aws iam list-roles
aws iam list-attached-user-policies --user-name admin
# Azure AD
az ad user list
az role assignment list

왜 위험한가?

권한 상승 경로 발견

과도한 권한의 IAM 역할을 식별하면 권한 상승의 발판이 됩니다.

데이터 접근 경로

S3, RDS 등 데이터 저장소에 접근 가능한 역할을 타겟팅합니다.

#2. 공격 기법 분석

AWS IAM 계정 열거

IAM API로 사용자, 역할, 정책 정보를 수집합니다.

# IAM 사용자 및 정책 열거
aws iam list-users --query 'Users[].UserName'
aws iam list-attached-user-policies --user-name admin
aws iam get-account-authorization-details
