#1. WMI(Windows Management Instrumentation) 개념

🏢 ➜ 🖥️ ➜ 📡 ➜ 💥

"건물 관리 시스템(BMS)을 해킹해서 모든 방 제어"

대형 빌딩의 관리실에는 모든 층의 냉난방, 조명, 출입문을 원격으로 제어하는 건물 관리 시스템(BMS)이 있습니다. 이 시스템에 접근하면 한 곳에서 전체 건물을 통제할 수 있습니다. WMI는 Windows의 "건물 관리 시스템"입니다. 시스템 정보 조회부터 프로세스 실행까지 원격으로 모든 것을 제어할 수 있습니다.

WMI가 할 수 있는 것들

📊
시스템 정보 조회
⚙️
프로세스 생성/종료
📡
원격 명령 실행
⏰
이벤트 구독/트리거

왜 공격자가 WMI를 좋아하는가?

  • Windows에 기본 설치 (별도 도구 불필요)
  • 네트워크를 통한 원격 실행 (포트 135, DCOM)
  • 실행 흔적이 적음 (파일을 디스크에 쓰지 않음)
  • 이벤트 구독으로 영구적 백도어 설치 가능

#2. WMI 공격 기법

wmic process call create

원격 컴퓨터에서 프로세스를 생성하여 명령을 실행합니다. 관리자 자격 증명만 있으면 네트워크의 어떤 PC에서든 실행 가능합니다.

# 원격 PC에서 calc.exe 실행
wmic /node:"192.168.1.100"
 /user:"admin" /password:"pass"
 process call create "calc.exe"

WMI 이벤트 구독 (영구 백도어)

특정 이벤트(예: 시스템 부팅)가 발생하면 자동으로 악성 코드를 실행하는 구독을 등록합니다. 재부팅 후에도 유지됩니다.

# WMI 이벤트 구독 구조
EventFilter: "5분마다 확인"
EventConsumer: "악성코드 실행"
FilterToConsumerBinding: 연결

WMI 공격 흐름

자격증명 획득 → WMI 원격 접속 → 정찰/열거 → 프로세스 생성 → 측면이동 완료
