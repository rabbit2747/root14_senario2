T1592.004: Client Configurations

Reconnaissance

Client Configurations

사용자의 컴퓨터 환경을 엿보는 공격자 — 클라이언트 구성 정보 수집

#1. 클라이언트 설정 정보 수집이란?

🖥️ ➜ 🔍 ➜ 📊 ➜ 🎯

"사용자의 디지털 지문을 수집하기"

공격자는 대상 조직 직원들이 사용하는 브라우저 종류, OS 버전, 이메일 클라이언트, VPN 소프트웨어, 보안 제품 등 클라이언트 환경을 수집합니다. 이 정보로 맞춤형 피싱 페이지를 만들거나, 특정 브라우저의 취약점을 공격합니다.

"수집 방법"

User-Agent 헤더에서 브라우저/OS 정보를, JavaScript API로 화면 해상도/플러그인/글꼴 목록을, 이메일 헤더에서 이메일 클라이언트 정보를 수집합니다. 이를 브라우저 핑거프린팅이라 합니다.

수집 대상 클라이언트 정보

🌐
Browser/OS
Chrome, Edge, macOS, Win11
📧
Email Client
Outlook, Thunderbird
🛡️
Security SW
AV, EDR, VPN Client

#2. 브라우저 핑거프린팅

User-Agent 분석

# 웹 서버 로그에서 User-Agent 추출
Mozilla/5.0 (Windows NT 10.0; Win64; x64)
AppleWebKit/537.36 Chrome/120.0.0.0 Safari/537.36
해석: Windows 10 64bit, Chrome 120

JavaScript 핑거프린팅

// 피싱 페이지에 삽입된 핑거프린팅 코드
navigator.platform: "Win32"
screen.width x height: 1920x1080
navigator.languages: ["ko-KR","en-US"]
Installed fonts: 245 detected
Canvas fingerprint: 0x3A7F2B1C

위험 포인트

  • ●맞춤형 공격: 대상의 브라우저/OS에 맞는 익스플로잇 선택
  • ●보안 제품 우회: 설치된 AV/EDR 제품에 맞는 우회 기법 적용
  • ●피싱 정밀도: 사용 환경에 맞는 가짜 로그인 페이지 제작
