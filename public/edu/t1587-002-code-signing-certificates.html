T1587.002
코드서명 인증서 개발

공격자가 셸 컴퍼니를 통해 합법적인 코드서명 인증서를 직접 취득하거나, 자체 서명 인증서를 생성하여 악성코드에 서명하는 기법을 학습합니다.

🔏 Chapter 1 — 코드서명 인증서 개요

코드서명 인증서는 소프트웨어의 무결성과 출처를 보증하는 디지털 서명입니다. 공격자는 탈취(T1588.003) 대신 직접 인증서를 개발하여 악성코드에 서명할 수 있습니다. 이를 통해 Windows SmartScreen, 안티바이러스, 애플리케이션 제어 정책을 우회합니다.

자체 서명 (Self-signed)

OpenSSL로 직접 생성. 신뢰 체인 없음. SmartScreen 우회 불가. 내부 네트워크 공격에 활용.

셸 컴퍼니 (Shell Company)

가짜 회사 설립 후 CA에서 합법 인증서 구매. OV/EV 인증서 취득 가능. SmartScreen 우회.

리셀러 악용

검증이 느슨한 인증서 리셀러를 통해 최소한의 서류로 인증서 구매. 저렴하고 빠른 발급.

⚡ Chapter 2 — 자체 인증서 생성 기법

셸 컴퍼니를 통한 EV 인증서 취득

공격자는 가짜 사업자등록증, 위조된 사무실 주소, 가상 전화번호로 셸 컴퍼니를 설립합니다. 일부 국가에서는 온라인으로 몇 시간 안에 법인을 등록할 수 있으며, 이를 기반으로 CA에 EV 코드서명 인증서를 신청합니다.

자체 서명 인증서 (내부 공격용)

Active Directory 환경에서는 조직 내부 CA가 발급한 인증서를 신뢰합니다. 공격자가 AD CS(Active Directory Certificate Services)를 악용하면, 내부적으로 신뢰되는 코드서명 인증서를 발급받을 수 있습니다.

다크웹 인증서 서비스

다크웹에서는 "Code Signing as a Service"를 제공하는 판매자가 있습니다. $500~$3,000에 EV 인증서를 구매하거나, 파일당 $50에 서명 서비스를 이용할 수 있습니다. 이 인증서들은 실제 CA에서 합법적으로 발급받은 것입니다.

🛡️ Chapter 3 — 탐지와 방어

인증서 분석
  • - 서명자의 사업 기간/이력 확인
  • - 인증서 발급일과 파일 생성일 비교
  • - 서명된 파일의 VT 평판 조회
  • - 같은 인증서로 서명된 다른 파일 검색
정책 기반 방어
  • - WDAC로 신뢰할 인증서 목록 관리
  • - AppLocker Publisher Rules 적용
  • - EV 인증서만 허용 정책
  • - CA 허용 목록 (특정 CA만 신뢰)
CA 업계 대응

CA/Browser Forum은 2024년부터 코드서명 인증서의 개인 키를 HSM에 저장하도록 의무화했습니다. 이는 키 탈취를 방지하지만, 셸 컴퍼니를 통한 합법적 취득은 여전히 가능합니다. Microsoft는 SmartScreen의 평판 시스템을 강화하여 새로운 인증서의 신뢰를 점진적으로 부여합니다.
