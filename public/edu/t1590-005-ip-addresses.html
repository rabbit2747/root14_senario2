#1. IP 주소 수집이란?

🏠 ➜ 📍 ➜ 🔍 ➜ 🎯

"진짜 집 주소 찾기"

많은 웹사이트가 CDN(Cloudflare, AWS CloudFront)을 사용하여 실제 서버 IP를 숨깁니다. 공격자는 DNS 기록 이력, SSL 인증서, 메일 헤더, 역사적 IP 데이터를 분석하여 CDN 뒤의 Origin IP를 찾아냅니다. 이를 알아내면 CDN의 WAF/DDoS 보호를 우회하여 직접 공격할 수 있습니다.

🌐 ➜ 🛡️ ➜ 💻 ➜ ⚠️

"IP에서 알 수 있는 것들"

지리적 위치(국가, 도시, 데이터센터), ISP/호스팅 제공자(AWS, Azure, 자체 호스팅), IP 대역 소유자(ARIN/RIPE WHOIS), 클라우드 리전(us-east-1 등), 공유 호스팅 여부(같은 IP의 다른 사이트)를 파악할 수 있습니다.

#2. CDN 뒤 실제 IP 찾기

CDN은 원본 서버를 보호하지만, 여러 경로를 통해 실제 IP가 유출될 수 있습니다. 과거 DNS 기록, 메일 헤더, SSL 인증서 등이 단서가 됩니다.

Origin IP 탐색 기법

$ # 1. 과거 DNS 기록에서 CDN 전 IP 확인
$ curl -s "https://api.securitytrails.com/v1/history/example.com/dns/a"
  2022-01: 52.84.220.64 (AWS - Origin Server!)

$ # 2. 메일 헤더에서 Origin IP 추출
$ nslookup -type=mx example.com
  mail.example.com → 198.51.100.25 (Origin IP!)

$ # 3. Shodan에서 SSL 인증서로 검색
$ shodan search ssl.cert.subject.cn:example.com
  198.51.100.25  Apache/2.4.41  (Origin!)

Origin IP가 노출되면?

CDN의 WAF(Web Application Firewall)와 DDoS 보호를 완전히 우회하여 서버에 직접 공격할 수 있습니다. CDN이 제공하는 모든 보안 기능이 무력화되는 것입니다. 따라서 Origin 서버는 CDN IP에서만 접근을 허용하도록 방화벽을 설정해야 합니다.
