#1. USB를 통한 데이터 유출이란?

🔌 ➜ 💻 ➜ 📂 ➜ 🏃

"USB 하나면 회사 전체 기밀이 주머니 안으로"

내부자나 침투에 성공한 공격자가 USB 저장 장치를 이용해 네트워크 모니터링을 우회하고 데이터를 물리적으로 반출하는 기법입니다. 네트워크 기반 탐지(NDR, DLP)를 완전히 회피할 수 있어 가장 원초적이면서도 효과적인 유출 경로입니다.

왜 USB 유출이 위험한가?

🕵️
네트워크 로그 없음
방화벽·IDS가 전혀 감지 못함
⚡
USB 3.0 = 5Gbps
수 GB 데이터를 수십 초 만에 복사
🎭
내부자 위협
권한 있는 직원의 악의적 행위

#2. 공격 기법 분석

수집 → 압축 → 복사

1 기밀 파일을 staging 폴더에 수집
2 7-Zip 등으로 암호화 압축하여 탐지 우회
3 USB 연결 후 robocopy/xcopy로 고속 복사

Rubber Ducky / BadUSB

일반 USB처럼 보이지만 실제로는 키보드로 인식되는 공격 장치입니다. 연결 즉시 사전 프로그래밍된 명령을 자동 입력하여 데이터를 수집하고 외부로 전송합니다. 물리 보안과 디바이스 제어 정책이 필수입니다.

# USB 데이터 유출 시뮬레이션 (의사코드)
$usbDrive = Get-WmiObject Win32_DiskDrive | Where { $_.InterfaceType -eq 'USB' }
$stagingDir = "$env:TEMP\staging_$(Get-Date -f yyyyMMdd)"
Copy-Item "C:\Confidential\*" $stagingDir -Recurse
Compress-Archive $stagingDir -DestinationPath "$usbDrive\backup.zip"
Remove-Item $stagingDir -Recurse -Force # 흔적 제거

탐지 방법

  • - Sysmon Event ID 1: USB 장치 연결 프로세스 모니터링
  • - Windows Event ID 4663: 파일 접근 감사 로그
  • - DLP 에이전트: 이동식 미디어 쓰기 차단/경고

방어 전략

  • - 그룹 정책(GPO)으로 USB 저장 장치 차단
  • - 엔드포인트 DLP로 민감 데이터 복사 통제
  • - USB 포트 물리적 잠금 장치 적용
