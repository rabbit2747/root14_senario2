T1036.007: Double File Extension

Defense Evasion

Double File Extension

이중 확장자로 실행 파일을 문서처럼 위장하는 기법

#1. 이중 확장자란?

"가면 무도회" 비유

실행 파일(.exe)이 문서 가면(.pdf, .docx)을 쓰고 무도회에 참석하는 것입니다. Windows는 기본적으로 마지막 확장자를 숨기므로, report.pdf.exe는 report.pdf로 보입니다. 사용자는 PDF를 열었다고 생각하지만, 실제로는 악성코드가 실행됩니다.

사용자가 보는 것

report.pdf

PDF 아이콘 표시

실제 파일

report.pdf.exe

실행 파일!

#2. 공격 기법

흔한 이중 확장자 패턴

  • invoice.pdf.exe - 청구서 위장
  • photo.jpg.scr - 이미지 위장 (화면 보호기)
  • document.docx.bat - 문서 위장 배치 파일
  • setup.msi.lnk - 설치 파일 위장 바로가기
# RLO (Right-to-Left Override) 유니코드 트릭
ren payload.exe "invoice_[U+202E]fdp.exe"
# 표시: invoice_exe.pdf (RLO로 확장자 반전!)

방어 방법

  • 확장자 표시 설정: '알려진 파일 형식의 확장자 숨기기' 해제
  • 그룹 정책: 이메일 첨부파일 확장자 필터링
  • 사용자 교육: 이중 확장자 패턴 인식
  • AppLocker: 허가된 경로 외 실행 파일 차단
