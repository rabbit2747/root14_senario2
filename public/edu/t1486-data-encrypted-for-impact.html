#1. 랜섬웨어란?

🔐 ➜ 📁 ➜ 💰 ➜ 😱

"집 안의 모든 물건에 자물쇠를 채우고 열쇠값 요구"

어느 날 집에 돌아왔더니 모든 서랍, 냉장고, 옷장에 자물쇠가 채워져 있습니다. 벽에는 "열쇠를 원하면 비트코인을 보내라"는 쪽지가 붙어 있습니다. 이것이 랜섬웨어(Ransomware)입니다. 파일을 암호화하고 복호화 대가(몸값, Ransom)를 요구합니다.

현대 랜섬웨어의 진화

최근 랜섬웨어는 단순 암호화를 넘어 이중 협박(Double Extortion)을 합니다. 먼저 데이터를 유출한 뒤 암호화합니다. 몸값을 지불하지 않으면 유출된 데이터를 공개하겠다고 협박합니다.

#2. AES+RSA 이중 암호화, RaaS

AES + RSA 이중 암호화

1 각 파일을 랜덤 AES 키로 고속 암호화
2 AES 키를 공격자의 RSA 공개키로 암호화
3 RSA 개인키 없이는 복호화 불가능

RaaS (Ransomware as a Service)

프로그래밍 능력이 없어도 랜섬웨어를 사용할 수 있는 구독형 서비스입니다. 개발자는 랜섬웨어를 만들고, "가맹점(Affiliate)"은 이를 배포합니다. 수익은 분배합니다. LockBit, BlackCat 등이 대표적입니다.

# 랜섬웨어 암호화 프로세스 의사코드
for each file in target_directories:
aes_key = random_bytes(32) # 파일별 고유 AES-256 키
encrypted_file = AES_encrypt(file, aes_key)
encrypted_key = RSA_encrypt(aes_key, attacker_pubkey)
save(encrypted_file + encrypted_key)
rename(file, file + ".locked")
