Cloud Account

클라우드 환경(AWS/Azure/GCP)에 백도어 계정 생성

#1. 클라우드 계정 생성이란?

☁️ ➜ 👤 ➜ 🔑 ➜ 💀

"클라우드에 가짜 직원을 등록하기"

AWS IAM, Azure AD, GCP IAM 같은 클라우드 ID 서비스에 백도어 계정이나 서비스 계정을 생성하는 기법입니다. 온프레미스 AD와 달리 클라우드 계정은 인터넷 어디에서든 접근 가능하므로, 공격자가 내부 네트워크 접근 없이도 클라우드 리소스를 제어할 수 있습니다.

주요 클라우드별 명령어

# AWS IAM 사용자 생성
aws iam create-user --user-name svc-monitoring
# Azure AD 사용자 생성
az ad user create --display-name "Service Monitor" --user-principal-name svc-monitor@tenant.onmicrosoft.com --password "P@ss..."
# GCP 서비스 계정 생성
gcloud iam service-accounts create svc-monitoring --display-name="Monitoring Service"

왜 위험한가?

원격 접근

인터넷만 있으면 어디서든 클라우드 리소스에 접근할 수 있습니다.

API 키 남용

Access Key를 생성하면 콘솔 로그인 없이 API로 자원을 제어합니다.

#2. 공격 기법 분석

AWS IAM 백도어 계정 + Access Key

# 1. IAM 사용자 생성
aws iam create-user --user-name svc-monitoring

# 2. 관리자 정책 연결
aws iam attach-user-policy --user-name svc-monitoring
  --policy-arn arn:aws:iam::aws:policy/AdministratorAccess

# 3. Access Key 생성 (API 접근용)
aws iam create-access-key --user-name svc-monitoring

탐지 및 방어 전략

🛡️

CloudTrail/Activity Log 모니터링: CreateUser, CreateAccessKey 같은 IAM 변경 이벤트 실시간 감시

🛡️

MFA 필수화: 모든 IAM 사용자에게 MFA를 강제하여 백도어 계정의 무단 사용 방지

🛡️

IAM Access Analyzer: 비정상적 권한 부여나 미사용 계정을 자동으로 탐지
