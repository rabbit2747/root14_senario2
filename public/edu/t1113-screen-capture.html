"몰래카메라로 컴퓨터 화면 촬영" — 스크린 캡처

#1. 왜 화면을 캡처하나?

"몰래카메라로 화면 촬영"

공격자가 피해자의 컴퓨터를 장악한 후, 정기적으로 화면을 캡처하면 이메일 내용, 채팅 대화, 은행 로그인 화면, 내부 문서 등 극도로 민감한 정보를 시각적으로 수집할 수 있습니다. 키로거가 놓치는 시각적 정보까지 포착합니다.

캡처로 수집 가능한 정보

📧
이메일 내용
💬
메신저 대화
🏦
은행/금융 화면
📄
내부 문서
🔒
비밀번호 입력
🗺
네트워크 토폴로지

#2. 캡처 기법

PowerShell 스크린샷

# .NET으로 화면 캡처
Add-Type -AssemblyName System.Windows.Forms
[System.Windows.Forms.Screen]::PrimaryScreen
# 30초마다 자동 캡처 + C2로 전송

키로거 연계

키 입력 로그 + 화면 캡처를 결합하면, 어떤 화면에서 어떤 키를 입력했는지 완벽한 컨텍스트를 확보합니다. MFA 코드 입력 화면까지 캡처 가능합니다.

탐지 방법

GDI API 호출
BitBlt, CreateCompatibleDC 모니터링
임시 파일 생성
%TEMP% 내 이미지 파일 급증
네트워크 업로드
대량 이미지 데이터 외부 전송
