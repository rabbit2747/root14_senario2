Archive Collected Data

수집한 데이터를 압축하고 암호화하여 유출을 준비하는 기법

#1. 데이터 아카이브란?

📂 ➜ 🗜️ ➜ 🔒 ➜ 📤

"훔친 물건을 가방에 담아 잠그다"

공격자는 수집한 파일들을 ZIP, RAR, 7z, tar.gz 등으로 압축하고 비밀번호로 암호화합니다. 압축하면 전송 크기가 줄고, 암호화하면 보안 장비가 내용을 검사할 수 없습니다.

왜 압축과 암호화를 하는가?

대용량 파일을 그대로 전송하면 네트워크 이상 탐지 시스템(NDR)에 잡힐 확률이 높습니다. 압축으로 크기를 줄이고, 암호화로 DLP(데이터 유출 방지)의 내용 검사를 우회합니다.

🗜️
크기 축소
전송 속도 향상, 탐지 회피
🔒
암호화
DLP 내용 검사 우회
📦
단일 파일화
여러 파일을 하나로 묶어 관리

#2. 공격 기법 분석

7-Zip / RAR 암호화 압축

7z나 RAR의 AES-256 암호화를 사용하면 비밀번호 없이는 내용을 확인할 수 없습니다. 보안 솔루션이 악성 파일을 탐지할 수 없게 됩니다.

분할 압축

대용량 아카이브를 작은 조각(예: 50MB)으로 분할하여 DLP의 파일 크기 기반 탐지를 우회합니다. 각 조각은 개별적으로 전송됩니다.

실전 예시: 암호화 7z 압축

스테이징 폴더의 파일을 AES-256으로 암호화하여 7z 아카이브로 압축합니다.

# 수집된 데이터를 암호화 압축
7z a -t7z -mhe=on -p"Str0ngP@ss!" C:\Windows\Temp\update.7z C:\Windows\Temp\collect_20260301\*
Compressing: 2026_전략보고서.xlsx → 78% ratio
Compressing: 고객_DB_백업.xlsx → 82% ratio
Archive size: 892 MB (original: 4.5 GB)
