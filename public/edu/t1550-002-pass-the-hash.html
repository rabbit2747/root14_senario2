Pass the Hash

"비밀번호를 몰라도 지문 복제본으로 통과" — 해시 전달 공격

#1. NTLM 해시란?

"지문 복제본으로 출입"

출입문이 지문으로 열린다면, 비밀번호를 몰라도 지문 복제본만 있으면 통과할 수 있습니다. Windows NTLM 인증에서 비밀번호의 해시(Hash)는 바로 이 '디지털 지문'입니다. 공격자는 비밀번호 원문을 몰라도 해시만으로 인증에 성공합니다.

NTLM 인증 과정

1 클라이언트가 서버에 접속 요청
2 서버가 Challenge(임의의 값)를 전송
3 클라이언트가 비밀번호 해시로 Challenge를 암호화하여 Response 전송
! 해시만 있으면 3단계를 직접 수행 가능 = Pass the Hash

Windows 10+ 에서 제공하는 Credential Guard는 가상화 기반 보안(VBS)을 사용하여 NTLM 해시를 격리된 영역에 저장합니다. Mimikatz로도 접근 불가능합니다.
