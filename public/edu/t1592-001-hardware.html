자동차의 차종과 연식을 파악하는 도둑 — 하드웨어 정보 수집

#1. 하드웨어 정보 수집이란?

🖥️ ➜ 🔍 ➜ 📋 ➜ 🎯

"자동차의 차종과 연식을 파악하는 도둑"

도둑이 목표 자동차의 모델과 연식을 알아야 적합한 도구를 준비하듯, 공격자는 대상의 CPU 종류, 메모리 크기, 네트워크 카드, 보안 장비 등 하드웨어 정보를 수집합니다. 이 정보로 어떤 익스플로잇이 동작할지, 가상머신인지 물리서버인지를 판단합니다.

"수집 가능한 하드웨어 정보"

CPU 아키텍처(x86, ARM)는 페이로드 호환성을 결정하고, 네트워크 인터페이스 정보는 내부 네트워크 구조를 드러내며, 보안 하드웨어(HSM, TPM) 존재 여부는 암호화 우회 난이도를 결정합니다.

수집 대상 하드웨어 정보

🔧
CPU/Architecture
x86_64, ARM, MIPS 등
🌐
Network Interface
NIC, MAC, 속도, 듀얼홈
🛡️
Security Hardware
TPM, HSM, 생체인식

#2. 수집 기법 심층 분석

SNMP를 통한 하드웨어 정보 수집

$ snmpwalk -v2c -c public 192.168.1.10 1.3.6.1.2.1.1
sysDescr.0 = STRING: Linux server01 5.15.0-91 #1 SMP x86_64
sysObjectID.0 = OID: netSnmpAgentOIDs.10
hrProcessorTable: Intel Xeon E5-2680 v4 @ 2.40GHz (28 cores)
hrMemorySize.0 = INTEGER: 65536 MB

Shodan을 통한 원격 하드웨어 정보

$ shodan search "org:TargetCorp" --fields ip_str,os,product,version
203.0.113.10 Linux Apache/2.4.41 2.4.41
203.0.113.20 Windows IIS/10.0 10.0
203.0.113.30 Linux nginx/1.18.0 1.18.0

위험 포인트

  • ● SNMP 기본 커뮤니티 문자열: 'public'이 기본값으로 설정된 경우 모든 정보 노출
  • ● 브라우저 핑거프린팅: User-Agent에서 OS, 브라우저, CPU 아키텍처 추출
  • ● 가상머신 탐지: MAC OUI로 VMware, VirtualBox 등 가상화 환경 식별

#3. 탐지 및 방어

SNMP 보안 강화

기본 커뮤니티 문자열('public') 변경, SNMPv3 사용, ACL 적용

HTTP 헤더 최소화

Server, X-Powered-By 등 정보 노출 헤더 제거
