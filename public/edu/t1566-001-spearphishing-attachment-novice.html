#1. 스피어피싱이란? — 낚시와 작살의 차이

🎣 ➜ 🐟🐟🐟 vs 🏹 ➜ 🐋

"그물 낚시 vs 작살 낚시"

바다에서 그물을 던지면 아무 물고기나 잡힙니다. 이것이 일반 피싱(Phishing)입니다.
하지만 특정 물고기를 노려 작살을 던지면? 이것이 스피어피싱(Spearphishing)입니다.

핵심 개념 3가지

🎯

특정인을 겨냥한다

공격자는 여러분의 이름, 직책, 회사 정보를 미리 조사합니다. 마치 소개팅 전에 상대 SNS를 샅샅이 뒤지는 것과 같습니다.

📎

첨부파일에 함정을 숨긴다

이메일에 붙어 있는 문서(.docx, .xlsx, .pdf)가 열리는 순간, 보이지 않는 악성 프로그램이 컴퓨터에 설치됩니다.

🎭

신뢰할 수 있는 사람으로 위장한다

상사, 거래처, 택배회사를 사칭합니다. "사장님이 보냈으니 빨리 열어봐야지"라는 심리를 이용합니다.

왜 위험한가요?

일반 피싱의 성공률은 약 3%입니다. 하지만 스피어피싱은 30% 이상이 성공합니다. 10배 차이! 공격자가 여러분의 정보를 알수록 속아 넘어갈 확률이 높아집니다.

~3%
일반 피싱 성공률
30%+
스피어피싱 성공률

#2. 피싱의 종류와 진화 역사

🧬 피싱도 진화한다

1990년대 단순 사기 이메일에서 시작해, 오늘날 AI가 작성하는 맞춤형 공격까지.
피싱은 기술과 함께 계속 진화하고 있습니다.

피싱의 진화 타임라인

1996

AOL 피싱 — 피싱의 탄생

"AOL 관리자입니다, 비밀번호를 알려주세요"라는 단순 메시지로 시작

2003

가짜 은행 웹사이트 등장

진짜 은행 사이트와 똑같은 페이지를 만들어 로그인 정보 탈취

2010

스피어피싱 본격화 — APT 공격의 시작

국가 기관과 대기업을 표적으로, 맞춤형 첨부파일 공격 급증

2020~

AI 피싱 — 문법 완벽, 개인화 극대화

AI가 SNS를 분석해 "진짜 동료가 쓴 것 같은" 이메일을 자동 생성

🎣

피싱 (Phishing)

불특정 다수에게 같은 메일을 보내는 "그물 던지기"

🏹

스피어피싱 (Spearphishing)

특정인을 조사한 뒤 맞춤형 메일을 보내는 "작살 던지기"

🐳

웨일링 (Whaling)

CEO, CFO 등 고위 임원만을 노리는 "고래잡이"

#3. 실제 피싱 메일 사례 분석

실제로 유포된 스피어피싱 이메일은 어떻게 생겼을까요? 세 가지 대표 사례를 살펴봅니다.

사례 1: 가짜 청구서 공격

From: accounting@samsumg-partner.com
To: 김재무@target-company.co.kr
Subject: [긴급] 3월 미지급 청구서 확인 요청
---
김재무 과장님, 안녕하세요.
첨부된 청구서를 확인해 주시기 바랍니다.
📎 첨부: 청구서_2026_03.xlsm (매크로 포함 스프레드시트)
🔍 수상한 점: 도메인이 samsung이 아닌 "samsumg" — 알파벳 하나가 다릅니다. .xlsm은 매크로 포함 파일입니다.

사례 2: 택배 사칭 공격

From: noreply@cj-logist1cs.com
Subject: 배송 실패 — 주소 확인이 필요합니다
고객님의 택배가 배송 실패되었습니다.
첨부된 송장을 확인 후 재배송 요청해 주세요.
📎 첨부: 송장확인.iso (2.3MB)
🔍 수상한 점: logistics의 'i'가 숫자 '1'로 바뀌었고, .iso 파일은 택배 송장과 무관한 디스크 이미지 형식입니다.

사례 3: 동료 사칭 공격

From: lee.manager@gmai1.com
Subject: 지난주 회의록 정리했어요
영수님, 지난주 회의록 첨부합니다.
월요일까지 확인 부탁드려요 :)
📎 첨부: 회의록_0315.docm (매크로 문서)
🔍 수상한 점: gmail이 아닌 "gmai1" (숫자 1), 회사 메일이 아닌 개인 메일 사용, .docm 매크로 문서 첨부

💡 공통 패턴 정리

  • 도메인 철자가 미세하게 다름 (알파벳 ↔ 숫자 치환)
  • "긴급", "즉시", "실패" 등 심리적 압박 키워드 사용
  • .docm, .xlsm, .iso, .hta 등 위험한 확장자의 첨부파일
  • 평소와 다른 메일 주소에서 온 "익숙한 이름"

#4. APT 스피어피싱 캠페인

🕵️ APT = 국가가 후원하는 해커 조직

APT(Advanced Persistent Threat)는 개인 해커가 아니라 국가 정보기관이 지원하는 전문 해킹 조직입니다.
이들의 스피어피싱은 일반 사기꾼과 차원이 다릅니다.

🐻

APT28 (Fancy Bear)

배후: 러시아 군사정보국(GRU)

대표 공격: 2016년 미국 민주당 전국위원회(DNC) 해킹

수법: "Google 보안 경고"로 위장한 이메일 → 비밀번호 변경 링크 클릭 유도 → 이메일 전체 탈취

피해: 수만 건의 내부 이메일 유출, 미국 대선에 영향

🐻‍❄️

APT29 (Cozy Bear)

배후: 러시아 대외정보국(SVR)

대표 공격: 2020년 SolarWinds 공급망 공격

수법: IT 관리 소프트웨어에 악성코드 삽입 → 업데이트를 통해 18,000개 조직에 배포

피해: 미국 정부 기관, 대기업 다수 침해

국내 사례: 북한 연계 공격 (Kimsuky)

타깃: 한국 외교·안보·통일 분야 전문가

수법: "통일부 정책자문 요청" 제목의 이메일에 한글(.hwp) 문서 첨부. 문서를 열면 취약점을 이용해 원격제어 악성코드 설치.

특징: 한국어가 자연스럽고, 실제 존재하는 공무원 이름을 사칭. 수신자의 최근 논문·강연 내용을 인용하여 신뢰도를 높임.

💡 APT 공격이 일반 피싱과 다른 점

구분 일반 피싱범 APT 그룹
목적 금전 탈취 정보 수집, 국가 안보
준비 기간 수 분 ~ 수 시간 수 주 ~ 수 개월
지속성 1회성 수 개월~수 년 잠복

#5. 이메일 시스템 기초 (SMTP)

📮 이메일 = 디지털 우체국 시스템

편지를 보낼 때 우체국→집배원→수취인 순서를 거치듯,
이메일도 보내는 서버 → 중간 서버 → 받는 서버를 거칩니다.

SMTP란?

SMTP(Simple Mail Transfer Protocol)는 이메일을 보내는 규칙(프로토콜)입니다. 우체국에 "이 편지를 이 주소로 보내주세요"라고 맡기는 것과 같습니다.

✉️ 작성 → 📤 SMTP 서버 → 🌐 인터넷 → 📥 수신 서버 → 📬 받은편지함

왜 이메일 위조가 쉬운가?

놀랍게도, SMTP는 보낸 사람 주소를 검증하지 않습니다. 편지 봉투에 아무 주소나 적을 수 있는 것처럼, 이메일도 "From:" 주소를 마음대로 바꿀 수 있습니다.

# 공격자가 보내는 명령 (단순화)
HELO attacker-server.com
MAIL FROM: <ceo@your-company.com> ← 위조!
RCPT TO: <victim@your-company.com>
DATA
Subject: [긴급] 연봉 조정 안내
...

이메일 위조를 막는 3가지 기술

SPF

"이 도메인에서 보내는 서버 목록을 미리 등록"합니다. 목록에 없는 서버에서 온 메일은 의심!

DKIM

"이메일에 디지털 서명(도장)"을 찍습니다. 서명이 없거나 위조되면 가짜!

DMARC

SPF+DKIM을 종합 판단. "인증 실패 시 어떻게 할지" 규칙을 정합니다.

#6. MIME 구조 이해

📦 MIME = 이메일 택배 포장 규격

택배를 보낼 때 상자 안에 물건을 넣고 포장지로 싸듯,
이메일도 텍스트, 이미지, 첨부파일을 MIME이라는 규격으로 포장합니다.

MIME이 필요한 이유

원래 이메일(SMTP)은 영어 텍스트만 전송할 수 있었습니다. 한글? 사진? 파일 첨부? 모두 불가능했습니다. MIME(Multipurpose Internet Mail Extensions)은 이 문제를 해결합니다.

❌

MIME 이전

영어 텍스트만 가능

✅

MIME 이후

한글, 사진, 파일 모두 OK

이메일의 내부 구조 (택배 상자 열어보기)

--- 이메일 헤더 (봉투 겉면) ---
From: sender@example.com
To: receiver@company.com
Subject: 3월 보고서
MIME-Version: 1.0
Content-Type: multipart/mixed
--- 본문 파트 (상자 안 물건 ①) ---
Content-Type: text/html
"안녕하세요, 보고서 첨부합니다..."
--- 첨부 파트 (상자 안 물건 ②) ---
Content-Type: application/vnd.ms-excel
Content-Disposition: attachment; filename="report.xlsm"
UEsDBBQAAAAIANpT... (Base64 인코딩된 파일)

💡 공격자는 MIME을 어떻게 악용하나요?

  • 파일명 위장: "보고서.pdf.exe"처럼 확장자를 속여 실행 파일을 문서로 위장
  • Content-Type 조작: 실제론 실행 파일인데 "image/jpeg"라고 거짓 선언
  • 인코딩 트릭: Base64로 인코딩하면 백신이 악성코드를 탐지하기 어려움

#7. OLE/매크로 기초 개념

🧩 OLE = 문서 안에 다른 프로그램을 끼워넣는 기술

Word 문서 안에 Excel 표를 넣거나, 파워포인트에 동영상을 삽입할 수 있죠?
이것이 OLE(Object Linking and Embedding) 기술입니다.

매크로(Macro)란?

매크로는 문서 안에 들어있는 자동화 프로그램입니다. 마치 TV 리모컨의 "매크로 버튼"처럼, 한 번 누르면 여러 동작이 자동으로 실행됩니다.

✅ 정상적인 사용

  • 엑셀에서 매일 반복하는 계산 자동화
  • 보고서 서식을 한 번에 맞추기
  • 데이터를 자동으로 정리하기

❌ 악의적인 사용

  • 문서를 열면 몰래 악성코드 다운로드
  • 시스템 정보를 외부로 전송
  • 원격제어 도구(RAT)를 설치

"콘텐츠 사용" 버튼의 함정

악성 문서를 열면 노란색 경고 바가 나타납니다: "매크로가 사용 중지되었습니다. [콘텐츠 사용]"

⚠️ 보안 경고: 매크로가 사용 중지되었습니다.
콘텐츠 사용 ← 절대 클릭하지 마세요!

이 버튼을 클릭하는 순간, 문서 안의 매크로가 실행되어 악성코드가 동작합니다. 출처가 불분명한 문서에서는 절대로 "콘텐츠 사용"을 클릭하면 안 됩니다.

#8. VBA란 무엇인가?

🤖 VBA = Office 문서의 로봇 비서

VBA(Visual Basic for Applications)는 Word, Excel 등 Office 프로그램 안에서
자동으로 작업을 수행하는 작은 프로그래밍 언어입니다.

VBA 코드 맛보기 (무해한 예시)

아래는 Excel에서 "Hello!"를 표시하는 간단한 VBA 코드입니다. 이 정도는 전혀 위험하지 않습니다.

' 엑셀에서 메시지를 표시하는 매크로
Sub SayHello()
    MsgBox "Hello! VBA 세계에 오신 것을 환영합니다!"
End Sub

공격자가 VBA를 악용하는 방법

같은 VBA라도 Shell 명령을 사용하면 컴퓨터에 직접 명령을 내릴 수 있습니다.

' ⚠️ 악성 매크로 예시 (실행하지 마세요!)
Sub AutoOpen() ' ← 문서를 열면 자동 실행!
    Shell "powershell -enc JABjAG..."
    ' 인코딩된 PowerShell 명령 실행
    ' → 외부 서버에서 악성코드 다운로드
End Sub
🔑 핵심: AutoOpen은 문서를 열면 자동 실행되는 특수 함수입니다. 사용자가 "콘텐츠 사용"을 클릭하면 즉시 동작합니다.

💡 VBA 자동 실행 트리거 이름

트리거 이름 실행 시점 위험도
AutoOpen 문서를 열 때 🔴 매우 높음
Auto_Open Excel 통합문서 열기 🔴 매우 높음
Document_Open Word 문서 열기 🔴 매우 높음
AutoClose 문서를 닫을 때 🟡 높음

#9. PowerShell 기초 개념

💻 PowerShell = Windows의 만능 리모컨

GUI(그래픽 화면)로 클릭해서 하는 모든 작업을
텍스트 명령어 한 줄로 실행할 수 있는 강력한 도구입니다.

PowerShell이 뭐길래?

Windows에 기본 설치된 명령줄 도구입니다. 시스템 관리자가 서버를 관리할 때 사용하지만, 공격자에게도 매우 유용한 도구입니다. 별도 설치 없이 모든 Windows에서 사용 가능하기 때문입니다.

# 무해한 예시: 현재 날짜와 시간 확인
PS C:\> Get-Date
2026년 3월 18일 화요일 오전 10:30:00
# 무해한 예시: 실행 중인 프로세스 목록
PS C:\> Get-Process | Select-Object -First 3
chrome, explorer, notepad ...

공격자가 PowerShell을 좋아하는 이유

🔑
이미 설치되어 있음 — 추가 도구를 설치할 필요 없어 탐지가 어려움
🔒
암호화 가능 — 명령어를 Base64로 인코딩하여 백신 탐지를 우회
🌐
네트워크 접근 — 외부 서버에서 추가 악성코드를 다운로드 가능
👻
파일리스 공격 — 파일을 디스크에 저장하지 않고 메모리에서만 실행 가능

VBA + PowerShell = 스피어피싱 공격 체인

앞서 배운 내용을 연결하면, 전체 공격 흐름이 보입니다:
