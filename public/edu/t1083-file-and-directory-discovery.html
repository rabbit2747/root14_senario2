File & Directory Discovery

"남의 집 서랍을 하나씩 열어보기" — 파일/디렉토리 탐색

#1. 공격자가 파일을 탐색하는 이유

"남의 집 서랍 열어보기"

도둑이 집에 침입한 후 가장 먼저 하는 일은 서랍을 열어보는 것입니다. 현금, 보석, 중요 서류가 어디 있는지 파악해야 하니까요. 공격자도 시스템에 침투한 후 비밀번호 파일, 설정 파일, 데이터베이스 백업 등 가치 있는 데이터를 찾습니다.

공격자가 찾는 파일 유형

*.txt, *.doc
비밀번호 메모
*.kdbx
KeePass DB
*.conf, *.ini
설정 파일
*.bak, *.sql
DB 백업
*.pem, *.key
인증서/키
*.rdp
원격접속 설정

#2. 탐색 명령어

Windows

C:\> dir /s /b *password*
C:\> dir /s /b *.kdbx
C:\> tree C:\Users /f
# /s=하위디렉토리, /b=간결출력

Linux

$ find / -name "*password*" 2>/dev/null
$ find / -name "*.pem" -o -name "*.key"
$ ls -laR /home/
# 2>/dev/null = 에러 메시지 숨기기

PowerShell 고급 탐색

PS> Get-ChildItem -Path C:\ -Recurse -Include *.txt,*.doc -ErrorAction SilentlyContinue | Select-String "password"
# 파일 내용까지 검색하여 비밀번호가 포함된 파일을 찾음
