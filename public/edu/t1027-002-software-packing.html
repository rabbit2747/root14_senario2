Software Packing

실행 파일을 압축/암호화하여 AV 탐지를 우회하는 기법

#1. Software Packing이란?

"선물 포장" 비유

악성코드를 선물 포장지로 감싸는 것입니다. 보안 소프트웨어(X-ray 검사)는 포장 안에 무엇이 있는지 볼 수 없습니다. 실행할 때만 포장을 풀고(언패킹) 진짜 악성코드가 메모리에 로드됩니다. UPX, Themida, VMProtect 등이 대표적인 패커입니다.

UPX

오픈소스 압축 패커, 가장 많이 사용됨

Themida

상용 코드 보호, 강력한 안티-디버깅

VMProtect

가상머신 기반 코드 난독화

#2. 패킹 분석 기법

# PE 헤더 분석으로 패킹 탐지
$ python3 pefile_analysis.py malware.exe
Section .UPX0: VirtualSize=0x15000 RawSize=0x0 ← 의심!
Section .UPX1: VirtualSize=0x8000 RawSize=0x7200
Entropy: 7.89 ← 매우 높음 (암호화/압축)

탐지 방법

  • 엔트로피 분석: 7.0 이상이면 암호화/압축 가능성 높음
  • 섹션 이름: UPX0, .themida 등 패커 고유 섹션명
  • Import Table: GetProcAddress, LoadLibrary만 있으면 동적 로딩 의심
  • PE 섹션 크기 불일치: VirtualSize >> RawSize는 런타임 언패킹 지표
  • YARA 규칙: 패커별 시그니처 패턴 매칭
