다크웹에서 사이버 무기상에게 정보를 구매하는 공격자들

#1. 기술 데이터 마켓이란?

"사이버 무기 중개상"

기술 데이터 구매란 공격자가 합법적 또는 불법적 채널을 통해 타겟 조직에 대한 기술 정보를 구매하는 행위입니다. 여기에는 유출된 데이터베이스, 네트워크 스캔 결과, 취약점 정보, 인증 정보, 내부 문서 등이 포함됩니다.

구매 가능한 데이터 유형

유출된 크레덴셜
이메일/패스워드 조합, 세션 토큰, API 키
가격: $5~$500/계정
제로데이 익스플로잇
패치되지 않은 취약점 공격 코드
가격: $10K~$2.5M
네트워크 접근 권한
VPN 계정, RDP 접속 정보, 내부 네트워크 맵
가격: $500~$100K
Shodan/Censys 데이터
인터넷 노출 서비스 스캔 결과
가격: 무료~$499/월

#2. 다크웹 데이터 거래 생태계

다크웹(Tor 네트워크)에서는 IAB(Initial Access Broker)라 불리는 초기 접근 중개상이 활동합니다. 이들은 직접 해킹으로 얻은 접근 권한을 랜섬웨어 그룹에 판매합니다.

IAB(Initial Access Broker) 운영 방식

# 다크웹 포럼 게시글 예시
[SELL] 한국 대기업 VPN 접근 권한
- 매출: $2B+ | 직원: 5,000+
- 접근: Citrix VPN (Domain Admin)
- AV/EDR: CrowdStrike (우회 가능)
시작가: $15,000 BTC

합법적 데이터 소스의 악용

  • ● Shodan, Censys: 인터넷에 노출된 서비스/장치 검색
  • ● SpyCloud, Have I Been Pwned: 유출된 크레덴셜 조회
  • ● ZoomInfo, LinkedIn Sales Navigator: 임직원 정보 수집

#3. 방어와 모니터링

다크웹 모니터링

전문 DarkWeb 모니터링 서비스(Flashpoint, Intel471, Kela)를 활용하여 자사 데이터가 거래되고 있는지 지속적으로 감시합니다. 유출이 감지되면 즉시 크레덴셜 리셋과 영향 범위를 평가합니다.

공격 표면 관리(ASM)

자사의 외부 노출 자산을 지속적으로 스캔하고, Shodan/Censys에서 보이는 것과 동일한 관점으로 공격 표면을 평가합니다. 불필요한 서비스는 즉시 차단합니다.
