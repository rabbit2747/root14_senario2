#1. 대칭키 암호화란?

🔑 ➜ 📝 ➜ 🔐 ➜ 📨

"같은 열쇠로 잠그고 여는 비밀 편지"

친구와 비밀 편지를 주고받을 때, 둘 다 같은 열쇠(Key)를 가지고 있어야 합니다. 보내는 사람이 그 열쇠로 편지를 잠그고(암호화), 받는 사람이 같은 열쇠로 열어봅니다(복호화). 해커와 C2 서버도 같은 방식으로 통신합니다.

AES와 RC4

AES(Advanced Encryption Standard)는 미국 정부가 사용하는 강력한 암호화 알고리즘입니다. RC4는 속도가 빠르지만 취약점이 알려진 오래된 알고리즘입니다. 해커들은 AES로 C2 통신을 암호화하여 네트워크 분석을 무력화합니다.

🔐
AES-256
군사 등급 암호화, 해독 사실상 불가능
⚡
XOR / RC4
빠르지만 간단, 초보 악성코드에 자주 사용

#2. 커스텀 프로토콜 암호화

왜 커스텀 암호화를 사용하나?

보안 장비(IDS/IPS)는 알려진 악성코드의 통신 패턴(시그니처)을 탐지합니다. 해커가 자체 제작한 암호화 프로토콜을 사용하면 기존 시그니처로는 탐지가 불가능합니다.

1
XOR 인코딩가장 단순한 암호화 — 데이터와 키를 비트 단위로 XOR 연산
2
커스텀 AES 래퍼AES 암호화 + Base64 인코딩 + 랜덤 패딩 추가
3
다중 레이어 암호화XOR → AES → Base64 순서로 다겹 암호화
# XOR 인코딩 예시 (Python)
key = 0x5A
plaintext = "whoami"
encrypted = ''.join(chr(ord(c) ^ key) for c in plaintext)
# 결과: 네트워크에서 알아볼 수 없는 바이너리 데이터
