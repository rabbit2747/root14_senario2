Container CLI

Docker/kubectl 등 컨테이너 CLI를 통한 악성 명령 실행 및 탈출

#1. 개념과 원리

컨테이너 CLI 악용이란?

Docker CLI, kubectl, podman 등 컨테이너 관리 도구를 악용하여 컨테이너를 생성/조작하고, 호스트 시스템으로 탈출합니다. 특권 컨테이너 실행, 호스트 파일시스템 마운트, CronJob 악용 등이 포함됩니다.

Docker 탈출

--privileged 또는 호스트 마운트로 호스트 접근

kubectl 악용

RBAC 우회로 시크릿/파드 조작

이미지 변조

악성 코드가 포함된 컨테이너 이미지 배포

#2. 공격 기법 분석

# 특권 컨테이너로 호스트 탈출
docker run -it --privileged --pid=host ubuntu nsenter -t 1 -m -u -i -n bash
# kubectl로 시크릿 수집
kubectl get secrets --all-namespaces -o json
# 악성 CronJob 생성
kubectl create -f malicious-cronjob.yaml
// 컨테이너 탈출 = 호스트 장악

공격 분석

  • Docker 소켓 악용: /var/run/docker.sock 마운트로 호스트 제어
  • 특권 컨테이너: --privileged로 호스트 커널 접근
  • RBAC 우회: 과도한 권한의 ServiceAccount 악용
  • 이미지 포이즈닝: 공개 레지스트리에 악성 이미지 등록

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • PSP/OPA: Pod Security Policy로 특권 컨테이너 차단
  • RBAC 최소 권한: ServiceAccount 권한 최소화
  • 이미지 서명: Cosign으로 이미지 무결성 검증
  • 런타임 보안: Falco로 컨테이너 이상 활동 탐지
  • 네트워크 정책: 파드 간 통신 제한
