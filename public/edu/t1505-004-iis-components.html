IIS Components

IIS 네이티브 모듈/ISAPI 필터를 이용한 스텔스 백도어

#1. IIS 악성 모듈이란?

🌐 ➜ ⚙️ ➜ 🔌 ➜ 💥

"IIS 파이프라인에 악성 모듈을 주입"

IIS의 네이티브 모듈이나 ISAPI 필터는 모든 HTTP 요청을 가로채어 처리할 수 있습니다. 공격자는 악성 모듈을 IIS 요청 파이프라인에 등록하여 모든 웹 트래픽을 모니터링하고, 특정 조건에서 백도어 기능을 활성화합니다.

IIS 모듈 유형

# Native Module (C++ DLL)
appcmd.exe install module /name:BackdoorModule /image:C:\path\to\module.dll
# Managed Module (.NET DLL)
appcmd.exe add module /name:BackdoorModule /type:Namespace.ClassName

왜 위험한가?

깊은 통합

IIS 파이프라인에 통합되어 별도 파일 없이 모든 요청을 처리합니다.

자격 증명 가로채기

인증 요청을 가로채어 평문 비밀번호를 수집할 수 있습니다.

#2. 공격 기법 분석

IIS 악성 모듈 등록

appcmd.exe를 사용하여 악성 네이티브 모듈을 IIS에 등록합니다.

# 악성 네이티브 모듈 설치
C:\Windows\System32\inetsrv\appcmd.exe install module /name:"SecurityFilter" /image:"C:\Windows\System32\inetsrv\secfilter.dll" /add:true

악성 모듈 기능

1.

자격 증명 수집: POST 요청에서 username/password 파라미터를 가로채어 기록

2.

숨은 백도어: 특정 HTTP 헤더(X-Debug: true)가 포함된 요청에만 명령 실행 기능 활성화

3.

트래픽 변조: 응답에 악성 JavaScript를 주입하여 클라이언트 공격

탐지 및 방어 전략

🛡️

IIS 모듈 감사: appcmd list module로 등록된 모듈을 정기적으로 검토

🛡️

DLL 서명 검증: IIS 모듈 DLL의 디지털 서명을 확인하여 비인가 모듈 탐지

🛡️

applicationHost.config 모니터링: IIS 구성 파일 변경을 실시간 감시
