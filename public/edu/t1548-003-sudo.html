Sudo and Sudo Caching

관리자 비밀번호를 한 번 입력하면 일정 시간 동안 자유 통행이 가능한 허점

#1. Sudo란?

"임시 관리자 카드" 비유

회사에서 서버실에 들어가려면 관리자에게 임시 출입카드를 받아야 합니다. sudo는 Linux/macOS에서 "이 한 번만 관리자 권한으로 실행해주세요"라고 요청하는 명령입니다. 비밀번호를 입력하면 일정 시간(기본 15분) 동안 다시 비밀번호를 묻지 않습니다. 이것이 Sudo Caching입니다.

sudoers 파일의 역할

1/etc/sudoers: 누가, 어떤 명령을 sudo로 실행할 수 있는지 정의
2NOPASSWD 옵션: 비밀번호 없이 sudo 실행 허용 (위험!)
3timestamp_timeout: 캐싱 시간 설정 (0 = 매번 물어봄)
# /etc/sudoers 예시
root ALL=(ALL:ALL) ALL
webadmin ALL=(ALL) NOPASSWD: /usr/bin/vim, /usr/bin/less
# webadmin 사용자는 vim, less를 비밀번호 없이 root로 실행 가능

#2. Sudo 악용 기법

NOPASSWD 남용과 Sudo Caching 악용

관리자가 편의를 위해 NOPASSWD를 설정하거나, sudo 캐시 시간을 길게 설정하면 공격자가 이를 악용합니다. 특히 vim, find, less 같은 프로그램은 내부에서 셸을 실행할 수 있어 "sudo escape"가 가능합니다.

GTFOBins: sudo vim

vim 편집기에서 :!bash 명령으로 root 셸을 획득하는 기법

$ sudo vim -c ':!bash'
# whoami
root

Sudo Caching 악용

관리자가 sudo를 사용한 직후, 캐시가 유효한 동안 공격자가 sudo를 무인증 실행

# 관리자가 sudo 실행 후...
$ sudo -n cat /etc/shadow
[패스워드 해시 출력됨]

방어 방법

  • NOPASSWD 최소화: 꼭 필요한 명령만 허용하고, 셸 이스케이프가 가능한 프로그램(vim, less, find) 제외
  • timestamp_timeout=0: sudo 캐싱 비활성화 (매번 비밀번호 입력)
  • sudo -l 모니터링: 사용자의 sudo 권한 조회 시도를 로깅
  • tty_tickets: 터미널별로 별도의 sudo 세션 관리
