"아파트 단지의 모든 현관문을 노크해보기" — 네트워크 서비스 탐색

#1. 포트 스캐닝이란?

"아파트 단지의 현관문 노크"

아파트 단지에 100세대가 있다고 상상하세요. 도둑이 하나씩 현관문을 두드려보며 "여기 문 열렸네!", "여기는 잠겼네"를 확인합니다. 포트 스캐닝(Port Scanning)은 네트워크에서 열린 포트(서비스)를 찾는 것으로, 마치 열린 문을 찾는 것과 같습니다.

포트 = 서비스의 출입구

컴퓨터는 총 65,535개의 포트를 가지고 있으며, 각 포트는 특정 서비스와 연결됩니다.

22
SSH
80
HTTP
443
HTTPS
3389
RDP

왜 위험한가?

공격자는 포트 스캐닝으로 어떤 서비스가 실행 중인지 파악한 후, 해당 서비스의 알려진 취약점(CVE)을 이용해 침투합니다. 열린 포트 = 잠재적 공격 표면입니다.

#2. Nmap 실전 기법

Nmap(Network Mapper)은 가장 대표적인 포트 스캐닝 도구입니다. 보안 전문가와 해커 모두가 사용하는 양날의 검입니다.

SYN Scan (-sS)

nmap -sS -p 1-1000 192.168.1.0/24

"반쯤 열어보기" — TCP 3-way handshake를 완료하지 않아 로그에 잘 남지 않습니다. 가장 은밀한 스캔 방식입니다.

Version Detection (-sV)

nmap -sV -sC 10.0.0.5

"서비스 이름표 확인" — 열린 포트에서 실행 중인 소프트웨어의 이름과 버전을 정확히 파악합니다.

Banner Grabbing (배너 그래빙)

서비스에 접속하면 돌아오는 환영 메시지(배너)를 수집하여 소프트웨어 종류와 버전을 파악합니다.

$ nc -v 10.0.0.5 22
SSH-2.0-OpenSSH_7.6p1 Ubuntu-4ubuntu0.3
# 서버의 SSH 버전이 7.6 → CVE-2018-15473 취약점 존재 가능
