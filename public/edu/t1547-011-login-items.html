T1547.011: Login Items (macOS)

Login Items

macOS 로그인 항목에 악성 앱 등록 — 사용자 로그인 시 자동 실행

#1. macOS Login Items란?

🍎 ➜ 📋 ➜ 🔄 ➜ 💥

"macOS 로그인 목록에 몰래 끼어들기"

macOS에서는 사용자가 로그인할 때 자동으로 실행되는 앱 목록을 Login Items라고 합니다. 시스템 환경설정에서 관리할 수 있으며, 공격자는 이 목록에 악성 앱이나 스크립트를 등록하여 macOS 사용자가 로그인할 때마다 악성 코드가 실행되게 합니다.

Login Items 등록 방법

# osascript를 이용한 Login Items 등록
osascript -e 'tell application "System Events" to make login item at end with properties {path:"/path/to/app", hidden:true}'
# LaunchAgents plist를 통한 등록
~/Library/LaunchAgents/com.apple.update.plist

왜 위험한가?

사용자 권한으로 충분

root 권한 없이 현재 사용자 권한만으로 Login Items를 등록할 수 있습니다.

숨김 옵션

hidden 속성을 true로 설정하면 로그인 시 창이 표시되지 않아 사용자가 인지하기 어렵습니다.

#2. 공격 기법 분석

AppleScript를 이용한 등록

osascript 명령으로 Login Items에 악성 앱을 숨김 모드로 등록합니다.

# 악성 앱을 Login Items에 숨김 등록
osascript -e 'tell application "System Events"
  to make login item at end
  with properties {path:"/Users/Shared/.hidden/updater.app",
  hidden:true, name:"SystemUpdater"}'

LaunchAgent plist 활용

LaunchAgents 디렉토리에 plist 파일을 생성하여 로그인 시 자동 실행합니다.

# LaunchAgent plist 생성
<plist version="1.0">
<dict>
  <key>Label</key><string>com.apple.update</string>
  <key>ProgramArguments</key><array>
    <string>/Users/Shared/.hidden/beacon</string>
  </array>
  <key>RunAtLoad</key><true/>
</dict></plist>
