Archive via Utility

"훔친 물건을 가방에 압축 포장" — 데이터 아카이브

#1. 공격자가 데이터를 압축하는 이유

"훔친 물건을 가방에 압축 포장"

도둑이 큰 TV를 훔쳐 나가려면 눈에 띕니다. 하지만 보석을 작은 가방에 담으면 몰래 빠져나갈 수 있죠. 공격자도 수집한 데이터를 압축(Archive)하여 크기를 줄이고, 비밀번호를 걸어 DLP(Data Loss Prevention)의 내용 검사를 우회합니다.

압축의 3가지 목적

📦
크기 축소
전송 속도 향상, 탐지 회피
🔒
비밀번호 보호
DLP 내용 검사 우회
📁
단일 파일화
수천 개 파일을 1개로 통합

#2. 아카이브 명령어

7-Zip

7z a -p"S3cret!" -mhe=on data.7z C:\Loot\

-mhe=on: 파일 이름까지 암호화

WinRAR

rar a -hp"P@ss" -v50m loot.rar C:\Data\

-v50m: 50MB씩 분할 압축

tar (Linux)

tar czf - /data | openssl enc -aes-256-cbc -o out.enc

압축 + AES 암호화 파이프

탐지 포인트

프로세스 모니터링
7z.exe, rar.exe, tar 실행 감지
파일 생성 감시
%TEMP%에 대용량 아카이브 생성
CLI 인자 분석
-p(비밀번호), -mhe(헤더암호화) 감지
