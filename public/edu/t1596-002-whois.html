#1. WHOIS 프로토콜이란?

"도메인의 등기부등본"

WHOIS는 도메인 등록 정보를 조회하는 인터넷 프로토콜(RFC 3912)입니다. 도메인 소유자 이름, 조직, 이메일, 전화번호, 등록일, 만료일, 네임서버 정보가 포함됩니다. GDPR 이후 많은 정보가 마스킹되었지만, 여전히 유용한 정보를 제공합니다.

WHOIS에서 얻을 수 있는 정보

Registrant
등록자 이름/조직
Admin Contact
관리자 연락처
Name Server
사용 DNS 서버
Created Date
등록 일자
Expiry Date
만료 일자
Registrar
등록 기관

#2. 공격자의 WHOIS 활용

역방향 WHOIS

같은 등록자/조직이 소유한 다른 도메인을 모두 찾아냅니다. 하나의 취약한 도메인이 전체 조직의 진입점이 됩니다.

$ whois -h whois.arin.net "org GOTROOT"
→ 12개 관련 도메인 발견

만료 도메인 탈취

WHOIS 만료일이 임박한 도메인을 모니터링하여, 만료 즉시 등록하여 피싱이나 C2에 활용합니다.

WHOIS Privacy 보호의 한계

  • ● GDPR 이전 데이터가 SecurityTrails, DomainTools에 이력으로 보존
  • ● SSL 인증서의 Organization 필드에 실제 정보가 노출
  • ● DNS SOA 레코드에 관리자 이메일이 포함됨
