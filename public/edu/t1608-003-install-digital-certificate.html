T1608.003
디지털 인증서 설치

공격자가 C2 서버에 SSL/TLS 인증서를 설치하여 암호화된 통신 채널을 구축하는 기법을 학습합니다.

🔐 Chapter 1 — 인증서 설치 개요

공격자는 C2 서버에 SSL/TLS 인증서를 설치하여 통신을 암호화합니다. 이를 통해 네트워크 보안 장비의 트래픽 검사를 회피하고, 합법적인 HTTPS 트래픽으로 위장합니다.

인증서 유형
  • • Let's Encrypt 무료 DV 인증서
  • • 자체 서명(Self-signed) 인증서
  • • 탈취된 합법 기업 인증서
  • • 와일드카드 인증서
설치 목적
  • • C2 통신 HTTPS 암호화
  • • 피싱 사이트 신뢰도 확보
  • • 네트워크 IDS/IPS 우회
  • • 합법 서비스 사칭

# C2 서버에 Let's Encrypt 인증서 자동 설치

$ certbot --nginx -d c2.malicious-cdn[.]com --non-interactive --agree-tos --email attacker@proton.me

[!] C2 서버에 합법 인증서 설치 완료 — HTTPS 통신 가능

⚡ Chapter 2 — C2 인증서 배포

Domain Fronting

CDN(Cloudflare, Azure CDN 등)의 인증서를 활용하여 실제 C2 도메인을 숨깁니다. TLS SNI에는 합법 도메인을, HTTP Host 헤더에는 C2 도메인을 사용합니다.

리다이렉터 + 인증서

여러 단계의 리다이렉터에 각각 인증서를 설치하여, 최종 C2 서버의 IP를 보호합니다. Apache mod_rewrite로 합법 트래픽과 C2 트래픽을 분리합니다.

🛡️ Chapter 3 — 탐지와 방어

탐지
  • • CT 로그에서 유사 도메인 인증서 발급 모니터링
  • • JA3 핑거프린트로 비정상 TLS 클라이언트 식별
  • • TLS 인터셉션으로 암호화 트래픽 내용 검사
  • • 인증서 유효기간/발급자 이상 탐지
방어
  • • DNS-over-HTTPS(DoH) 트래픽 모니터링
  • • Domain Fronting 차단 정책
  • • HSTS + Certificate Pinning
  • • 네트워크 세그멘테이션
