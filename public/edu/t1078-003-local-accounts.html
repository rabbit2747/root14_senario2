T1078.003: Local Accounts

Initial Access

Local Accounts

로컬 계정의 SAM 해시 덤프, Pass-the-Hash, 백도어 계정 생성

#1. 개념과 원리

로컬 계정 악용이란?

운영체제에 생성된 로컬 사용자 계정을 탈취하거나 새로 생성하여 시스템에 접근합니다. SAM 데이터베이스에서 해시를 덤프하거나, 비밀번호 스프레이 공격, 백도어 계정 생성 등이 포함됩니다. LAPS(Local Administrator Password Solution) 미적용 환경에서 특히 위험합니다.

SAM 해시 덤프

Mimikatz/secretsdump로 NTLM 해시 추출

Pass-the-Hash

탈취한 해시로 비밀번호 없이 인증

백도어 계정

net user로 관리자 그룹에 숨겨진 계정 생성

#2. 공격 기법 분석

# SAM 해시 덤프 + Pass-the-Hash
secretsdump.py -sam SAM -system SYSTEM LOCAL
mimikatz # sekurlsa::logonpasswords
# 백도어 로컬 계정 생성
net user support$ P@ssw0rd! /add
net localgroup administrators support$ /add

공격 분석

  • SAM 덤프: 레지스트리에서 SAM/SYSTEM 하이브 추출
  • PtH: NTLM 해시로 비밀번호 없이 원격 인증
  • $ 계정: 계정명 끝에 $를 붙여 net user에서 숨김
  • 동일 비밀번호: LAPS 미적용 시 모든 시스템 동일 관리자 비밀번호

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • LAPS: 각 시스템마다 고유한 로컬 관리자 비밀번호 자동 관리
  • Credential Guard: 가상화 기반 자격증명 보호
  • Event 4720: 새 계정 생성 이벤트 모니터링
  • SAM 접근 제한: LSA 보호 활성화
  • 비밀번호 정책: 최소 12자, 복잡도, 히스토리
