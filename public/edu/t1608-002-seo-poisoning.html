T1608.002
SEO 포이즈닝

검색 엔진 최적화(SEO)를 악용하여 악성 다운로드 사이트를 검색 결과 상위에 노출시키는 기법을 학습합니다.

🔍 Chapter 1 — SEO 포이즈닝 개요

SEO 포이즈닝은 검색 결과를 조작하여 사용자가 악성 웹사이트를 방문하도록 유도하는 기법입니다. 사용자가 소프트웨어 다운로드, 문서 양식, 기술 지원을 검색할 때 악성 사이트가 상위에 노출됩니다.

주요 타겟 키워드
  • • "무료 PDF 편집기 다운로드"
  • • "TeamViewer 크랙 다운로드"
  • • "연말정산 양식 다운로드"
  • • "Visual Studio 무료 다운로드"
SEO 조작 기법
  • • 키워드 스터핑 (대량 키워드 삽입)
  • • 클로킹 (검색봇과 사용자에게 다른 콘텐츠)
  • • 링크 팜 (대량 백링크 생성)
  • • 해킹된 사이트의 SEO 평판 악용

# Google 검색 결과 분석 — 악성 사이트 감지

$ python3 google_dorking.py "free pdf editor download" --results 5

[1] pdf-editor-free[.]download — MALICIOUS (registered 3 days ago)

[2] adobe.com/acrobat — LEGITIMATE

[3] free-pdf-tools[.]net — SUSPICIOUS (excessive redirects)

[4] smallpdf.com — LEGITIMATE

[5] pdfescape.com — LEGITIMATE

⚡ Chapter 2 — 공격 기법

Google Ads 악용 (Malvertising)

합법 소프트웨어의 Google 광고를 구매하여 검색 결과 최상단에 악성 다운로드 링크를 노출합니다. 광고는 정상 URL을 표시하지만, 클릭 시 악성 사이트로 리다이렉트됩니다.

해킹된 사이트 SEO 하이재킹

높은 검색 순위를 가진 합법 사이트를 해킹하여 악성 다운로드 페이지를 삽입합니다. 사이트의 기존 SEO 평판이 자동으로 적용되어 빠르게 상위에 노출됩니다.

🛡️ Chapter 3 — 탐지와 방어

탐지
  • • 신규 등록 도메인(NRD) 필터링
  • • 다운로드 파일 자동 샌드박스 분석
  • • 검색 광고 클릭 후 리다이렉트 체인 분석
  • • 브라우저 격리(Browser Isolation)
방어
  • • 공식 소프트웨어 다운로드 포털 운영
  • • AppLocker/WDAC로 미승인 실행 차단
  • • 사용자 교육 — 공식 사이트 직접 방문
  • • DNS 보호 서비스 활용
