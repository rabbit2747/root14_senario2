#1. 도메인 속성이란?

🌐 ➜ 📋 ➜ 🏢 ➜ 🔍

"인터넷 부동산의 등기부등본"

부동산의 등기부등본에 소유자, 주소, 설정일이 기록되듯이, 도메인 속성(Domain Properties)에는 도메인 소유자, 등록기관, 네임서버, 만료일 등이 기록됩니다. 공격자는 WHOIS 조회를 통해 이 정보를 수집하여 조직의 인프라 구조를 파악합니다.

📝 ➜ 🏠 ➜ 📍 ➜ 🗓️

"도메인에서 알 수 있는 것들"

도메인 속성을 통해 등록자 정보(이름, 이메일, 전화번호), 등록기관(GoDaddy, Namecheap 등), 네임서버(DNS 인프라), 등록/만료일(인프라 변경 시점 추정), 관련 도메인(동일 소유자의 다른 사이트)을 파악할 수 있습니다.

#2. WHOIS와 등록 정보 분석

WHOIS는 도메인의 "신분증"을 확인하는 프로토콜입니다. 공격자는 WHOIS 데이터에서 조직 구조, 인프라 제공업체, 관리자 연락처를 추출합니다.

WHOIS 조회 결과 예시

$ whois example-corp.com

Domain Name: EXAMPLE-CORP.COM
Registry Domain ID: 1234567890_DOMAIN
Registrar: GoDaddy.com, LLC
Created Date: 2018-03-15T12:00:00Z
Expiry Date: 2026-03-15T12:00:00Z
Updated Date: 2025-01-10T08:30:00Z

Registrant Name: John Smith
Registrant Organization: Example Corporation
Registrant Email: admin@example-corp.com
Registrant Phone: +1.5551234567

Name Server: ns1.cloudflare.com
Name Server: ns2.cloudflare.com
DNSSEC: unsigned

공격자가 WHOIS에서 추출하는 핵심 정보

  • 등록자 이메일/전화: 소셜 엔지니어링, 피싱 공격의 시작점
  • 네임서버: DNS 인프라 파악 (Cloudflare, AWS Route53 등)
  • 만료일: 만료 직전 도메인 탈취(Domain Hijacking) 가능성
  • 등록기관: 등록기관 취약점을 이용한 도메인 탈취
  • DNSSEC 미설정: DNS 스푸핑 공격 가능성 확인

WHOIS Privacy 보호란?

GDPR 시행 이후 많은 등록기관이 WHOIS Privacy Protection을 제공합니다. 이를 사용하면 등록자의 실제 이름, 이메일, 전화번호가 대리 정보로 대체됩니다. 하지만 공격자는 역사적 WHOIS 데이터, SSL 인증서 정보, DNS 기록 등을 통해 실제 소유자를 추적할 수 있습니다.
