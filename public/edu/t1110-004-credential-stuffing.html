Credential Access

Credential Stuffing

유출된 자격 증명을 다른 서비스에 대입하는 공격

#1. Credential Stuffing이란?

"유출된 열쇠 묶음" 비유

다크웹에서 유출된 ID/비밀번호 조합을 수집한 뒤, 이를 다른 웹사이트에 자동으로 대입하여 비밀번호 재사용 계정을 찾아내는 공격입니다. 사용자의 80%가 비밀번호를 재사용한다는 통계가 이 공격의 핵심입니다.

Password Spraying과 차이점

하나의 비밀번호 → 다수 계정

패턴 탐지 용이

Credential Stuffing

유출된 ID+PW 쌍 → 타 서비스 대입

정상 로그인처럼 보임

공격 흐름

  1. 다크웹에서 유출된 자격 증명 데이터베이스(Combo List) 구매/수집
  2. 중복 제거 및 대상 서비스별 포맷 정리
  3. 자동화 도구(Sentry MBA, OpenBullet)로 대량 로그인 시도
  4. 성공한 계정에서 개인정보 탈취 또는 금전 피해 유발

#2. 공격 기법

주요 공격 도구

  • OpenBullet: 설정 파일(Config)로 다양한 사이트 타겟팅
  • Sentry MBA: GUI 기반 크리덴셜 스터핑 도구
  • Hydra: CLI 기반 온라인 패스워드 공격 도구
  • Custom Python Scripts: requests + 프록시 로테이션
# Python Credential Stuffing 예시 (교육용)
import requests
with open("combo_list.txt") as f:
for line in f:
email, password = line.strip().split(":")
r = requests.post("https://target.com/login",
data={"email": email, "password": password},
proxies={"https": next(proxy_pool)})
if "dashboard" in r.url:
print(f"[HIT] {email}:{password}")

방어 방법

  • MFA(다중 인증): 비밀번호가 맞아도 2차 인증 필요
  • CAPTCHA: 자동화 도구 차단
  • 유출 비밀번호 차단: Have I Been Pwned API와 연동하여 유출 비밀번호 거부
  • 속도 제한(Rate Limiting): IP당/계정당 로그인 시도 횟수 제한
  • 디바이스 핑거프린팅: 비정상적인 브라우저/디바이스 패턴 탐지
