#1. VPS와 공격 인프라

💰 ➜ 🖥️ ➜ 🔧 ➜ 💥

"비트코인으로 서버를 임대하면 누구인지 알 수 없다"

공격자는 VPS(Virtual Private Server)를 암호화폐, 도용된 카드 등으로 익명 구매하여 공격 인프라의 기반으로 사용합니다. VPS는 C2 서버, 피싱 서버, 스캐닝 프록시, 데이터 수집 서버 등 다양한 용도로 활용됩니다.

C2 서버
악성코드 제어
피싱 서버
가짜 로그인 호스팅
프록시/VPN
IP 세탁
데이터 수집
유출 데이터 임시 저장

#2. Bulletproof 호스팅

Bulletproof 호스팅이란?

법적 규제가 느슨한 국가에 위치하여 불법 콘텐츠나 악성 활동에 대한 신고를 무시하는 호스팅 서비스입니다. 테이크다운 요청에도 서비스를 유지하므로 공격자의 인프라가 오래 생존합니다.

  • ● DMCA/법적 요청 무시하는 호스팅 업체
  • ● 암호화폐만으로 결제 가능 (신원 확인 없음)
  • ● 러시아, 몰도바, 세이셸 등에 주로 위치

방어 전략

  • ● 알려진 Bulletproof 호스팅 IP 대역 차단
  • ● 위협 인텔리전스 피드를 통한 악성 IP 실시간 차단
  • ● 신규/저평판 도메인에 대한 접근 제한
  • ● GeoIP 기반 비정상 트래픽 모니터링
