#1. 디스크 와이핑이란?

🔥 ➜ 💽 ➜ 0️⃣ ➜ 💀

"증거 인멸을 위해 사무실을 불태우기"

랜섬웨어는 돈을 요구하기 위해 파일을 암호화합니다. 하지만 디스크 와이핑(Disk Wipe)은 복구 자체를 불가능하게 만드는 것이 목적입니다. 해커가 목표를 달성한 후 증거를 완전히 파괴하거나, 국가 차원의 사이버 공격에서 상대방의 인프라를 무력화하기 위해 사용합니다.

와이핑의 두 가지 유형

MBR/파티션 와이핑

디스크의 부팅 영역(MBR)을 0으로 덮어씀. 운영체제 부팅 불가능

전체 디스크 와이핑

디스크 전체를 0 또는 랜덤 데이터로 덮어씀. 데이터 완전 파괴

#2. MBR 덮어쓰기, dd, Shamoon

실전 사례: Shamoon (2012/2016)

Shamoon은 사우디아라비아 석유 회사 Saudi Aramco를 공격하여 35,000대 이상의 컴퓨터를 와이핑한 악성코드입니다. MBR을 덮어쓰고 파일을 파괴하여 회사 운영을 마비시켰습니다.

# MBR 덮어쓰기 (Linux)
dd if=/dev/zero of=/dev/sda bs=512 count=1
# 전체 디스크 와이핑
dd if=/dev/zero of=/dev/sda bs=1M
# Windows: format + diskpart clean all
diskpart → select disk 0 → clean all

국가 차원 공격

Shamoon, NotPetya, WhisperGate 등 국가 지원 APT 그룹이 인프라 파괴 목적으로 사용

증거 파괴

침투 후 포렌식 증거를 제거하기 위해 관련 시스템을 와이핑
