#1. 워드리스트 스캐닝이란?

📖 ➜ 🔑 ➜ 🚪 ➜ 💡

"사전의 단어로 자물쇠를 여는 도둑"

도둑이 비밀번호 목록을 가지고 모든 조합을 시도하듯, 공격자는 미리 준비된 워드리스트(단어 목록)를 사용하여 웹 서버의 숨겨진 디렉토리, 서브도메인, 파일을 찾아냅니다. /admin, /backup, /config 같은 일반적인 경로부터 기업 특화된 이름까지 수천~수만 개의 후보를 자동으로 시도합니다.

📂 ➜ 🌐 ➜ 🔍 ➜ 🎯

"세 가지 주요 스캐닝 유형"

디렉토리 브루트포싱은 /admin, /backup 같은 숨겨진 경로를 찾고, 서브도메인 열거는 dev.target.com, staging.target.com 같은 하위 도메인을 발견하며, 파일 퍼징은 .env, .git/config 같은 민감한 파일을 탐지합니다.

주요 워드리스트 도구

🔨
Gobuster
Go 기반 고속 디렉토리 스캐너
🌀
ffuf
빠른 웹 퍼저 (Fuzz Faster U Fool)
📋
SecLists
보안 테스트 워드리스트 모음

#2. 디렉토리/서브도메인 퍼징

Gobuster 디렉토리 스캔

$ gobuster dir -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/common.txt -t 50
/admin (Status: 302) [Size: 0]
/api (Status: 200) [Size: 1245]
/backup (Status: 403) [Size: 278]
/config (Status: 403) [Size: 278]
/uploads (Status: 200) [Size: 4521]

ffuf 서브도메인 열거

$ ffuf -u https://FUZZ.target.com -w subdomains-top1million.txt -mc 200,301,302
dev [Status: 200, Size: 3421]
staging [Status: 200, Size: 8901]
api [Status: 301, Size: 0]
internal [Status: 200, Size: 12045]

탐지 포인트

  • ● WAF 로그: 단일 IP에서 대량 404 에러 발생 패턴
  • ● 웹 서버 로그: 비정상적 User-Agent(Gobuster, ffuf 등)
  • ● Rate Limiting: 초당 수십~수백 건의 요청 감지

#3. 탐지 및 방어

방어 전략

WAF Rate Limiting

동일 IP의 초당 요청 수를 제한하여 자동화 스캐닝을 차단합니다.

커스텀 에러 페이지

404 페이지에서 서버 정보를 노출하지 않도록 설정합니다.

디렉토리 리스팅 비활성화

Apache/Nginx에서 Options -Indexes 설정으로 디렉토리 목록 노출을 방지합니다.

민감 파일 접근 제한

.env, .git, /backup 등의 경로에 대한 접근을 웹 서버 설정에서 차단합니다.
