#1. 봇넷이란?

"좀비 군단"

봇넷(Botnet)은 악성코드에 감염된 수천~수백만 대의 컴퓨터(봇/좀비)가 하나의 C2(Command & Control) 서버의 명령을 따르는 네트워크입니다. DDoS 공격, 스팸 발송, 크리덴셜 스터핑, 크립토마이닝에 활용됩니다.

봇넷 임대 서비스(BaaS)

다크웹에서는 봇넷을 시간 단위로 임대하는 Botnet-as-a-Service가 성행합니다. 기술이 없는 공격자도 돈만 있으면 DDoS 공격을 수행할 수 있습니다. 평균 1시간 DDoS: $50~$300, 1주일: $500~$2,000.

대표적 봇넷 사례

Mirai
IoT 장치 대상, 2016년 Dyn DNS 1.2Tbps DDoS
Emotet
이메일 기반 확산, 랜섬웨어 배포 플랫폼
TrickBot
뱅킹 트로이목마 → 범용 봇넷으로 진화

#2. 봇넷 아키텍처

중앙 집중형 (C2)

하나의 C2 서버가 모든 봇에 명령을 내립니다. 관리가 쉽지만, C2 서버가 차단되면 전체 봇넷이 무력화됩니다.

# C2 구조
Bot → C2 Server → Operator
취약점: SPOF(단일 장애점)

P2P 분산형

봇 간 직접 통신으로 명령을 전파합니다. 중앙 서버가 없어 차단이 매우 어렵습니다. GameOver Zeus가 대표적입니다.

# P2P 구조
Bot ↔ Bot ↔ Bot ↔ Bot
장점: 복원력, 은닉성

DGA (Domain Generation Algorithm)

봇넷은 매일 수천 개의 랜덤 도메인을 생성하고, 그 중 하나만 등록하여 C2로 사용합니다. 방어측은 어떤 도메인이 활성화될지 예측할 수 없어 차단이 어렵습니다.

#3. 탐지와 대응

네트워크 기반 탐지

  • ● DGA 도메인 탐지: 엔트로피 분석, 머신러닝 기반 분류
  • ● DNS 싱크홀링: 악성 도메인을 제어된 서버로 리다이렉트
  • ● 비정상 트래픽 패턴: 주기적 비콘, 비정상 DNS 쿼리량 모니터링

호스트 기반 방어

  • ● IoT 기기 기본 비밀번호 변경 (Mirai 방지)
  • ● 네트워크 세그멘테이션으로 감염 확산 차단
  • ● EDR/XDR로 봇 행위(비콘, 횡이동) 탐지
