성문의 경비병을 파악하는 공격자 — 보안 장비 정찰의 세계

#1. 보안 장비 정찰이란?

🏰 ➜ 🛡️ ➜ 🔍 ➜ ⚔️

"성문의 경비병 파악하기"

성을 공격하기 전, 도둑은 먼저 경비병의 종류와 위치를 파악합니다. 네트워크 보안 장비 정찰도 마찬가지입니다. 공격자는 방화벽 제조사와 버전, IDS/IPS 규칙, WAF 종류, VPN 게이트웨이를 식별하여 각 장비에 맞는 우회 전략을 수립합니다.

🔥 ➜ 👁️ ➜ 🛡️ ➜ 🌐

"보안 장비의 종류"

Firewall(Palo Alto, Fortinet, Cisco ASA), IDS/IPS(Snort, Suricata), WAF(Cloudflare, AWS WAF, ModSecurity), VPN Gateway(Cisco AnyConnect, FortiGate), Proxy(Zscaler, Blue Coat), NAC(Cisco ISE), EDR(CrowdStrike, SentinelOne)이 주요 보안 장비입니다.

#2. 보안 장비 핑거프린팅

보안 장비는 HTTP 응답 헤더, SSL 인증서, 에러 메시지, 로그인 페이지 등에서 자신의 정체를 드러냅니다. 공격자는 이런 단서를 통해 정확한 제품과 버전을 식별합니다.

WAF 탐지 예시 (wafw00f)

$ wafw00f https://example-corp.com

                 ______
                /      \
               (  W00f! )
                \  ____/
                 ||
                 ||

[*] Checking https://example-corp.com
[+] The site is behind Cloudflare WAF
[~] Reason: Response headers contain 'cf-ray'
    Server: cloudflare
    X-Content-Type: nosniff (Cloudflare default)

보안 장비를 알면 무엇이 가능한가?

장비의 알려진 취약점(CVE)을 활용한 직접 공격, WAF 우회 페이로드 제작, IDS 규칙에 탐지되지 않는 트래픽 생성, 방화벽 규칙 추측을 통한 허용 포트 탐색이 가능합니다. 예를 들어 Fortinet FortiGate의 CVE-2023-27997은 장비 자체를 장악할 수 있는 치명적 취약점입니다.
