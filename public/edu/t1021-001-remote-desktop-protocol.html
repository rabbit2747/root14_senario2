Remote Desktop Protocol

"원격으로 남의 컴퓨터 화면을 조종하기" — RDP 악용

#1. RDP란?

"원격 조종 리모컨"

RDP(Remote Desktop Protocol, 포트 3389)는 원격에서 다른 컴퓨터의 화면을 그대로 보면서 마우스와 키보드로 조작할 수 있는 프로토콜입니다. IT 관리자가 원격 지원에 사용하지만, 공격자에게는 가장 편리한 침투 도구가 됩니다.

정상 사용

  • IT 관리자의 원격 서버 관리
  • 재택근무 시 사무실 PC 접속
  • 헬프데스크 원격 지원

악용 사례

  • 탈취한 자격증명으로 원격 접속
  • 랜섬웨어 배포 거점으로 활용
  • 인터넷 노출된 RDP 브루트포스

#2. RDP 악용 기법

NLA (Network Level Authentication)

RDP 연결 전 네트워크 수준에서 먼저 인증하는 보안 기능입니다. NLA가 비활성화되면 인증 없이 RDP 화면까지 도달할 수 있어 공격 표면이 커집니다.

reg query "HKLM\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" /v SecurityLayer
SecurityLayer REG_DWORD 0x0 (0 = NLA 미적용!)

RDP 터널링

공격자는 방화벽을 우회하기 위해 SSH나 포트 포워딩으로 RDP 트래픽을 터널링합니다.

$ ssh -L 13389:10.0.0.5:3389 attacker@pivot-server
# 로컬 13389 포트를 통해 내부 RDP에 접속
$ mstsc /v:localhost:13389

SharpRDP — 파일 없는 RDP 공격

GUI 없이 RDP 프로토콜을 통해 원격 명령을 실행하는 도구입니다. 화면이 표시되지 않아 탐지가 더욱 어렵습니다.
