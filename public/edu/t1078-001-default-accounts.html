T1078.001: Default Accounts

Initial Access

Default Accounts

장비/소프트웨어의 기본 계정(admin/admin)을 악용한 초기 접근

#1. 개념과 원리

기본 계정 악용이란?

네트워크 장비, IoT 디바이스, 소프트웨어에 제조사가 설정한 기본 계정(admin/admin, root/root)을 변경하지 않고 사용하면, 공격자가 누구나 알 수 있는 비밀번호로 쉽게 접근합니다. Mirai 봇넷은 62개의 기본 자격증명으로 수십만 대의 IoT 장비를 감염시켰습니다.

네트워크 장비

라우터, 스위치, AP의 admin/admin 기본 계정

IoT 디바이스

IP 카메라, 프린터, NAS의 제조사 기본 비밀번호

관리 콘솔

Jenkins, Tomcat Manager, phpMyAdmin 기본 관리자

#2. 공격 기법 분석

# Mirai 스타일 기본 계정 공격
hydra -L default_users.txt -P default_pass.txt telnet://target
shodan search "default password" port:23,80,443
# 62개의 기본 자격증명으로 IoT 대량 스캔
admin/admin, root/root, admin/1234, admin/(empty)

공격 벡터

  • Shodan/Censys 검색: 인터넷에 노출된 관리 인터페이스 발견
  • 기본 계정 사전 공격: Hydra로 알려진 기본 자격증명 시도
  • 제조사 매뉴얼: 공개된 기본 비밀번호 목록 활용
  • 봇넷 자동화: Mirai처럼 대규모 자동 스캔 및 감염

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • 초기 설정 변경 필수화: 장비 설치 시 기본 비밀번호 변경 강제
  • 네트워크 세분화: IoT/OT 장비를 별도 VLAN으로 격리
  • 자격증명 스캐너: 분기별 기본 계정 사용 여부 자동 점검
  • 포트 차단: Telnet(23) 비활성화, SSH만 허용
  • NAC: 보안 상태 확인 후 네트워크 접근 허용
