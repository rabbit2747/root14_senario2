Network Share Discovery

네트워크 공유 폴더 열거를 통한 데이터 접근 경로 발견

#1. Share Discovery란?

📁 ➜ 🔍 ➜ 📋 ➜ 📦

"네트워크 공유 폴더와 드라이브 열거"

공격자는 net share, net view 등의 명령으로 네트워크의 공유 폴더를 열거합니다. 이를 통해 민감한 파일이 저장된 위치, 백업 공유, 관리자 공유(C$, ADMIN$) 등을 식별합니다.

주요 열거 명령어

net share
net view \\target-server
Get-SmbShare
Get-SmbShareAccess -Name "SharedDocs"

왜 위험한가?

민감 데이터 노출

접근 제어가 느슨한 공유 폴더에서 기밀 문서, 자격 증명 파일을 발견합니다.

관리자 공유 악용

C$, ADMIN$ 등 기본 관리자 공유를 통해 원격 파일 접근이 가능합니다.

#2. 공격 기법 분석

SMB 공유 열거

# 원격 서버 공유 목록
net view \\10.0.1.50 /all

# 관리자 공유 접근 테스트
dir \\10.0.1.50\C$

# PowerShell로 상세 조회
Get-SmbShare -CimSession target | Select Name, Path, Description

탐지 및 방어 전략

🛡️

SMB 감사 로깅: 공유 접근 시도를 Windows Security Event로 기록

🛡️

관리자 공유 비활성화: 불필요한 C$, ADMIN$ 공유를 비활성화

🛡️

접근 제어 강화: 공유 폴더에 최소 권한 원칙 적용
