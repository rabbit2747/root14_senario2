T1027.001: Binary Padding

Defense Evasion

Binary Padding

가방에 쓰레기를 잔뜩 넣어 X-ray를 속이는 기법

#1. 바이너리 패딩이란?

"가방에 쓰레기 채우기" 비유

공항 X-ray 검사기가 특정 크기의 가방만 정밀 검사한다고 가정합니다. 범인은 작은 무기가 든 가방에 신문지와 쓰레기를 잔뜩 채워 크기를 늘립니다. X-ray 기사는 "이건 대형 가방이라 일반 짐이겠지"라고 생각하고 넘깁니다. 이것이 바이너리 패딩입니다.

왜 효과적인가?

#️⃣

해시값 완전 변경

1바이트만 추가해도 SHA-256 해시가 완전히 바뀜. 시그니처 기반 탐지 무력화.

📦

샌드박스 크기 제한 우회

많은 샌드박스가 100MB+ 파일을 분석하지 않음. 패딩으로 크기 부풀리기.

# 악성 파일에 100MB 패딩 추가 예시
C:\> copy /b malware.exe + padding.bin padded_malware.exe
# 또는 PowerShell로 널 바이트 추가
PS> $bytes = [byte[]]::new(100MB); [IO.File]::AppendAllBytes("mal.exe", $bytes)

3

EDR 분석 지연
