T1003.006: DCSync

Credential Access

DCSync

DC인 척하고 도메인 전체 비밀번호를 요청하는 원격 공격

#1. DCSync란?

"가짜 본사" 비유

회사 본사(DC) 간에는 직원 정보를 서로 동기화하는 시스템이 있습니다. DCSync는 공격자가 "나도 본사야, 직원 명부를 보내줘"라고 가짜 요청을 보내는 공격입니다. DC에 직접 접근하지 않고도, 네트워크를 통해 원격으로 모든 비밀번호 해시를 가져올 수 있습니다. NTDS.dit 덤프보다 훨씬 은밀합니다.

필요 권한: 복제 권한

!DS-Replication-Get-Changes: 디렉토리 변경 내용 요청
!DS-Replication-Get-Changes-All: 비밀번호 포함 전체 데이터 요청
iDomain Admins, Enterprise Admins, DC 컴퓨터 계정에 기본 부여

#2. DCSync 공격 원리

Mimikatz lsadump::dcsync

Mimikatz의 dcsync 기능은 MS-DRSR(Directory Replication Service Remote) 프로토콜을 사용해 DC에게 특정 사용자의 복제 데이터를 요청합니다. DC는 이것이 정상적인 DC 간 복제 요청이라고 판단하고 비밀번호 해시를 응답합니다.

# DCSync: 특정 사용자 해시 요청
mimikatz # lsadump::dcsync /domain:corp.local /user:krbtgt
# DCSync: 전체 도메인 해시 요청
mimikatz # lsadump::dcsync /domain:corp.local /all /csv

방어 방법

  • 복제 권한 감사: 비 DC 계정의 Replication 권한 정기 점검
  • Event ID 4662: DS-Replication-Get-Changes 접근 감사
  • 네트워크 모니터링: 비 DC IP에서의 DRSUAPI 트래픽 탐지
