T1070.001: Clear Windows Event Logs

Defense Evasion

Clear Windows Event Logs

CCTV 녹화 파일을 지우는 도둑의 기법

#1. Windows 이벤트 로그란?

"CCTV 녹화" 비유

건물에 CCTV가 24시간 녹화하듯, Windows는 시스템에서 일어나는 모든 일을 이벤트 로그에 기록합니다. 누가 로그인했는지, 어떤 프로그램이 설치됐는지, 보안 정책이 변경됐는지 등. 도둑이 침입 후 가장 먼저 하는 일? CCTV 녹화 파일 삭제입니다.

🔐

Security Log

로그인/로그아웃, 권한 변경, 감사 정책. 포렌식의 핵심.

⚙️

System Log

서비스 시작/중지, 드라이버 오류, 시스템 이벤트.

📱

Application Log

앱 오류, 설치, 업데이트 기록.

#2. 로그 삭제 기법

공격자가 사용하는 명령어

# CMD: wevtutil로 보안 로그 삭제
wevtutil cl Security
wevtutil cl System
wevtutil cl Application
# PowerShell: 한 줄로 모든 로그 삭제
Get-WinEvent -ListLog * | ForEach { Clear-EventLog $_.LogName }

핵심: Event ID 1102

보안 로그가 삭제되면 Windows는 자동으로 Event ID 1102 ("The audit log was cleared")를 기록합니다. 이것은 로그 삭제의 "마지막 발자국"입니다. 범인이 CCTV를 끄는 순간, "CCTV가 꺼졌습니다"라는 마지막 알람이 울리는 것과 같습니다.
