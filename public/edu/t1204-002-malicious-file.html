T1204.002: Malicious File

Execution

Malicious File

맛있어 보이는 독 사과 — 정상 파일로 위장한 악성 파일

#1. 사용자 실행 유도

🍎 ➜ 💀 ➜ 👆 ➜ 💥

"맛있어 보이는 독 사과"

겉보기에는 빨갛고 맛있어 보이는 사과지만, 한 입 베어 물면 독이 퍼지는 것처럼, 공격자는 파일의 겉모습을 정상 문서나 이미지처럼 꾸며 사용자가 직접 더블클릭하도록 유도합니다. 핵심은 사용자의 클릭(User Execution)이 있어야 감염이 시작된다는 것입니다.

대표적인 위장 기법

이중 확장자

이력서.pdf.exe — Windows 기본 설정에서 .exe가 숨겨져 "이력서.pdf"로 보입니다.

아이콘 위장

실행 파일(.exe)의 아이콘을 PDF, Word, 폴더 아이콘으로 변경하여 문서처럼 보이게 합니다.

RLO 공격

Unicode의 Right-to-Left Override 문자를 삽입하여 invoice[RLO]fdp.exe가 "invoiceexe.pdf"로 표시됩니다.

#2. 파일 위장 기법 상세

📄

.pdf.exe (이중 확장자)

Windows의 "알려진 확장자 숨기기" 기본 설정을 악용합니다. 사용자에게는 .pdf만 보여 안전한 문서로 착각합니다.

# 사용자가 보는 것:
📄 이력서.pdf

# 실제 파일명:
이력서.pdf.exe
🖱️

.scr (화면보호기)

화면보호기 파일(.scr)은 실행 파일과 동일하게 동작하지만, 사용자들은 실행 파일로 인식하지 못합니다.

# 위장된 화면보호기
ocean_wallpaper.scr

# 실행 시:
→ 랜섬웨어 다운로드
🔗

LNK 파일 (바로가기)

Windows 바로가기(.lnk) 파일에 악성 명령을 내장합니다. 아이콘을 문서 아이콘으로 변경하면 구분이 어렵습니다.

# LNK 파일 내부 명령
Target: cmd.exe /c
 powershell -enc JABX...
# 아이콘: Word 문서

방어 방법

1. 파일 확장자 항상 표시 설정 (폴더 옵션 → "알려진 확장자 숨기기" 해제)
2. 실행 파일 화이트리스트(AppLocker, WDAC) 적용
3. 이메일 게이트웨이에서 실행 가능 확장자 차단
4. 파일 다운로드 시 속성 확인 (파일 종류: "응용 프로그램" 주의)
