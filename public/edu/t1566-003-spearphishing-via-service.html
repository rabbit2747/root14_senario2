Initial Access

Spearphishing via Service

SNS, 메신저 등 제3자 서비스를 통한 표적 피싱 공격

#1. 개념과 원리

서비스를 통한 스피어피싱이란?

이메일이 아닌 LinkedIn, Facebook, Slack, Discord, Teams 같은 제3자 서비스를 통해 악성 링크나 파일을 전달하는 공격입니다. 이메일 보안 게이트웨이를 우회하고, 플랫폼의 신뢰성을 이용하여 피해자의 경계심을 낮춥니다.

SNS 메시지

LinkedIn 채용 제안, Facebook 메시지를 통한 악성 링크 전달

메신저 앱

Slack, Teams, Discord DM으로 악성 파일 공유

클라우드 공유

Google Drive, OneDrive 공유 링크를 통한 악성코드 배포

#2. 공격 기법 분석

# LinkedIn 채용 제안을 통한 스피어피싱 시나리오
Platform: LinkedIn Direct Message
From: "Sarah Kim - HR Director @ TechCorp"
To: target_developer (보안 엔지니어)
Message: "안녕하세요! 귀하의 프로필을 보고 연락드립니다."
Attachment: Job_Description_TechCorp_2026.pdf.exe
# 이중 확장자로 실행파일을 문서로 위장

공격 벡터 분석

  • 이메일 보안 우회: SPF/DKIM/DMARC 검사가 적용되지 않음
  • 플랫폼 신뢰: LinkedIn/Slack 자체의 신뢰도 이용
  • 개인정보 활용: 공개된 프로필 정보로 맞춤형 메시지 작성
  • 파일 공유 악용: 클라우드 스토리지의 정상 공유 기능 악용

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • SNS 보안 설정: 외부 메시지 수신 제한, 프로필 공개 범위 최소화
  • EDR/XDR: 엔드포인트에서 악성 파일 실행 탐지
  • URL 샌드박싱: 클릭 전 URL 동적 분석
  • 보안 인식 교육: SNS를 통한 피싱 시나리오 포함
  • CASB: 클라우드 서비스 파일 공유 모니터링
