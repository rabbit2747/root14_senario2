T1593.004: 위협 벤더 데이터 검색

Reconnaissance

위협 벤더 데이터 검색

VirusTotal, AbuseIPDB, OTX 등 공개 위협 인텔리전스 플랫폼에서 대상 조직의 보안 정보를 수집하는 정찰 기법을 학습합니다.

01 위협 인텔리전스 벤더

위협 인텔리전스(TI)란?

위협 인텔리전스는 사이버 위협에 대한 정보를 수집, 분석, 공유하는 활동입니다. 보안 벤더들은 악성코드 샘플, 악성 IP/도메인, 공격 패턴 등을 데이터베이스화하여 방어에 활용합니다.

VirusTotal

파일, URL, IP, 도메인의 악성 여부를 70+ AV 엔진으로 검사. 조직의 악성코드 샘플과 보안 도구 정보가 노출될 수 있습니다.

AbuseIPDB

악성 IP 리포트 데이터베이스. 조직의 IP가 리포트되면 방화벽 설정과 보안 상태를 추론할 수 있습니다.

AlienVault OTX

Open Threat Exchange로 위협 지표(IoC)를 공유. Pulse에서 조직 관련 위협 정보와 이전 침해 이력을 확인할 수 있습니다.

Hybrid Analysis

악성코드 샌드박스 분석 플랫폼. 조직이 제출한 샘플에서 내부 파일 경로, 도메인 정보가 유출될 수 있습니다.

02 공격자의 악용 방법

TI 플랫폼이 노출하는 정보

보안 팀이 TI 플랫폼에 분석을 요청하면, 의도치 않게 다음 정보가 노출될 수 있습니다:

  • VirusTotal 검색: 조직이 제출한 악성코드 샘플에 내부 파일 경로, 사용자 이름, 도메인 정보가 포함
  • Shodan/Censys 연동: IP 기반 검색으로 조직의 노출 서비스와 보안 장비 종류 파악
  • OTX Pulse: 이전 공격 캠페인 IoC에서 조직이 피해자로 언급된 사례 발견
  • Hybrid Analysis: 조직이 분석한 악성코드에서 C2 서버, 공격 TTP 정보 파악
# VirusTotal에서 대상 조직 도메인 검색
$ vt domain target-corp.com --include resolutions,subdomains
# → 서브도메인 목록, DNS 이력, 관련 파일 해시 노출

# OTX에서 조직 관련 위협 보고서 검색
$ otx-cli search "target-corp" --type pulse
# → 이전 공격 IoC, 피해 이력, 사용된 악성코드 정보

방어 전략

  • 샘플 제출 정책: 내부 정보가 포함된 파일은 VT에 직접 제출하지 않고, 해시값만 검색
  • OPSEC 검토: TI 플랫폼 제출 전 민감 정보(파일 경로, 사용자명) 제거
  • 프라이빗 스캐닝: 유료 프라이빗 스캔 서비스 활용하여 공개 노출 방지
  • IoC 모니터링: 조직 도메인/IP가 TI 플랫폼에 등록되는지 정기 모니터링
