T1588.002
도구 획득

공격자가 외부에서 개발된 해킹 도구를 획득하여 공격 캠페인에 활용하는 기법을 학습합니다.

📦 Chapter 1 — 공격 도구 생태계

도구 획득이란?

공격자는 직접 도구를 개발하는 대신 기존에 만들어진 공격 도구를 획득하여 사용합니다. 이는 개발 비용을 절감하고 검증된 도구를 즉시 활용할 수 있는 장점이 있습니다.

합법적 도구의 악용
  • • Cobalt Strike — 원래 레드팀용 상업 도구
  • • Mimikatz — 자격증명 덤프 도구
  • • Metasploit — 오픈소스 침투테스트 프레임워크
  • • PsExec — 합법적 원격 관리 도구
불법 도구 획득 경로
  • • 다크웹 포럼 — 전문 해킹 도구 거래
  • • 크랙된 상업 도구 — 불법 복제 버전
  • • 텔레그램 채널 — 도구 배포 그룹
  • • GitHub 공개 저장소 — PoC 익스플로잇

🛠️ Chapter 2 — 주요 공격 도구 분류

카테고리별 공격 도구

1. C2 프레임워크
Cobalt Strike — 가장 많이 악용되는 상업 C2. Beacon 페이로드, Malleable C2 프로필 지원
Sliver — Go 기반 오픈소스 C2. mTLS, WireGuard, DNS 터널링 지원
Brute Ratel C4 — EDR 우회에 특화된 신규 C2 프레임워크
2. 자격증명 도구
Mimikatz — LSASS 메모리에서 평문 패스워드, NTLM 해시, Kerberos 티켓 추출
Rubeus — Kerberos 공격 전문. AS-REP Roasting, Kerberoasting
LaZagne — 브라우저, WiFi, 이메일 등 다양한 저장 자격증명 수집
3. 측면 이동 도구
Impacket — SMB, WMI, DCOM 원격 실행. Python 기반 네트워크 프로토콜 라이브러리
CrackMapExec — AD 환경 자동 열거 및 측면 이동. 다양한 프로토콜 지원
BloodHound — AD 관계 그래프 분석. 최단 경로 공격 벡터 시각화

🛡️ Chapter 3 — 탐지와 대응

도구 기반 탐지 전략

시그니처 기반 탐지
  • • YARA 룰로 알려진 도구 바이너리 탐지 (Cobalt Strike Beacon, Mimikatz 등)
  • • 네트워크 IDS/IPS에서 C2 프레임워크 통신 패턴 탐지
  • • VirusTotal, OPSWAT 등 멀티엔진 스캔으로 해시 매칭
  • • JA3/JA3S 핑거프린트로 TLS 클라이언트 식별
행위 기반 탐지
  • • Named Pipe 생성 모니터링 (Cobalt Strike 기본 파이프: \\.\pipe\msagent_*)
  • • LSASS 프로세스 접근 감시 (Sysmon Event ID 10)
  • • 비정상 부모-자식 프로세스 관계 탐지
  • • 메모리 내 PE 인젝션 탐지 (Reflective DLL Loading)

# YARA 룰 — Cobalt Strike Beacon 탐지

rule CobaltStrike_Beacon {

strings:

$pipe = "\\\\.\pipe\\msagent_" ascii

$cfg = { 00 01 00 01 00 02 ?? ?? 00 02 00 01 }

$sleep = "sleeptime" ascii

condition: 2 of them

}
