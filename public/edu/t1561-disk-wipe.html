T1561: Disk Wipe

Impact

Disk Wipe

디스크를 완전히 지워 시스템을 사용 불능으로 만드는 파괴 공격

#1. 디스크 와이프란?

💽 ➜ 🗑️ ➜ 💀 ➜ 🚫

"하드디스크를 백지로 만들어 부팅조차 불가능하게"

디스크 와이프(Disk Wipe)는 저장 장치의 데이터를 의도적으로 파괴하여 시스템을 완전히 사용 불능으로 만드는 공격입니다. 랜섬웨어와 달리 복구 대가를 요구하지 않으며, 순수하게 파괴만을 목적으로 합니다. 국가 지원 해커 그룹이 주로 사용하는 사이버 무기입니다.

랜섬웨어 vs 디스크 와이프

구분랜섬웨어디스크 와이프
목적금전 요구순수 파괴
복구키 지불 시 가능불가능
주요 행위자사이버 범죄 조직국가 지원 APT 그룹
대표 사례LockBit, BlackCatShamoon, NotPetya

#2. 공격 유형 분석

MBR/GPT 파괴

1 마스터 부트 레코드(MBR)에 0x00 덮어쓰기
2 시스템이 부팅 불가 상태가 됨
3 데이터는 남아있으나 접근 불가

전체 디스크 제로필

1 디스크 전체를 0x00으로 덮어쓰기
2 파일시스템, 파티션 테이블 모두 파괴
3 데이터 복구가 사실상 불가능
# 디스크 와이프 의사코드 (MBR 파괴)
$disk = "\\\\.\PhysicalDrive0"
$handle = [IO.File]::Open($disk, 'Open', 'ReadWrite')
$zeros = New-Object byte[] 512 # MBR = 512 bytes
$handle.Write($zeros, 0, 512) # MBR 영역 제로필
# 재부팅 시 "Operating System Not Found"

#3. 탐지 · 방어 + 퀴즈

디스크 와이프 시뮬레이션

디스크 와이프가 MBR을 파괴하는 과정을 관찰하세요.

💀
OPERATING SYSTEM NOT FOUND
MBR이 파괴되어 부팅이 불가능합니다.

탐지 방법

  • - 원시 디스크 접근(\\.\PhysicalDrive) 모니터링
  • - Sysmon으로 비정상 프로세스의 디스크 쓰기 감지
  • - EDR에서 MBR/GPT 수정 시도 차단

방어 전략

  • - Secure Boot + UEFI 부팅 보호 활성화
  • - 오프라인 백업 (air-gapped) 운영
  • - 네트워크 세그멘테이션으로 확산 차단
