T1562.002: Disable Windows Event Logging

Defense Evasion

Disable Windows Event Logging

이벤트 로그를 비활성화하거나 삭제하여 포렌식 증거를 없애는 기법

#1. 이벤트 로깅 비활성화란?

"기록 삭제" 비유

범죄 현장에서 CCTV 녹화를 중단하고, 이미 녹화된 테이프를 삭제하는 것입니다. Windows Event Log는 보안 사고의 핵심 증거이며, 공격자는 이를 비활성화하거나 삭제하여 포렌식 분석을 방해합니다.

EventLog 서비스 중지

모든 이벤트 기록 중단

감사 정책 변경

특정 이벤트 카테고리 비활성화

로그 삭제

wevtutil cl로 기존 로그 삭제

#2. 공격 기법

# 이벤트 로그 비활성화/삭제 기법들
wevtutil cl Security # 보안 로그 삭제
wevtutil cl System # 시스템 로그 삭제
auditpol /set /category:* /success:disable /failure:disable
# 모든 감사 정책 비활성화

방어 방법

  • 중앙 로그 수집(SIEM): 이벤트를 실시간으로 원격 서버에 전달
  • Event ID 1102: 보안 로그 삭제 시 항상 기록되는 이벤트
  • 로그 무결성 보호: 로그 파일 ACL 제한
  • GPO: 감사 정책 변경 차단
