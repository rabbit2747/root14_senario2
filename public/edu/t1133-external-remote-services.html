T1133: External Remote Services

Initial Access

External Remote Services

VPN, RDP, SSH 등 외부 원격 접근 서비스를 악용한 침투

#1. 개념과 원리

외부 원격 서비스 악용이란?

VPN, RDP, SSH, Citrix 등 외부에서 내부 네트워크에 접근할 수 있는 원격 서비스를 악용합니다. 탈취한 자격증명이나 취약점으로 정상 원격 접근 채널을 통해 침투하므로 탐지가 어렵습니다. 코로나 이후 원격근무 확대로 공격 표면이 크게 증가했습니다.

VPN 악용

탈취된 VPN 자격증명으로 내부 접근

RDP 공격

BlueKeep, 크리덴셜 스터핑으로 RDP 침투

SSH 무차별 대입

SSH 키 탈취 또는 비밀번호 브루트포스

#2. 공격 기법 분석

# VPN 크리덴셜 스터핑 + RDP 접근
hydra -L users.txt -P leaked_passwords.txt vpn.target.com https-form-post
xfreerdp /v:10.0.0.5 /u:jkim /p:P@ssw0rd2025
# SSH 키 기반 접근
ssh -i stolen_key.pem admin@bastion.target.com

공격 분석

  • VPN: 유출된 비밀번호로 SSL-VPN 접근 (MFA 미적용)
  • RDP: NLA 없이 인터넷에 노출된 3389 포트 공격
  • SSH: 피싱으로 탈취한 SSH 키 또는 비밀번호 브루트포스
  • Citrix: CVE-2023-4966 (Citrix Bleed)으로 세션 하이재킹

#3. 탐지 및 방어 + 퀴즈

방어 전략

  • MFA 필수: VPN, RDP, SSH 모든 원격 접근에 MFA 적용
  • Zero Trust: 네트워크 위치와 무관하게 신원/디바이스 검증
  • JIT Access: Just-In-Time 접근으로 필요한 시간만 허용
  • UEBA: 비정상 로그인 패턴 탐지
  • VPN 패치: Fortinet, Pulse Secure 등 VPN 장비 최신 패치
