#1. Active Directory 공격 경로 이해

🏰

Active Directory는 '왕국의 조직도'

초급에서 "호텔 마스터키"로 비유한 Domain Admin. 이제 한 단계 깊이 들어갑니다. Active Directory(AD)는 마치 거대한 왕국의 조직도와 같습니다.

👑
Domain Admin
왕 (모든 권한)
🛡️
Tier 0~2 관리자
귀족 (위임 권한)
👤
Domain User
평민 (기본 권한)
🕸️

공격 그래프(Attack Graph)란?

AD의 모든 사용자, 컴퓨터, 그룹, 정책은 서로 권한 관계로 연결되어 있습니다. 이 관계들을 그래프(Graph)로 그리면, 일반 사용자에서 관리자까지 도달할 수 있는 "숨겨진 길"이 보입니다.

// 공격 경로 예시
Alice (User) ──[MemberOf]──▶ IT-Support (Group)
IT-Support ──[AdminTo]──▶ FileServer01
FileServer01 ──[HasSession]──▶ DomainAdmin
→ 3단계만에 Domain Admin 도달 가능!

BloodHound가 추적하는 핵심 관계(Edge)

관계 의미 위험도
MemberOf 그룹 소속 관계 보통
AdminTo 해당 컴퓨터의 관리자 권한 높음
HasSession 해당 컴퓨터에 로그인 중 (메모리에 인증정보 존재) 매우 높음
GenericAll 대상 객체의 모든 속성 수정 가능 (비밀번호 변경 포함) 치명적
WriteDacl 대상의 접근 제어 목록(ACL) 변경 가능 → 스스로에게 권한 부여 치명적

#2. BloodHound 실전 활용

🐕

Step 1: SharpHound로 정보 수집

BloodHound는 크게 두 부분으로 나뉩니다: SharpHound(수집기)와 BloodHound GUI(분석기). 먼저 SharpHound를 사내 네트워크에서 실행하여 AD의 모든 관계 데이터를 수집합니다.

# SharpHound 수집 명령 (공격자 관점)
PS C:\Tools> .\SharpHound.exe -c All --outputdirectory C:\Loot\
[*] Status: 142 name resolutions, 89 computer connections
[*] Enumeration completed in 00:00:34
[*] SharpHound saved: 20260302_BloodHound.zip (2.4 MB)
# 수집 항목: 사용자, 그룹, 컴퓨터, 세션, ACL, 트러스트 관계
⚠️

방어자 팁: SharpHound는 대량의 LDAP 쿼리와 SMB 연결을 발생시킵니다. SIEM에서 단시간 내 대량 LDAP 요청(4662 이벤트)을 모니터링하면 탐지할 수 있습니다.

🔍

Step 2: BloodHound GUI에서 공격 경로 분석

수집된 ZIP 파일을 BloodHound(Neo4j 그래프 DB 기반)에 불러오면, AD의 모든 관계가 그래프로 시각화됩니다. 내장 쿼리(Pre-built Queries)로 위험한 경로를 즉시 찾을 수 있습니다.

🎯 핵심 쿼리 Top 3

  • 1. Find Shortest Path to Domain Admin
    → 최단 경로 자동 탐색
  • 2. Find Kerberoastable Users with Admin
    → SPN이 설정된 관리자 계정 탐색
  • 3. Find Computers where Domain Users can RDP
    → 일반 사용자가 원격 접속 가능한 서버

🚨 ACL 남용 경로

  • GenericAll: 대상의 비밀번호를 강제 리셋
  • WriteDacl: 자신에게 GenericAll 부여 후 공격
  • ForceChangePassword: 비밀번호 변경 강제 (이력 없이)
  • AddMember: 자신을 관리자 그룹에 추가

#3. 방어자의 시선: 탐지와 대응

🔬

SharpHound의 발자국 추적

공격자가 SharpHound를 실행하면, Windows 이벤트 로그에 뚜렷한 흔적이 남습니다. 방어자는 이 패턴을 알면 즉시 탐지할 수 있습니다.

4662
대량 LDAP 객체 접근
수 초 내에 수천 건의 AD 객체 조회 → SharpHound 수집 패턴
5145
네트워크 공유 접근 열거
모든 컴퓨터의 공유 폴더를 순차적으로 스캔 → 세션 수집
4688
프로세스 생성 로그
SharpHound.exe 또는 인메모리 실행 흔적 (부모 프로세스 분석)

AD 공격 경로 차단 전략

🧹 권한 위생 (Privilege Hygiene)

  • • 불필요한 AdminTo, GenericAll 관계 제거
  • • 관리자 계정 최소화 (Tiered Admin Model)
  • • 서비스 계정 gMSA 전환

🔐 세션 보호

  • • 관리자 계정 일반 워크스테이션 로그인 금지
  • • LSA 보호(RunAsPPL) 활성화
  • • Credential Guard 적용

📡 모니터링

  • • LDAP 대량 쿼리 임계값 알림
  • • ACL 변경 이벤트(5136) 실시간 감시
  • • 비정상 그룹 멤버십 변경 감지

🛡️ 선제적 방어

  • • 방어자도 BloodHound를 정기 실행하여 경로 점검
  • • PingCastle, Purple Knight로 AD 보안 점수 측정
  • • 허니팟 계정으로 공격자 유인
