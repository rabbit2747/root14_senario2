Domain Generation Algorithms

수학적 알고리즘으로 매일 수천 개의 C2 도메인을 생성

#1. DGA란? 도메인 생성 알고리즘

🎲 ➜ 🌐 ➜ 🔄 ➜ 💀

"매일 수천 개의 도메인 중 하나만 실제 C2"

DGA는 시간(날짜), 시드값 등을 입력으로 받아 수학적으로 도메인 이름을 생성하는 알고리즘입니다. 악성코드는 매일 수백~수천 개의 도메인을 생성하고 순서대로 접속을 시도합니다. 공격자는 그 중 하나만 실제로 등록하면 C2 통신이 성립됩니다.

왜 DGA를 사용하는가?

하드코딩된 C2 도메인은 한 번 차단되면 끝입니다. DGA는 매일 새로운 도메인을 생성하므로, 보안 팀이 모든 가능한 도메인을 미리 예측하고 차단하지 않는 한 C2 통신을 유지할 수 있습니다. 이것이 DGA의 핵심 강점입니다.

#2. DGA 알고리즘 구조 분석

시간 기반 DGA

가장 일반적인 DGA 유형입니다. 현재 날짜를 시드로 사용하여 도메인을 생성합니다. 같은 날짜에 같은 알고리즘을 실행하면 동일한 도메인이 생성됩니다. 악성코드와 공격자가 시간을 공유하기만 하면 별도의 통신 없이 같은 도메인을 알 수 있습니다.

사전 기반 DGA

영어 단어 사전에서 단어를 조합하여 도메인을 생성합니다. "blue-ocean-42.com"처럼 사람이 등록한 것처럼 보이는 도메인을 만들어 머신러닝 탐지를 우회합니다. 엔트로피가 낮아 랜덤 문자열 DGA보다 탐지가 어렵습니다.

실전 사례: Conficker DGA

Conficker 웜은 하루에 50,000개의 도메인을 생성하는 DGA를 사용했습니다. 보안 연구자들이 알고리즘을 리버스 엔지니어링하여 도메인을 예측하고 선점(sinkhole)했지만, 공격자는 알고리즘을 업데이트하며 대응했습니다.

# 시간 기반 DGA 예시 (Python)
import hashlib, datetime
seed = datetime.date.today().isoformat()
for i in range(5):
h = hashlib.md5(f"{seed}-{i}".encode()).hexdigest()[:12]
print(f" {h}.com")
# 출력: a3f2c1d8e9b4.com, 7b6d4e2f1a3c.com, ...
