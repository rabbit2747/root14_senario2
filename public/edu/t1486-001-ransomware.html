ATT&CK Matrix

T1486.001: Ransomware

Impact

Ransomware

디지털 인질극 — 파일을 잠그고 몸값을 요구하는 사이버 범죄

#1. 랜섬웨어 생태계

🏭 ➜ 🤝 ➜ 💣 ➜ 💰

"범죄의 기업화 — RaaS(Ransomware as a Service)"

현대 랜섬웨어는 개인 해커가 아닌 조직적인 범죄 생태계에서 운영됩니다. 개발자(Developer)는 랜섬웨어 플랫폼을 만들고, 제휴 공격자(Affiliate)는 이를 배포합니다. 수익은 보통 70:30으로 분배됩니다. 고객 지원 채팅, 피해자 포털까지 갖춘 '서비스형 범죄'입니다.

👨‍💻
개발자 (Developer)
랜섬웨어 코드, 인프라, 복호화 도구 개발
🎯
제휴자 (Affiliate)
초기 침투, 횡적 이동, 랜섬웨어 배포
🔑
IAB (초기 접근 브로커)
네트워크 접근 권한을 판매하는 중개인

#2. 랜섬웨어 감염 체인 (Kill Chain)

전형적인 감염 타임라인

D-14 피싱 이메일 또는 취약점을 통해 초기 침투
D-7 도메인 관리자 계정 탈취, 횡적 이동
D-3 기밀 데이터를 외부로 유출(이중 협박 준비)
D-Day 백업 파괴 → 전사 파일 암호화 → 랜섬 노트 배포
# 랜섬웨어 배포 명령 (GPO 악용)
schtasks /create /s dc01.corp.local /tn "WindowsUpdate"
/tr "C:\Windows\Temp\payload.exe" /sc once
/st 02:00 /ru SYSTEM /f
# → 새벽 2시, 모든 도메인 PC에서 동시 실행
# → 수 분 내 전사 파일 암호화 완료

#3. 대응 전략 + 퀴즈

랜섬웨어 대응 체크리스트

예방 (Before)

  • - 3-2-1 백업: 3개 복사본, 2종 매체, 1개 오프라인
  • - 네트워크 세그멘테이션
  • - 패치 관리 자동화
  • - 이메일 필터링 + 직원 보안 교육

대응 (During)

  • - 감염 시스템 네트워크 즉시 격리
  • - 침해 범위 파악 (IoC 수집)
  • - 법 집행 기관 통보 (KISA, 경찰청)
  • - 몸값 지불 결정은 최후 수단
