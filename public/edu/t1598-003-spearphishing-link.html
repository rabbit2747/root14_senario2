T1598.003: 링크 스피어피싱

Reconnaissance

링크를 통한 스피어피싱

가짜 로그인 페이지로 유도하여 비밀번호를 수확한다

#1. 링크 기반 피싱이란?

🔗 ➜ 🌐 ➜ 🔐 ➜ 📤

"Microsoft 365 비밀번호가 만료됩니다 — 지금 갱신하세요"

공격자는 이메일에 가짜 로그인 페이지 링크를 포함시켜 대상이 실제 서비스(Microsoft 365, Google, VPN 등)로 착각하고 인증 정보를 입력하도록 유도합니다. 이 기법은 정보 수집(Reconnaissance) 단계에서 크레덴셜을 획득하기 위해 사용됩니다.

URL 위장 기법

정상 URL:
https://login.microsoftonline.com
위장 URL 예시:
https://login.microsoftonline.com.evil-site.com
https://login-microsoftonline.com
https://l0gin.microsoftonline.com (0 = 영문 o)
https://bit.ly/3xK9mQ2 (단축 URL)

#2. 크레덴셜 하베스팅

공격 도구: EvilGinx2 / GoPhish

이러한 도구는 피싱 프레임워크로, 실제 로그인 페이지를 완벽히 복제하고 MFA 토큰까지 가로챌 수 있습니다.

  • ● 리버스 프록시로 실제 사이트와 피해자 사이에 위치
  • ● 세션 쿠키를 탈취하여 MFA 우회 가능
  • ● 피해자에게는 정상 로그인처럼 보임

방어 전략

  • ● FIDO2/WebAuthn 기반 패스키 사용 (피싱 불가)
  • ● URL 필터링 및 실시간 피싱 사이트 차단
  • ● 이메일 내 URL 미리보기 및 안전 링크(Safe Links) 활성화
  • ● 정기적인 피싱 시뮬레이션 훈련
