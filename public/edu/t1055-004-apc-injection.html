T1055.004: APC Injection

Privilege Escalation / Defense Evasion

APC Injection

프로세스의 대기열에 악성 작업을 몰래 추가하는 비동기 공격 기법

#1. APC(Asynchronous Procedure Call)란?

"우편함" 비유

각 스레드에는 "우편함(APC Queue)"이 있습니다. 누군가 이 우편함에 편지(작업)를 넣어두면, 스레드가 "우편함을 확인하는 시간(Alertable Wait State)"이 되었을 때 그 작업을 실행합니다. 공격자는 이 우편함에 악성 작업을 몰래 넣어둡니다.

APC Queue 동작 원리

1QueueUserAPC: 타겟 스레드의 APC Queue에 함수 포인터 등록
2스레드가 SleepEx, WaitForSingleObjectEx 등으로 Alertable Wait 진입
3APC Queue의 함수가 타겟 스레드 컨텍스트에서 자동 실행

#2. APC Injection 원리

Early Bird APC Injection

가장 효과적인 변형으로, 프로세스를 SUSPENDED 상태로 생성한 뒤 APC를 등록합니다. 프로세스가 재개되면 보안 도구가 초기화되기 전에 악성 코드가 먼저 실행됩니다. "새벽(Early Bird)"이라는 이름은 여기서 유래했습니다.

// APC Injection 의사 코드
hProcess = OpenProcess(PROCESS_ALL_ACCESS, targetPID);
remoteMem = VirtualAllocEx(hProcess, ...);
WriteProcessMemory(hProcess, remoteMem, shellcode, ...);
QueueUserAPC(remoteMem, hThread, NULL);
// 스레드가 Alertable Wait에 진입하면 shellcode 실행

방어 방법

  • EDR API 후킹: QueueUserAPC, NtQueueApcThread 호출 모니터링
  • Sysmon Event ID 8: CreateRemoteThread 탐지
  • 메모리 보호: CFG(Control Flow Guard), CIG(Code Integrity Guard) 활성화
  • ETW(Event Tracing): 커널 수준 APC 호출 추적
