07 품질 체크리스트

  • 해당 레벨에 적절한 난이도인가?
  • feynman 설명이 비전공자도 이해 가능한가?
  • expert 설명이 실무자에게 유용한가?
  • 실제 명령어/도구가 정확한가? (가짜 명령어 없음)
  • i18n 구조가 가이드를 준수하는가? (ko/en 필수, 5개 추가 언어)
  • 시네마틱 슬라이드가 15~20장인가?
  • 시나리오가 3~5 Sector로 분할되었는가?
  • Lab step이 8~15개인가?
  • npm run build 성공하는가?
