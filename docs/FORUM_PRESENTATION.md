# GOTROOT Cybersecurity Education Platform

### "MITRE ATT&CK 154개 서브테크닉을 인터랙티브 교육 SPA로 — 1인 풀스택 개발기"

> **기술 스택**: Vite 6 + React 19 + Tailwind CSS 4 + Supabase

## 1. 발표 소개 — 왜 직접 만들었는가

### 배경

저는 모의해킹 컨설턴트로 일하면서, 신입 보안 엔지니어들이 MITRE ATT&CK 프레임워크를 학습할 때 겪는 **3가지 벽**을 목격했습니다:

| 문제 | 현실 | 이 플랫폼의 해결 방식 |
|------|------|---------------------|
| **추상적 이론** | 공격 기법 이름과 설명만 나열 | 단계별 데스크톱 시뮬레이션으로 직접 체험 |
| **단절된 학습** | 공격/방어가 별도 교육 | 해커 뷰 ↔ 방어자 SOC 뷰 실시간 전환 |
| **낮은 접근성** | 영어 중심, 전문가 전용 | 5개 언어, 초급→중급→고급 단계 시스템 |

### 핵심 메시지

> **"해커의 공격을 직접 실행하면서 배우고, 즉시 방어자 시점으로 전환하여 탐지와 대응을 학습한다."**

## 3. 핵심 기능 Deep Dive

### 3-1. MITRE ATT&CK 인터랙티브 매트릭스

```
14개 전술(Tactic) × 154개 서브테크닉(Sub-Technique)
├── 실시간 검색 (한/영 기법명)
├── 택틱별 색상 코딩
├── 교육 완료 상태 뱃지 (진행중/완료)
├── 서브기법 클릭 → suck-in 애니메이션 → 교육 진입
└── 반응형 가로 스크롤 (모바일 대응)
```

**기술 포인트**: `matrix-fallback.json` (154개 서브테크닉) + Supabase `edu_meta` 동적 매핑. 오프라인 시 로컬 JSON 폴백.

### 3-2. 듀얼 뷰 데스크톱 시뮬레이션

이 플랫폼의 **핵심 차별점**입니다.

```
┌──────────────────────────────────────────────────┐
│           GenericLabSimulator.jsx                  │
│  ┌─────────────────────┬────────────────────────┐ │
│  │    LEFT PANEL        │     RIGHT PANEL        │ │
│  │                      │                        │ │
│  │  [해커 뷰]           │  [해커 뷰 교육]        │ │
│  │  - 터미널 명령어     │  - Feynman 비유 설명   │ │
│  │  - 프로세스 트리     │  - 전문가 분석         │ │
│  │  - 네트워크 토폴로지 │  - 기술 용어 사전      │ │
│  │                      │  - 해커 로그 뷰어      │ │
│  │  [방어자 뷰]         │                        │ │
│  │  - SIEM 알럿         │  [방어자 뷰 교육]      │ │
│  │  - SOC 대시보드      │  - 탐지 분석           │ │
│  │  - 프로세스 모니터링 │  - 대응 전략           │ │

│  └─────────────────────┴────────────────────────┘ │
│  [4단계 진행 바] ● 정찰 → ● 실행 → ● 지속성 → ● 유출 │
└──────────────────────────────────────────────────┘
```

**41개 시나리오 JSON** 기반 데이터 주입 방식:
- 각 JSON에 `steps[]`, `phases[]`, `topoNodes/Edges[]`, `desktopIcons[]` 포함
- 스텝마다 `feynman`(비유), `expert`(전문분석), `terms`(용어), `hackerLog`(로그) 포함
- **제로 코드 시나리오 추가**: JSON만 작성하면 새 시뮬레이션 자동 생성

### 3-4. 보안 아키텍처

| 계층 | 구현 | 상세 |
|------|------|------|
| **인증** | Supabase Auth (JWT) | 이메일/비밀번호 + 관리자 승인 2단계 |
| **인가** | Row Level Security (RLS) | 테이블별 정책, admin role 분리 |
| **XSS 방어** | DOMPurify 3.3 | 교육 HTML 에디터 입출력 전체 산화 |
| **CSRF** | Supabase Token | SameSite Cookie + Bearer Token |
| **관리자 재검증** | useAdminVerify 훅 | 민감 작업 시 비밀번호 재입력 |
| **Open Redirect** | 화이트리스트 기반 | ROUTE_MAP으로 허용 경로만 이동 |
| **코드 난독화** | vite-plugin-obfuscator | 프로덕션 빌드 시 자동 적용 |
| **감사 추적** | audit_logs 테이블 | 관리자 모든 CRUD 작업 IP + 타임스탬프 |

## 4. 개발 과정 — 도전과 해결

### 4-1. 154개 서브테크닉 매핑의 현실

```
전체 서브테크닉: 154개
├── 교육 HTML 완성: 42개 (27%)
├── 랩 시나리오 완성: 41개 (27%)
├── 위젯 애니메이션: 14개 (전체 전술)
└── 진행률 추적 연동: 42개 (100% of HTML)
```

**해결 전략**: "준비중" 기법은 토스트 메시지로 표시하되, JSON 기반 시나리오 시스템을 설계하여 **콘텐츠 추가 시 코드 변경 없이** 시나리오만 추가하면 되도록 아키텍처링.

### 4-2. 1인 개발에서의 품질 유지

| 자동화 요소 | 적용 |
|------------|------|
| Vite HMR | 코드 수정 → 50ms 이내 반영 |
| Lazy Loading | 14개 라우트 코드 분할 (초기 로드 최적화) |
| DOMPurify | 사용자 입력 자동 산화 |
| RLS 정책 | DB 레벨 자동 접근 제어 |
| DB 트리거 | 신규 가입/공지 → 관리자 알림 자동 생성 |
| 감사 로그 | Fire-and-forget 패턴 (실패해도 서비스 미차단) |

### 4-3. 다국어 지원 (5개 언어)

```
🇰🇷 한국어 (기본) | 🇺🇸 English | 🇨🇳 中文 | 🇮🇳 हिन्दी | 🇯🇵 日本語
```

- **컴포넌트 내장 번역 패턴**: 각 컴포넌트에 `const t = translations[lang]` 방식
- **localStorage 기반 언어 감지**: `gotroot_lang` 키 + 브라우저 언어 자동 감지
- **교육 HTML은 한국어 우선**: 기술 보안 용어의 정확성 우선

## 8. 주요 기술적 인사이트

### 인사이트 1: JSON-Driven Architecture

> 시뮬레이션 시나리오를 JSON으로 완전 분리함으로써, **보안 전문가가 코드 없이도 새로운 공격 시나리오를 추가**할 수 있게 되었습니다. 41개 시나리오 모두 동일한 GenericLabSimulator.jsx 하나로 구동됩니다.

### 인사이트 2: Dual-View Learning

> 해커 뷰에서 명령어를 실행하고, 토글 하나로 방어자 SOC 뷰로 전환하면 **동일한 공격을 탐지하는 SIEM 알럿과 대응 절차**를 즉시 확인할 수 있습니다. 이 "양면 학습"이 보안 교육의 핵심이었습니다.

### 인사이트 3: Progressive Locking

> 초급 → 중급 → 고급 잠금 시스템은 학습자가 기초를 건너뛰지 못하도록 하면서도, 완료 시 즉각적인 성취감을 줍니다. `useEduProgress` 훅으로 실시간 진행률이 Supabase에 동기화됩니다.

## 10. Q&A

### 자주 묻는 질문

**Q: 왜 Next.js가 아닌 Vite + React?**
> 정적 HTML 교육 콘텐츠가 42개이며, SSR이 필요 없는 대시보드 SPA입니다. Vite의 빠른 HMR과 간결한 설정이 1인 개발에 최적이었습니다.

**Q: Supabase RLS만으로 보안이 충분한가?**
> RLS 외에도 관리자 재검증(useAdminVerify), DOMPurify XSS 필터링, 코드 난독화, 감사 로그, Open Redirect 방어까지 7단계 보안 레이어를 적용했습니다.

**Q: 41개 시나리오 JSON은 어떻게 관리하나?**
> 관리자 대시보드에서 시나리오 편집/프리뷰가 가능하며, 각 JSON의 스키마가 통일되어 있어 새 시나리오 추가 시 기존 패턴을 복사 후 수정하면 됩니다.
