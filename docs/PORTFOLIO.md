## 1. 프로젝트 개요

GOTROOT Education Platform은 **MITRE ATT&CK 프레임워크** 기반의 인터랙티브 사이버보안 교육 플랫폼입니다.

보안 실무자와 학습자가 **154개 공격 서브테크닉**을 시각적으로 탐색하고, **해커 시점의 공격 시뮬레이션**과 **방어자 SOC 시점의 탐지/대응**을 동시에 체험할 수 있습니다.

기획부터 배포까지 전 과정을 1인으로 수행하며, 보안 도메인 전문성과 프론트엔드/백엔드 기술력을 모두 발휘한 프로젝트입니다.

## 4. 주요 기능

### 4-1. MITRE ATT&CK 인터랙티브 매트릭스

- **14개 전술 × 154개 서브테크닉** 그리드 시각화
- 실시간 검색 (한/영 기법명)
- 택틱별 색상 코딩 + 교육 완료 상태 뱃지
- 서브기법 클릭 시 suck-in 애니메이션 → 과정 진입
- 오프라인 폴백 (`matrix-fallback.json`)

### 4-2. 듀얼 뷰 데스크톱 시뮬레이션 ★

> **이 프로젝트의 핵심 차별점**

- **해커 뷰**: 터미널 명령어 실행, 프로세스 트리, 네트워크 토폴로지, Feynman 비유 설명
- **방어자 뷰**: SIEM 알럿, SOC 대시보드, 탐지 분석, 대응 전략, 확인 포인트
- **토글 전환**: 동일 공격 단계를 양쪽 시점에서 실시간 체험
- **41개 시나리오**: JSON 기반 데이터 주입 — 코드 변경 없이 시나리오 추가

### 4-3. 단계별 교육 시스템

```
🟢 초급 (Beginner)    → 개념과 원리, 기본 시나리오
🔵 중급 (Intermediate) → 공격/방어 기법 실습 (초급 완료 시 잠금 해제)
🔴 고급 (Advanced)     → APT 사례 분석, 실전 시뮬레이션 (중급 완료 시 잠금 해제)
```

### 4-4. 9-Tab 관리자 대시보드

| 탭 | 기능 |
|----|------|
| 🎨 위젯 편집기 | JSON 기반 위젯 실시간 프리뷰 편집 |
| 📚 교육 관리 | 교육 메타데이터 CRUD |
| 🗂️ 매트릭스 구조 | 서브테크닉 매핑 관리 |
| 📢 공지 관리 | 공지사항 CRUD + 카테고리 |
| 👤 사용자 관리 | 승인/역할/마케팅 동의 관리 |
| 🧪 실습 페이지 | HTML 교육 코드 에디터 (Prism.js) |
| 🖥️ 랩 시나리오 | 시나리오 JSON 편집/프리뷰 |
| 📊 교육 통계 | SVG 차트 기반 학습 분석 대시보드 |
| 📋 감사 로그 | IP/타임스탬프 기반 관리자 행동 추적 |

## 7. 개발 과정의 도전

### 도전 1: 대규모 교육 콘텐츠 관리

> 42개 HTML 교육 페이지와 41개 JSON 시나리오를 일관된 품질로 관리하기 위해, **JSON-Driven Architecture**를 설계했습니다. GenericLabSimulator.jsx 하나가 41개 시나리오를 모두 구동하며, 새 시나리오 추가 시 코드 변경이 필요 없습니다.

### 도전 2: 보안과 UX의 균형

> 관리자 재검증(비밀번호 재입력)과 RLS 정책은 보안을 강화하지만 UX를 저해할 수 있습니다. `useAdminVerify` 훅에 5분 캐시를 적용하여, 연속 작업 시에는 재검증 없이 작업할 수 있도록 설계했습니다.

### 도전 3: 듀얼 뷰 교육 설계

> 해커와 방어자 교육 콘텐츠가 동일한 JSON에서 나와야 하므로, 각 스텝에 `cmd/out/desc`(해커)와 `def/defAction/defTooltip`(방어자) 필드를 분리하되, `feynman/expert/terms`는 양쪽에서 재활용하는 구조를 설계했습니다.
