# Orion Echo 페이지 개성·고유성 가이드라인

각 페이지가 똑같이 보이지 않도록, 다음 5가지 축에서 의식적으로 차별화한다.

## 5대 차별화 원칙

```
1. 시각(Visual)       — 시그니처 색 1색 + 레이아웃 모티프(grid/list/spline 등)
2. 인터랙션           — 주 입력 패턴 1종 고정 (스크롤·클릭·드래그·키보드·자동재생)
3. 톤·시점            — narrator 시점, 시제, 감정 온도, 어휘 격조
4. 페이스             — 정보 밀도·전환 속도(컷·크로스페이드·스태거·정지)
5. 연결(3원칙)         — 이전 페이지의 무엇을 받아오고, 다음 페이지로 무엇을 넘기는가
```

## 페이지별 적용

### 1️⃣ 목차 (Course TOC)
- **시각**: 차분한 다크 그리드 · 시그니처 = 시안(`#06b6d4`) · 책상 위 펼친 작전 지도 톤
- **인터랙션**: 스크롤 + 카드 호버 — 클릭 안 해도 정보 다 보임
- **톤·시점**: 안내자(curator) 격조 · "당신은 다음의 여정에 진입한다"
- **페이스**: 천천히 · 페이드 1.2s · 위→아래 자연스러운 트래킹
- **연결**: ⏎ 시나리오 허브에서 받은 호기심 → ⏵ 인트로의 스토리로 이양

### 2️⃣ 인트로 (Mission Briefing)
- **시각**: 짙은 보랏빛(`#7c3aed`) + 회사 로고 + 시각적 빌딩 실루엣
- **인터랙션**: 자동 페이드 시퀀스 · 사용자는 "다음" 한 번만 누름
- **톤·시점**: 영화 오프닝 narrator · "당신은 공격자다" · 단호
- **페이스**: 시네마틱 — 컷 0.6s 크로스페이드 · 자막 하단 고정
- **연결**: ⏎ 목차의 11스테이지 → ⏵ 시네마틱의 피해자 시점

### 3️⃣ 2D 시네마틱 (피해자 입장)
- **시각**: 따뜻한 사무실 톤(`#f59e0b` 형광등) → 후반 차가운 적색(`#dc2626`)
- **인터랙션**: 자동 재생 + 일시정지/되감기 · 키보드 Space
- **톤·시점**: 피해자 1인칭 · "오늘 출근, 당신의 메일함에 한 통의 메시지" · 무덤덤하게 시작
- **페이스**: 60~75초 · 클립 5~7개 · 점진 가속
- **연결**: ⏎ 인트로의 외부 시점 → ⏵ 사용자 디자인 #1로 시점 전환 충격

### 4️⃣ 사용자 디자인 #1
- **시각**: TBD (사용자 디자인 톤 추출 후 결정)
- **인터랙션**: TBD
- **톤·시점**: 공격자 시점 · "당신은 공격자다" 격조
- **페이스**: 사용자 디자인 의도 따름
- **연결**: ⏎ 시네마틱의 피해자 충격 → ⏵ 디자인 #2로 행동 진행

### 5️⃣ 사용자 디자인 #2
- **시각**: 디자인 #1과 톤은 일치하되 레이아웃 모티프는 차별
- **인터랙션**: 디자인 #1과 다른 주 입력 (드래그·키보드 등)
- **톤·시점**: 공격자 시점 유지 · 진행 단계별 미세 변주
- **페이스**: 디자인 의도 따름
- **연결**: ⏎ 디자인 #1 결과 → ⏵ 학습 단계로 개념화

### 6️⃣ 학습 단계 (Lesson · 준비중)
- **시각**: 도서관 / 교과서 톤 · 흰 배경 또는 옅은 베이지 · 시그니처 = 깊은 청록
- **인터랙션**: 정독 + 사이드 테이블 클릭 · 코드 블록 복사
- **톤·시점**: 강사 격조 · "당신은 방금 이 행위를 보았다 · 이것의 이름은 T1190 이다"
- **페이스**: 느림 · 한 개념당 2~3분 · 다이어그램·표 비중 높음
- **연결**: ⏎ 체험에서 본 행위 → ⏵ 방어자 시점으로 전환

### 7️⃣ 방어자 입장 학습+체험
- **시각**: 보안관제센터 SOC 톤 · 시그니처 = 차가운 청색(`#3b82f6`) + 적색 알림
- **인터랙션**: 로그 검색·룰 토글·타임라인 스크럽
- **톤·시점**: SOC 분석가 격조 · "당신은 이제 방어자다 · 같은 사건을 반대편에서 본다"
- **페이스**: 빠른 알림 + 천천히 분석
- **연결**: ⏎ 학습의 개념 → ⏵ CTF의 실전

### 8️⃣ CTF 연계
- **시각**: 터미널 흑·녹색 · 챌린지 카드 그리드
- **인터랙션**: flag 제출·힌트 토글·점수 보드
- **톤·시점**: 운영자 격조 · 결과 위주
- **페이스**: 자유 페이스 · 학습자 주도
- **연결**: ⏎ 모든 학습 → ⏵ 다음 시나리오 추천

## 어투 일관 원칙

전체 페이지 공통 narrator 어투:

```
✅ "당신은 공격자다."
✅ "당신은 다음 단계로 진입한다."
✅ "당신의 첫 수는 무엇인가."

❌ "너는 ..."  (반말)
❌ "나는 ..."  (1인칭 — 시네마틱 자막에서만 예외 허용)
❌ "~하시겠습니까"  (존댓말 — 거리감 깨짐)
```

학습자를 **2인칭 격조 "당신"** 으로 일관 호명. 명령형보다 직설 평서형 ("당신은 ~다").
