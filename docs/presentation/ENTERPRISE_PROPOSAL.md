## 2. 솔루션: GOTROOT Education Platform

### 2-1. 제품 개요

**MITRE ATT&CK 프레임워크 기반 인터랙티브 사이버보안 교육 플랫폼**

```
┌─────────────────────────────────────────────────────┐
│                                                       │
│   154개 공격 기법  ×  듀얼 뷰 시뮬레이션  ×  5개 언어  │
│                                                       │
│   "해커의 공격을 직접 체험하고,                        │
│    즉시 방어자 시점에서 탐지/대응을 학습한다"          │
│                                                       │
└─────────────────────────────────────────────────────┘
```

### 2-2. 핵심 차별점 (vs 경쟁 솔루션)

| 비교 항목 | 기존 솔루션 | GOTROOT Platform |
|-----------|------------|-----------------|
| 학습 방식 | PPT/동영상 수동 학습 | **인터랙티브 시뮬레이션** |
| 공격/방어 | 별도 과정으로 분리 | **듀얼 뷰 실시간 전환** |
| 콘텐츠 | 일반적 보안 개념 | **MITRE ATT&CK 154개 기법 매핑** |
| 진행률 | 출석 체크만 | **챕터별 실시간 추적 + 통계 대시보드** |
| 레벨 | 단일 수준 | **초급→중급→고급 잠금 시스템** |
| 언어 | 한국어/영어 | **5개 언어 (한/영/중/힌/일)** |
| 환경 구축 | VM/Lab 별도 구성 필요 | **웹 브라우저만으로 완전 가동** |
| 커스터마이징 | 불가 | **JSON 기반 시나리오 자유 추가** |
| 수료 인증 | 없음 | **기법별 3D 수료증 발급** |

## 3. 기업 도입 시나리오

### 3-1. 시나리오 A: 보안 팀 전문 교육

| 항목 | 내용 |
|------|------|
| **대상** | SOC/CERT/보안관제팀 (5~30명) |
| **목적** | MITRE ATT&CK 기반 위협 인텔리전스 역량 강화 |
| **기간** | 4주 (주 2회, 회당 2시간) |

| **성과 지표** | 기법 완료율, 시뮬레이션 완료율, 평균 학습 시간 |

| 항목 | 내용 |
|------|------|
| **대상** | 전 직원 (100~1,000명) |
| **목적** | ISMS-P 컴플라이언스 + 실질적 보안 인식 제고 |
| **기간** | 상시 (자기 주도 학습, 월 리포트) |
| **과정** | 초급 과정 필수, 중급 선택 |
| **성과 지표** | 초급 완료율 100%, 월별 활성 사용자 수 |

### 3-3. 시나리오 C: 보안 교육 서비스 OEM

| 항목 | 내용 |
|------|------|
| **대상** | 보안 교육 기관 / 대학교 |
| **목적** | 기존 교육 커리큘럼에 MITRE ATT&CK 실습 모듈 통합 |
| **형태** | 화이트 라벨링 (브랜드 커스터마이징) |
| **과정** | 전 레벨 (초급/중급/고급) + 커스텀 시나리오 |
| **성과 지표** | 학생 이수율, 교수자 만족도 |

## 5. 기술적 안정성

### 5-1. 보안 아키텍처

```
[7단계 보안 레이어]

Layer 1: Supabase Auth (JWT + 관리자 승인 2단계)
Layer 2: Row Level Security (테이블별 접근 정책)
Layer 3: DOMPurify (XSS 필터링)
Layer 4: CSRF Protection (SameSite + Bearer Token)
Layer 5: 관리자 재검증 (민감 작업 비밀번호 재입력)
Layer 6: Open Redirect 방어 (화이트리스트 라우팅)
Layer 7: 코드 난독화 + 감사 로그 (프로덕션)
```

### 5-2. 성능

| 지표 | 수치 |
|------|------|
| 초기 로드 | < 3초 (코드 분할 + lazy loading) |
| 번들 크기 | ~800KB (gzip ~216KB) |
| 빌드 시간 | ~26초 |
| 동시 접속 | Supabase Free Tier 기준 500명 |

### 5-3. 확장성

| 항목 | 현재 | 확장 가능 |
|------|------|----------|
| 교육 콘텐츠 | 42개 기법 | 154개 (전체 매핑) |
| 시나리오 | 41개 | JSON 추가만으로 무제한 |
| 언어 | 5개 | 번역 파일 추가만으로 무제한 |
| 사용자 | 500명 (Free) | Supabase Pro: 무제한 |
