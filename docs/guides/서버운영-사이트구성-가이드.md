## 1. 우리 서비스는 어떻게 생겼나요?

갓루트 에듀는 **맥 미니(Mac mini)** 한 대로 운영되는 사이버보안 교육 플랫폼입니다.

```
[사용자 브라우저]
       ↓  인터넷
[공유기 / 포트포워딩]
       ↓
[Mac mini — 갓루트 서버]
  ├─ 웹서버 (Express.js) — 포트 4173
  ├─ 데이터베이스 (Supabase 클라우드) — 외부 서비스
  └─ 사이트 파일 (/Users/db/Desktop/Gotroot_Edu/)
```

**쉽게 말하면:** 사무실 맥 미니가 웹 서버 역할을 하고, 데이터(회원 정보, 학습 기록)는 Supabase라는 외부 클라우드에 저장됩니다.

---

## 2. 핵심 용어 정리

| 용어 | 뜻 | 우리 서비스에서 |
|------|------|----------------|
| **서버** | 웹사이트 파일을 사용자에게 전달하는 컴퓨터 | 맥 미니 |
| **포트(Port)** | 컴퓨터가 통신에 사용하는 창구 번호 | 4173번 창구 사용 |
| **PM2** | 서버를 자동으로 켜고 끄고 재시작해주는 관리자 프로그램 | 맥 미니 안에 설치됨 |
| **Supabase** | 회원 정보·학습 기록을 저장하는 클라우드 DB | 외부 서비스 (supabase.com) |
| **빌드(Build)** | 개발 코드를 실제 서비스용 파일로 변환하는 과정 | 배포 전 필수 |
| **nvm** | Node.js 버전 관리 프로그램 | 맥 미니에 설치됨 |

## 3. 서버 시작 / 중지 / 재시작 방법

> ⚠️ **필수 조건**: 맥 미니에서 **터미널(Terminal)** 앱을 실행한 상태여야 합니다.

### 3-1. 터미널 여는 방법
1. 맥 미니에서 `Cmd + Space` 눌러서 Spotlight 열기
2. `terminal` 입력 → Enter

---

### 3-2. 서버 상태 확인

```bash
source ~/.nvm/nvm.sh && pm2 list
```

**결과 예시:**

```
┌──┬───────────────┬──────┬─────────┬──────┐
│id│ name          │ pid  │ status  │ ↺    │
├──┼───────────────┼──────┼─────────┼──────┤
│0 │ gotroot-prod  │12345 │ online  │  2   │
└──┴───────────────┴──────┴─────────┴──────┘
```

| status 값 | 의미 |
|-----------|------|
| `online`  | ✅ 정상 실행 중 |
| `stopped` | ⛔ 중지됨 |
| `errored` | ❌ 오류로 중단됨 |

---

### 3-3. 서버 시작

```bash
source ~/.nvm/nvm.sh && pm2 start gotroot-prod
```

---

### 3-4. 서버 중지

```bash
source ~/.nvm/nvm.sh && pm2 stop gotroot-prod
```

---

### 3-5. 서버 재시작 (설정 변경 후 적용할 때)

```bash
source ~/.nvm/nvm.sh && pm2 restart gotroot-prod
```

---

### 3-6. 실시간 로그 보기 (오류 발생 시)

```bash
source ~/.nvm/nvm.sh && pm2 logs gotroot-prod --lines 50
```

> 로그 보기 종료: `Ctrl + C`

---

### 3-7. 맥 재부팅 후 서버 자동시작 설정

맥 미니가 재부팅되면 서버가 꺼집니다. 자동시작을 설정하려면:

```bash
# 1단계: startup 명령어 생성
source ~/.nvm/nvm.sh && pm2 startup

# 2단계: 출력된 명령어를 복사해서 그대로 실행 (예시, 실제 출력 기준으로)
# sudo env PATH=$PATH:/Users/db/.nvm/versions/node/v24.14.0/bin ...

# 3단계: 현재 상태 저장
source ~/.nvm/nvm.sh && pm2 save
```

## 4. 사이트 전체 구성 한눈에 보기

```
갓루트 에듀 (Gotroot Edu)
│
├── 🌐 프론트엔드 (사용자가 보는 화면)
│   ├── 메인 페이지 — MITRE ATT&CK 매트릭스 인터랙티브 시각화
│   ├── 레벨 테스트 — 7문제 퀴즈로 사용자 수준 자동 진단
│   ├── 학습 경로 선택 — 추천 학습 vs 자율 학습
│   ├── 교육 콘텐츠 — 이론(HTML) → 그래픽 → 시나리오 → 실습 랩
│   ├── 커뮤니티 — 피드백, 공지사항
│   └── 마이페이지 — 개인 학습 진행률
│
├── ⚙️ 백엔드 (서버, 사용자 눈에 안 보이는 부분)
│   ├── Express.js 웹서버 (포트 4173)
│   │   ├─ 교육 HTML 파일 인증 검사 (로그인 없으면 차단)
│   │   ├─ 로그인 브루트포스 방어 (5회 실패 → 15분 잠금)
│   │   └─ 방문자 IP 수집 (1시간 쿨다운)
│   └── PM2 (서버 자동 재시작 관리자)
│
└── ☁️ 클라우드 (Supabase)
    ├── 회원 정보 (이메일, 레벨, 역할)
    ├── 학습 진행률 (어떤 챕터까지 완료했는지)
    ├── 공지사항
    ├── 커뮤니티 피드백
    ├── 접속 로그 (IP, 시간, 경로)
    └── 위키 용어사전
```

## 5. 사용자가 사이트를 이용하는 흐름

```
1. 사이트 접속
       ↓

   → 결과: novice / beginner / intermediate / advanced / expert
       ↓
3. 회원가입 (레벨 자동 저장)
       ↓
4. 학습 경로 선택
   ├─ 추천 학습: 14개 전술 중 선택 → 서브테크닉 목록 → 학습 시작
   └─ 자율 학습: 전체 매트릭스에서 원하는 기법 직접 선택
       ↓
5. 4단계 학습
   ① 이론 학습 (텍스트)
   ② 그래픽 설명 (시네마틱 슬라이드)
   ③ 시나리오 (스토리 기반 설명)
   └─ ④ 실습 랩 (해커 vs 방어자 시뮬레이션)
       ↓
```

## 8. 자주 있는 상황별 대응

### Q. 사이트가 안 열려요
```bash
# 1. 서버 상태 확인
source ~/.nvm/nvm.sh && pm2 list

# 2. stopped/errored 상태면 재시작
source ~/.nvm/nvm.sh && pm2 restart gotroot-prod

# 3. 로그 확인
source ~/.nvm/nvm.sh && pm2 logs gotroot-prod --lines 30
```

### Q. 맥 미니를 재부팅했더니 사이트가 안 열려요
```bash
# 서버 시작
source ~/.nvm/nvm.sh && pm2 start gotroot-prod
```

### Q. 코드 업데이트 후 반영이 안 돼요 (개발자 작업 후)
```bash
# 프로젝트 폴더로 이동
cd /Users/db/Desktop/Gotroot_Edu

# 빌드 (개발자가 할 작업)
source ~/.nvm/nvm.sh && npm run build

# 서버 재시작
source ~/.nvm/nvm.sh && pm2 restart gotroot-prod
```

### Q. 서버는 켜져있는데 DB 데이터가 안 나와요
→ Supabase 클라우드 문제일 수 있습니다.
→ [Supabase 상태 페이지](https://status.supabase.com)에서 장애 여부 확인

## 10. 명령어 빠른 참조

```bash
# ─────────────────────────────────
# nvm 환경 로드 (매번 터미널 열 때마다 필요)
source ~/.nvm/nvm.sh

# ─────────────────────────────────
# 서버 상태 확인
pm2 list

# 서버 시작
pm2 start gotroot-prod

# 서버 중지
pm2 stop gotroot-prod

# 서버 재시작
pm2 restart gotroot-prod

# 실시간 로그 보기
pm2 logs gotroot-prod --lines 50
# (종료: Ctrl + C)
# ─────────────────────────────────
```

> 💡 **팁**: `source ~/.nvm/nvm.sh`를 매번 치기 귀찮으면, 터미널에서 아래를 실행하면
> 터미널을 새로 열 때마다 자동 적용됩니다.
> ```bash
> echo 'source ~/.nvm/nvm.sh' >> ~/.zshrc
> ```
