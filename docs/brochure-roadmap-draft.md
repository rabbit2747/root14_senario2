# 📋 투자자 브로슈어 — 출시 전 로드맵 섹션 (초안)

> 목적: 기술 과장 없이 투자자 신뢰를 얻는 현실적 로드맵 작성 가이드
> 기준일: 2026-03-04

---

## 핵심 전략: 3단계 분리 프레임

투자자에게 신뢰를 주는 방법은 "전부 다 한다"가 아니라
**"지금 어디까지 됐고, 돈이 생기면 무엇을 언제 한다"**를 명확하게 보여주는 것이다.

```
[단계 1] 이미 완성된 것 (오픈 즉시 가동)
[단계 2] 투자 후 6개월 내 (Seed 라운드 실행 계획)
[단계 3] 2년 목표 (비전 아키텍처 — 레퍼런스용)
```

---

## ✅ 브로슈어 권장 문구 — "오픈 전 완성 기준"

### [현재 완성 = 오픈 즉시 가동]

```markdown
## 현재 완성된 핵심 기능 (출시 즉시 가동)

| 영역 | 완성 항목 |
|------|-----------|
| 학습 콘텐츠 | MITRE ATT&CK 기반 5전술 · 8실제 사고 · 200+ TTP 분석 |
| 실습 환경 | 실시간 시뮬레이션 시나리오 (SolarWinds, WannaCry 등) |
| 다국어 | 한국어·영어·중국어·일본어·힌디어·아랍어 6개 언어 완성 |
| 보안 | Row-Level Security (RLS), XSS 필터링, 감사 로그 |
| 커뮤니티 | 피드백 시스템, 대댓글, 이모지 반응 |
| 관리자 | 실습 에디터, 공지사항 관리, 감사 로그 조회 |
| 인프라 | Supabase(PostgreSQL) + React + Vite, Vercel 배포 |
```

> 💡 **포인트**: "이미 작동하는 제품"이라는 것을 데모로 보여줄 수 있다는 게 강점.
> 피치덱에서 가장 강력한 건 "이미 만들어져 있음"이다.

### [투자 후 6개월 — Seed 집행 계획]

이 부분이 투자자가 가장 보고 싶은 구간이다.
**"이 돈으로 정확히 무엇을 살 거냐"**에 대한 답변이어야 한다.

```markdown
## 투자 후 6개월 실행 계획 (Seed 라운드 기준)

### 인프라 고도화 (Month 1–2)
- Vercel Pro → 전용 Cloud Run 마이그레이션 (가용성 99.9% SLA)
- GitHub Actions CI/CD 파이프라인 구축 (자동 테스트 + 배포)
- Sentry 에러 모니터링, Datadog 기본 대시보드
- 결제 시스템 연동 (Toss Payments / Stripe)

### 콘텐츠 확장 (Month 2–4)
- MITRE ATT&CK 사고 시나리오 8개 → 20개 확장
- 3단계 학습 경로 완성 (입문 / 실무 / 전문가)
- 자격증 연동 커리큘럼 (CISSP, CEH, OSCP 매핑)

### B2B 기반 구축 (Month 3–6)
- 멀티 테넌트 기업 계정 대시보드
- 학습 현황 리포트 (관리자용 Excel/PDF 내보내기)
- LDAP / SSO 연동 (기업 IT 환경 호환)
- 파일럿 고객 3–5개사 계약 목표

### 팀 확장
- 백엔드 개발자 1명 채용
- 콘텐츠 기획자 (사이버보안 전문가) 1명 채용
```

### [2년 목표 비전 아키텍처 — "우리가 향하는 방향"]

여기서 아까 그 엔터프라이즈 아키텍처를 쓰면 된다.
단, 레이블을 바꾼다: **"즉시 실행"이 아니라 "2년 목표"**로.

```markdown
## 2년 목표 — 엔터프라이즈 아키텍처 로드맵

GOTROOT Edu는 Series A 단계에서 Google Cloud 기반 클라우드 네이티브
아키텍처로 전환하여 대기업·정부기관 수준의 확장성을 확보합니다.

[목표 기술 스택]
- GKE Autopilot + Istio Service Mesh (마이크로서비스)
- AlloyDB Global Distribution (멀티리전 DB)
- BeyondCorp Zero Trust 보안
- ArgoCD GitOps 자동화 배포

[전환 조건]
- MAU 10,000명 이상 달성 시점
- 전담 DevOps 엔지니어 확보 후 단계적 전환
- CSAP 인증 클라우드 병행 검토 (공공 조달 대응)
```
