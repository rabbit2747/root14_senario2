# v1.0.1 — 로그인 브루트포스 방어 + 방문자 IP 수집

> 날짜: 2026-03-12
> 심각도: 🔴 Critical (브루트포스), 🟡 Medium (IP 수집 누락)

## 1. 로그인 브루트포스 방어

### 이전 상태 (취약)
- 로그인 실패 시 아무런 제한 없이 무한 재시도 가능
- 공격자가 자동화 스크립트로 비밀번호 대입 공격 가능

### 수정 내용
- **5회 실패 시 15분 잠금** — localStorage 기반 클라이언트 측 제한
- 잠금 시 실시간 카운트다운 타이머 표시 (분:초)
- 잠금 경고: "⚠ 5회 이상 로그인 실패 시 15분간 계정이 잠금됩니다" (5개 언어)
- 로그인 실패마다 `access_logs`에 `login_failed` 액션 기록 (IP 포함)
- 로그인 성공 시 실패 카운터 초기화

### 기술 상세
- `MAX_ATTEMPTS = 5`, `LOCKOUT_DURATION = 15 * 60 * 1000`
- `localStorage('gotroot_login_bf')`: `{ attempts, lockedUntil }` 구조
- 잠금 상태는 탭/브라우저 재시작 시에도 유지 (localStorage 영속)
- i18n: ko, en, zh, hi, ja 5개 언어 지원 (`errLocked`, `attemptsLeft`, `lockWarning`)

### 한계점 (클라이언트 측 방어)
- localStorage 삭제로 우회 가능 → Phase 1 (NestJS) 전환 시 서버 측 rate limiting 추가 예정
- 현재로서도 자동화 봇 대부분 차단 가능 + 실패 로그 기록으로 감사 추적 가능

## 2. 방문자 IP 수집 누락 문제

### 이전 상태 (IP 미수집)
- **원인**: `logAccess()`가 `Login.jsx`의 로그인 **성공** 시에만 호출됨
- `/api/ip` 엔드포인트는 IP를 **반환**만 하고 **기록하지 않음**
- 서버(server.js)에 Supabase DB 클라이언트가 없어 서버 측 기록 불가
- 결과: **익명 방문자, 로그인 실패, 단순 페이지 열람** 시 IP가 전혀 수집되지 않음

### IP 수집 흐름 (수정 전)
```
방문자 → 페이지 접속 → ❌ 기록 안 됨
방문자 → 로그인 실패 → ❌ 기록 안 됨
방문자 → 로그인 성공 → ✅ logAccess(action:'login') → access_logs
```

### IP 수집 흐름 (수정 후)
```
방문자 → 페이지 접속 → ✅ 서버 미들웨어 → access_logs (action:'page_visit')
방문자 → 로그인 실패 → ✅ Login.jsx → access_logs (action:'login_failed')
방문자 → 로그인 성공 → ✅ Login.jsx → access_logs (action:'login')
```

### 수정 내용

#### server.js (프로덕션)
- Express 미들웨어 추가: 모든 HTML 페이지 요청 시 방문자 IP 기록
- Supabase REST API 직접 호출 (`POST /rest/v1/access_logs`)
- **Rate limit**: IP당 1시간 1회만 기록 (in-memory Map, 최대 10,000개)
- 인증된 사용자: JWT 쿠키에서 user_id/email 디코딩하여 함께 기록
- **fire-and-forget**: 로깅 실패가 응답을 지연시키지 않음

#### vite.config.js (개발)
- `blockExternalSourcePlugin` 내 동일 로직 추가
- `process.env.VITE_SUPABASE_URL/KEY` 사용
- 개발 환경에서도 IP 수집 동작 확인 가능

#### Login.jsx (클라이언트)
- 로그인 **실패** 시 `logAccess({ action: 'login_failed' })` 추가
- 기존 로그인 **성공** 로그 유지

### access_logs 테이블 action 값 정리
| action | 발생 시점 | user_id | 비고 |
|--------|----------|---------|------|
| `page_visit` | 모든 페이지 접속 (서버 측) | null 또는 JWT에서 추출 | IP당 1시간 1회 |
| `login` | 로그인 성공 (클라이언트) | 인증된 user_id | |
| `login_failed` | 로그인 실패 (클라이언트) | null | email 포함 |
