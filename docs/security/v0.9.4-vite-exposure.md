# v0.9.4 — Vite Dev Server 소스코드 외부 노출 차단

> **날짜**: 2026-03-08
> **심각도**: 🔴 Critical
> **상태**: ✅ 해결

## 문제

Vite dev server의 `host: '0.0.0.0'` 설정으로 인해 **같은 네트워크의 모든 기기**에서 개발 서버에 접근 가능했음.

### 영향 범위
- 소스코드 (.jsx, .js, .css) 전체 노출
- `.env` 환경변수 (Supabase URL, Anon Key) 노출 가능
- 소스맵을 통한 원본 코드 노출

### 재현 방법
```bash
# 같은 네트워크에서 Mac mini의 IP로 접근
curl http://192.168.x.x:5173/src/main.jsx
# → 200 OK + 소스코드 반환
```

## 원인

`vite.config.js`에 `server.host: '0.0.0.0'` 설정이 있어 모든 네트워크 인터페이스에서 접근 허용.

## 해결

### 변경 사항
1. **`vite.config.js`**: `host: '0.0.0.0'` → `host: '127.0.0.1'` (로컬만 허용)
2. **`blockExternalSourcePlugin`**: Vite 미들웨어 추가 — 비-localhost 요청 차단
3. **`sourcemap: false`** (빌드): 프로덕션 소스맵 제거
4. **`sourcemapIgnoreList`** (dev): 개발 소스맵에서 node_modules 제외

### 수정 파일
- `vite.config.js`

## 검증

```bash
# 외부 접근 차단 확인
curl http://192.168.x.x:5173/src/main.jsx
# → Connection refused (127.0.0.1만 바인딩)
```

## 교훈

- 개발 서버는 항상 `127.0.0.1`로 바인딩할 것
- 프로덕션 빌드에서 sourcemap은 반드시 비활성화
